## 默认版 5 点（无个性化发现时直接用）

> 以下 5 点基于本仓库已记录的高频失分（各卷 `-morning-key.md` 的丢分重灾区 +
> `review-round2/3.md` 错题清单 + Task 27–29 大题专项的易错点），按"丢分概率 × 分值"排序。

### 第 1 点：关键路径与总时差（松弛时间）计算

- **知识点**：AOE 网中，关键路径 = 从源点到汇点的**最长路径**（长度 = 最短工期）；
  活动总时差 = LS − ES = Vl(终点) − Ve(起点) − 活动时长；**关键活动总时差 = 0**；
  一个 AOE 网可有多条**等长**的关键路径。
- **为什么易错**：
  ① 只找出一条最长路径，**漏掉等长的第二条**（如 2020 下/2019 下均有 2 条）；
  ② 记反计算方向——**最早时间从左向右取大，最晚时间从右向左取小**；
  ③ 原图权值没提取全时只能靠猜（本仓库多卷标【存疑：图形复原】）；
  ④"一旦延期就影响工期"= 关键活动（时差为 0），与"非关键活动可吸收延迟"混淆。
- **考前怎么看**：
  1. 重算 `docs/practice/papers/2019H2-morning-key.md` Q17-18——关键路径 **ABFJL** 与
     **ADGIJL**（总工期 22 天，2 条），活动 BE 总时差 = LS − ES = 6 − 4 = **2 天**；
  2. 再算 `docs/practice/papers/2021H1-morning-key.md` Q17-18——关键路径 A-D-F-H-J
     （48 天），各活动总时差 AC=8 / BE=21 / FI=14 / HJ=0；
  3. 错题对照：`docs/practice/review-round3.md`（卷 5 第 17–18，关键路径与关键活动）、
     `review-round2.md`（卷 3 第 18–19，关键路径与松弛时间）；
  4. 默写一遍口诀：**"最早取大、最晚取小；总时差 = LS − ES；时差为 0 是关键活动。"**

### 第 2 点：页式 / 段页式地址转换

- **知识点**：页面大小 2^k → 逻辑地址**低 k 位为页内偏移、高位为页号**；查页表由页号得
  物理块号；**物理地址 = 块号拼接偏移**。段页式多一层：逻辑地址 = 段号 + 页号 + 页内偏移，
  先查段表得页表始址，再查页表得块号。
- **为什么易错**：
  ① 忘了偏移位数（4K = 2¹²，16K = 2¹⁴）；
  ② 把**页号直接当物理块号**拼接（页号是查表用的键，块号才是结果）；
  ③ 段页式题漏掉段表那一层，位数换算算错；
  ④ 十六进制与二进制换算时位数对不齐。
- **考前怎么看**：
  1. 重算 `docs/practice/papers/2020H2-morning-key.md` Q24——页面 4K，逻辑地址 3C20H
     → 页内偏移 C20H、页号 3 → 查表得块号 6 → 物理地址 **6C20H**；
  2. 段页式结构看 `docs/practice/papers/2022H2-morning-key.md` Q27（段页式地址结构）
     与 `2022H1-morning-key.md` Q36（段页式位数换算）；
  3. 固定套路写一遍：**"除以页大小得页号、取余得偏移；物理地址 = 块号 × 页大小 + 偏移"**。

### 第 3 点：E-R 联系类型判定与关系模式转换（下午试题二）

- **知识点**：联系类型判定口诀——**两端都唯一 → 1:1；一端唯一 → 1:n；都不唯一 → m:n**。
  转换规则：1:1 → 任一端加对方主键作外键；1:n → **n 端**关系加 **1 端的主键**作外键；
  m:n → 新建关系，主键 = 两端主键的组合。主键 = 唯一确定元组的最小属性组；
  外键 = 引用其它关系主键的属性。
- **为什么易错**：
  ① 量词句读不全，1:1 与 1:n 混淆——典型陷阱是把"每家只有一名店长、每名只负责一家"
     （**1:1**）看成 1:n，或把"至少一位"（上界不限 = **n**）看成 1:1；
  ② 1:n 转换时外键加错端、或写成 1 端的**非主键**属性（如把"专卖店名"当外键）；
  ③ 新增实体的关系模式**漏掉外键属性**（如紧急联系人漏"职员号"）；
  ④ 关系模式填空只补一个属性——要把需求属性清单与关系模式**逐项对照**找全空缺。
- **考前怎么看**：
  1. 精读 `docs/practice/subject2/database-notes.md` 二·第 2 步（联系类型判定口诀 +
     量词句读法）+ 第 4 步（E-R → 关系模式转换规则）+「主键 / 外键判定规则」；
  2. 重做本模拟 `docs/practice/mock-exam/subject2-questions.md` **试题二**
     （2022下营销公司：1:1 店长 + 两个 1:n + 新增实体，三杀考点），对答案见
     `subject2-key.md` 的【存疑：推导答案】与逐空推导；
  3. 错题对照：`docs/practice/papers/2020H2-morning-key.md` Q17-18 之外的数据库题——
     候选码与主属性（2019H2 Q52-53、2021H1 Q52-53）、关系代数表达式构造
     （2019H2 Q54-55、2021H2 Q54-55）。

### 第 4 点：动态规划状态转移（下午试题四）

- **知识点**：**最优子结构 + 重叠子问题 → 动态规划**。区间 DP 的三重循环固定套路：
  **外层枚举区间规模 r → 中层枚举左端点 i（右端点 j = i + r − 1）→ 内层枚举切点 k**；
  状态转移三件套 = 状态定义 / 边界条件 / 递推式；典型时空复杂度 O(n³) / O(n²)。
- **为什么易错**：
  ① 内外层循环的**枚举对象分不清**（规模 / 端点 / 切点谁在外层）；
  ② 题干递推式与代码对不上——不会把 `m[i][j] = min{...}` 逐项映到三重循环；
  ③ 空间复杂度误写成与时间相同（空间只看声明的二维数组，不看循环次数）；
  ④ 递归输出函数的空不会填——通常是**参数的对称变换**（如 `(i, S[i][j])` 对
     `(S[i][j]+1, j)`）；⑤ 策略误答成分治或贪心。
- **考前怎么看**：
  1. 精读 `docs/practice/subject2/patterns-algo-notes.md` 二·2.2（DP 题专属：状态转移三件套）
     + 2.3（常考算法骨架·动态规划）+ 2.4（得分技巧）；
  2. 重做本模拟 `subject2-questions.md` **试题四**（2021上凸多边形最优三角剖分），
     把题干递推式与 C 代码三重循环逐项对齐；对答案见 `subject2-key.md`（含空(1) 的
     OCR 存疑说明与判读）；
  3. 选择题 DP 连环错：`docs/practice/papers/2019H1-morning-key.md` Q62-65
     （矩阵连乘 DP 四空连环）；
  4. 默写一遍：**"外层规模、中层左端、内层切点；右端点 = 左端点 + 规模 − 1。"**

### 第 5 点：设计模式角色结构与场景关键词（试题五/六 + 试题三问题 3）

- **知识点**：**场景关键词 → 模式映射**（"状态变化自动通知依赖者"= 观察者；
  "统一接口访问多个子系统"= 外观；"撤销/恢复状态"= 备忘录；"多种可替换算法/格式"
  = 策略；"树形/部分-整体"= 组合；"多对象交互由第三方协调"= 中介者）。
  每个模式要记**意图 + 角色结构 + 代码特征**，填空题的空几乎都在角色类的声明上。
- **为什么易错**：
  ① 只背模式名不背**角色结构**，填空时不知该填哪个类/方法签名；
  ② 相近模式混淆——策略 vs 状态、外观 vs 中介者、组合 vs 装饰、
     观察者 vs 发布-订阅；
  ③ Java/C++ 语言细节错——`abstract` vs `virtual`、`new` 返回对象 vs 指针、
     `List` 声明 vs `ArrayList` 实例化；
  ④ 下午试题三的"问题 3 加什么模式"只写模式名不解释角色对应（要写"本需求中 X 是主题、
     Y 是观察者"）。
- **考前怎么看**：
  1. 过一遍 `docs/practice/subject2/patterns-algo-notes.md` 一·1.1（场景关键词 → 模式
     映射秒选表）+ 1.2（六个高频模式：意图 + 角色结构 + 代码特征）+ 1.3（填空通用三招）；
  2. 本模拟 `subject2-key.md` **试题三问题 3**（观察者模式 + 角色对应解释）；
  3. 选择题模式连错：`docs/practice/papers/2021H2-morning-key.md` Q44-46（中介者三连）、
     `2020H2-morning-key.md` Q44-47（设计模式四连）、`2023H1-morning-key.md` 试题五
     （策略模式完整代码题，本卷未选作大题，可当选择题读）；
  4. 考前 30 分钟只看 1.1 秒选表 + 1.2 的角色结构图。
