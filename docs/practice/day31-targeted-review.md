**3 分钟速记卡**（合上文件默写）

```
关键路径 = 源点到汇点的【最长路径】，其长度 = 【最短工期】（不是边最多的路径！）
正向求 Ve：从左向右，取【大】 max{ Ve(i) + d(i,j) }，源点 Ve = 0
逆向求 Vl：从右向左，取【小】 min{ Vl(j) − d(i,j) }，汇点 Vl = Ve(汇点)
活动总时差（松弛）= LS − ES = Vl(终点) − Ve(起点) − 活动时长
总时差 = 0 的活动 = 【关键活动】；"延期 x 天是否影响工期"⇔ 比较 x 与总时差
一个 AOE 网可有多条【等长】关键路径——找全再选答案
口诀：最早取大、最晚取小；总时差 = LS − ES；时差为 0 是关键活动
```

**自测小题 2 道（先做，答案在本点末尾折叠区）**

**自测 1-1**：某工程 AOE 网如下（顶点为事件，边上数字为活动天数）：

```

V1 ────┤          └──e=5──▶ V5 ──h=4──▶ V6
```

（边集：V1→V2=3、V1→V3=2、V2→V4=4、V3→V4=6、V2→V5=5、V4→V5=2、V4→V6=7、V5→V6=4）

问：① 关键路径是哪条？总工期多少天？② 活动 V2→V5（e）的总时差是多少天？③ 哪些活动只要延期 1 天就会影响总工期？

**自测 1-2**：某项目活动表如下（只给出前驱关系与工期）：

| 活动 | 紧前活动 | 工期（天） |
|------|----------|-----------|
| A | — | 5 |
| B | — | 3 |
| C | A | 4 |
| D | A | 6 |
| E | B | 7 |
| F | C | 3 |
| G | D、E | 5 |
| H | F、G | 4 |

问：① 关键路径是哪条？总工期多少天？② 活动 E 的总时差是多少天？③ 若活动 E 延期 2 天，总工期是否变化？变成多少？

<details>
<summary>【答案】自测 1-1 与 1-2（做完再展开）</summary>

**自测 1-1 答案**：
- ① 正向求 Ve：Ve(V1)=0；Ve(V2)=3；Ve(V3)=2；Ve(V4)=max(3+4, 2+6)=8；Ve(V5)=max(3+5, 8+2)=10；Ve(V6)=max(8+7, 10+4)=max(15,14)=15。
  **关键路径 = V1→V3→V4→V6（2+6+7=15），总工期 15 天**（其余路径：V1→V2→V4→V6=14、V1→V3→V4→V5→V6=14、V1→V2→V5→V6=12，均短于 15，故本题只有 1 条关键路径）。
- ② 逆向求 Vl：Vl(V6)=15；Vl(V5)=15−4=11；Vl(V4)=min(15−7, 11−2)=8。
  活动 e（V2→V5）总时差 = Vl(V5) − Ve(V2) − 5 = 11 − 3 − 5 = **3 天**。
- ③ **关键活动 = 总时差为 0 的活动**：V1→V3（0）、V3→V4（0）、V4→V6（0）。这三条边上任意一条延期 1 天，总工期立即变 16 天。
  （对照：V1→V2 时差 1、V2→V4 时差 1、V4→V5 时差 1、V5→V6 时差 1、V2→V5 时差 3，均能吸收 1 天延迟。）

**自测 1-2 答案**：
- ① ES/EF：A(0,5)、B(0,3)、C(5,9)、D(5,11)、E(3,10)、F(9,12)、G(11,16)、H(16,20)。

4. 笔记章节：`docs/knowledge-points/os/day02-memory.md` §3.3（页式地址转换：乘页大小 / 二进制切位）、§4.2（段式加段基址、段页式先段表后页表）；
5. 默写固定套路（见下方速记卡）。

**3 分钟速记卡**（合上文件默写）

```
页大小 = 2^k ⇒ 逻辑地址【低 k 位 = 页内偏移】，高位 = 页号
页号是【查表的键】，查表得到的【块号】才是结果
物理地址 = 块号 × 2^k + 偏移（即二进制【拼接】，不是相加！）
固定套路口诀：除以页大小得页号、取余得偏移；物理地址 = 块号 × 页大小 + 偏移
段页式 = 段号 + 页号 + 页内偏移：先查【段表】得页表始址，再查【页表】得块号
段式 ≠ 页式：页式乘页大小（块号拼接偏移）、段式加段基址（段基址 + 偏移）
常用换算：4K = 2¹²、8K = 2¹³、16K = 2¹⁴、1K = 2¹⁰
```

**自测小题 2 道（先做，答案在本点末尾折叠区）**

**自测 2-1**：某系统采用页式存储管理，页面大小为 **8KB**。逻辑地址为 **5F3AH**，查页表知页号对应的物理块号为 **9**。求：① 页号与页内偏移各是多少（偏移用十六进制写）？② 物理地址是多少？

**自测 2-2**：某计算机采用**段页式**存储管理，逻辑地址共 **32 位**，其中**段号 8 位、页号 12 位**，其余为页内偏移。求：① 页内偏移占几位？页大小是多少？② 该系统最多允许多少个段？每个段最多允许有多少页？

<details>
<summary>【答案】自测 2-1 与 2-2（做完再展开）</summary>

**自测 2-1 答案**：
- ① 8KB = 2¹³，故低 13 位为页内偏移。
  5F3AH = 24378；24378 ÷ 8192 = 2 余 7998 ⇒ **页号 = 2**；余数 7998 = **1F3AH**（验算：2 × 2000H = 4000H，5F3AH − 4000H = **1F3AH**）⇒ **页内偏移 = 1F3AH**。
  （二进制切位验算：5F3AH = 0101 1111 0011 1010B，低 13 位 = 1 1111 0011 1010B = 1F3AH，高 3 位 = 010B = 2 ✓）
- ② 物理地址 = 块号 × 页大小 + 偏移 = 9 × 8192 + 7998 = 73728 + 7998 = **81722 = 13F3AH**。
  （验算：9 × 2000H = 12000H，12000H + 1F3AH = **13F3AH** ✓。块号 9 拼到高位，偏移照抄——这就是"拼接不是相加"。）

**自测 2-2 答案**：
- ① 页内偏移位数 = 32 − 8 − 12 = **12 位** ⇒ 页大小 = 2¹² = 4096 B = **4 KB**。
- ② 段号 8 位 ⇒ 最多 **2⁸ = 256** 个段；页号 12 位 ⇒ 每个段最多允许 **2¹² = 4096** 页（是**上限**，不是"每个段都正好 4096 页"——段内页数随段大小变化）。

</details>

**自测小题 2 道（先做，答案在本点末尾折叠区）**

**自测 4-1**：下面是区间型动态规划（矩阵连乘 / 最优三角剖分类）的核心代码骨架，(1)~(4) 各应填什么？

```c
for (r = 2; r <= n; r++)              // (1) ____________________
    for (i = 1; i <= n - r + 1; i++)  // (2) ____________________
    {
        j = i + r - 1;                // (3) ____________________
        for (k = i; k < j; k++)       // (4) ____________________
            m[i][j] = min(m[i][j], m[i][k] + m[k+1][j] + p[i-1]*p[k]*p[j]);
    }
```

**自测 4-2**：三个矩阵连乘，维数分别为 A₁: 10×5、A₂: 5×20、A₃: 20×3（即 p₀=10, p₁=5, p₂=20, p₃=3）。求：① 最少乘法次数；② 最优括号化方案（在哪个位置断开）？要求写出 m[1][2]、m[2][3]、m[1][3] 的计算过程。

<details>
<summary>【答案】自测 4-1 与 4-2（做完再展开）</summary>

**自测 4-1 答案**：
- (1) **枚举区间规模 r**（从 2 到 n：先算所有长度为 2 的区间，再长度为 3……保证算 m[i][j] 时它依赖的更短区间已算完）；
- (2) **枚举左端点 i**（右端点由规模推出，上界 n−r+1 保证 j ≤ n）；
- (3) **右端点 j = i + r − 1**；
- (4) **枚举切点 k**（在 i 与 j−1 之间，把区间 [i,j] 切成 [i,k] 与 [k+1,j] 两段）。
  口诀对照：**外层规模、中层左端、内层切点**。方向记反是本题最常见的错——规模一定在最外层，否则依赖的子问题还没算。

**自测 4-2 答案**：
- 边界：m[1][1] = m[2][2] = m[3][3] = 0。
- 长度 2：m[1][2] = p₀p₁p₂ = 10×5×20 = **1000**；m[2][3] = p₁p₂p₃ = 5×20×3 = **300**。
- 长度 3（m[1][3]，在 k=1 或 k=2 断开）：
  - k=1：m[1][1] + m[2][3] + p₀p₁p₃ = 0 + 300 + 10×5×3 = 300 + 150 = **450**；
  - k=2：m[1][2] + m[3][3] + p₀p₂p₃ = 1000 + 0 + 10×20×3 = 1000 + 600 = **1600**。
  - 取最小 ⇒ **m[1][3] = 450**，断开点 **k = 1**。
- 结论：① **最少乘法次数 = 450 次**；② 最优方案 **(A₁(A₂A₃))**——先算 A₂A₃（5×20×3=300 次，得 5×3 矩阵），再算 A₁×该结果（10×5×3=150 次），合计 450 次。若用 (A₁A₂)A₃ 则需 1000+600=1600 次。

</details>

### 3.2 答案与解析（每题标注知识点 + 在练哪个漏洞）

**1. C。**
- 推导：4KB = 2¹²，故逻辑地址**低 12 位为页内偏移**。2A5CH = 0010 1010 0101 1100B，低 12 位 = **A5CH**（偏移），高 4 位 = 0010B = **2**（页号）；查表得块号 5 ⇒ 物理地址 = 块号 × 4KB + 偏移 = 5 × 1000H + A5CH = **5A5CH**。
- 【知识点】页式地址转换（TOP 2）　【出题意图】练"**块号拼接偏移，不是相加**"这个最高频的错——A（7A5CH）是把页号 2 与块号 5 相加（2+5=7）；B（2A5CH）是把页号直接当块号；D（A5CH）是只取偏移。
- ✅ 自检：若选 A，回看 `2020H2-morning-key.md` Q24（3C20H → 6C20H）。

**2. B。**
- 推导：同步信号量初值 = 0；每条前趋边 Pi→Pj 对应"**Pi 结束处 V，Pj 开头 P**"（口诀：前 P 后 V 一对配，初值看资源：互斥 1、同步 0）。P1→P2 ⇒ P1 末尾 V(S1)、P2 开头 P(S1)；P1→P3 ⇒ P1 末尾 V(S2)、P3 开头 P(S2)。
- 【知识点】前趋图与 PV 操作（TOP 3）　【出题意图】练**初值（同步 0）+ P/V 方向（前驱 V 在后、后继 P 在前）**——A/D 初值错（同步信号量不是 1）；C 把 P/V 填反了位置（P2/P3 无后驱 P1，开头 P 会立刻阻塞）。
- ✅ 自检：若选 C，回看 `2019H2-morning-key.md` Q23-25（三空连环）。

**3. A。**
- 推导：块数 = 1024GB ÷ 4MB = 2²⁰ MB ÷ 2² MB = 2¹⁸ = 262144 块（每位记录 1 块，共需 2¹⁸ 位）；字长 64 = 2⁶ 位 ⇒ 字数 = 2¹⁸ ÷ 2⁶ = 2¹² = **4096** 个字。
- 【知识点】位示图（TOP 2 变式）　【出题意图】练**容量单位 2 进制换算**——B（2048）是忘记把 GB 换成 MB 多除了一次；C（8192）/ D（16384）是块数或字长换算错。
- ✅ 自检：若算错，回看 `2021H1-morning-key.md` Q24（2048GB / 8MB / 128 位 → 2048 字）。

**4. C。**
- 推导：ARP 把 **IP 解析为 MAC**，为 IP 服务；虽然 ARP 报文不经 IP 封装（直接装在以太网帧里），但**软考按网际层（网络层）作答**。
