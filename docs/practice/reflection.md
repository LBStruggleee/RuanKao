> - **第 7 题（顺序 vs 过程内聚）**：**有数据链（前元素输出是后元素输入）→ 顺序内聚；只按固定顺序执行而无数据链 → 过程内聚**。通信内聚的判据是"使用同一输入或产生同一输出"，不是流水线。
> - **第 13、14 题（覆盖标准）**：强度顺序**语句 < 判定 < 条件 < 判定-条件 < 条件组合 < 路径**（判定在条件之前）。**条件组合覆盖 = 每个判定中所有条件的各种取值组合至少一次**——`if(a>0&&b>0)` 有 2 个条件就要覆盖 (T,T)/(T,F)/(F,T)/(F,F) **4 种**组合。
> - **第 15、16 题（V(G)）**：`V(G) = E − N + 2`，**"+2" 最容易漏**（漏了得 E−N）。`V(G) = 判定节点数 + 1`（V(G)=5 ⇒ 4 个判定，不是 5 个）。**V(G) = 独立路径数 = 最少用例数**；全部可能路径数**可以远大于** V(G)（含循环时甚至无穷）。
> - **第 10、11 题（等价类/边界值）**：[0,100] 的有效等价类 1 个、**无效等价类 2 个（x<0、x>100）**；边界值取 **{−1, 0, 1, 99, 100, 101}**——"刚好越界"的 −1 和 101 最容易漏。
> - **第 17、18 题（维护）**：两步法——先问"系统错了吗"（改正性），再问"环境变了还是用户想要更多"（**环境变了=适应性，用户要更多/更好=完善性**）。占比最大的是**完善性（~50%）**。导出 PDF = 新功能 = 完善性。
> - **第 19、20 题（项目管理）**：甘特图**直观但难以反映任务间依赖与关键路径**（那是 PERT/CPM 的强项）；关键路径 = **源点到汇点最长路径**，其长度 = 项目最短工期（不是最短路径！）。
> - **计算题 21–23**：错了一定要**重画 CFG、重数 E 和 N**，不要只对答案。三题 V(G) 分别为 **3、4、3**，均可用 `E−N+2` 与 `判定数+1` 两法交叉验算；独立路径数用路径向量的秩验证。第 22 题的**不可行路径**（走 ④ 又走 ⑦：D2 真 ⇒ f=10 ⇒ f>50 恒假）和第 23 题的**回边**（③→②）是两道题的精华。

### 「仍错知识点」标记区

> **填法**：Day 17 暴露的仍错知识点（重做仍错 + 25 题仍错 + UML 自评 ≤6 分的项）在下面打 ☑。

**操作系统**（仍错就打 ☑）：
- ☐ 页式地址转换（物理 = 块号×页大小 + 偏移）
- ☐ 多级页表访存次数（TLB 命中 1 次 / 二级页表未命中 3 次）
- ☐ 磁盘 SSTF 寻道计算（折返跑，逐段列距离）
- ☐ 索引文件可管理大小（4KB 块：一级 4MB / 二级 4GB / 三级 4TB）
- ☐ PV 操作信号量取值范围（−(n−m) 〜 m）
- ☐ SJF 周转时间计算
- ☐ 位示图 / 改进型 Clock 页面置换

**计算机网络**（仍错就打 ☑）：
- ☐ 子网划分 5 步法（2^h − 2 ≥ 主机数 → 定网络位 → 写掩码 → 块大小 → 子网数）
- ☐ CIDR 路由聚合（2^k 个网络 → 前缀减 k）
- ☐ ARP / ICMP = 网络层
- ☐ 加密算法参数（DES 56/64、3DES 168、AES 分组 128）+ 数字签名不提供机密性
- ☐ 拥塞控制（超时回 1 vs 重复 ACK 减半）

**数据库**（仍错就打 ☑）：
- ☐ 聚合与 NULL（COUNT(*) / COUNT(列) / AVG 分母不算 NULL）
- ☐ JOIN 类型与行数（左外 = 匹配 + 左表无匹配）
- ☐ 候选码求解（L/N/R/LR 分类 + 闭包，多候选码要求全）
- ☐ 范式判断 5 步流程 / 3NF 与 BCNF 分界
- ☐ E-R 转关系模式（M:N 独立建表 / 1:N 外键在 N 端）

**计算机组成**（仍错就打 ☑）：
- ☐ 不等长段流水线（T = Σt + (n−1)Δt；E = n·Σt/(k·T)，等长段公式 E = n/(k+n−1) 不适用）
- ☐ Cache 三种映射地址结构（全相联**无行号字段**；位数守恒律自查）
- ☐ Cache 命中率（t_a = h·t_c+(1−h)·t_m / S = t_m/t_a / e = t_c/t_a；效率 ≤ 100%）
- ☐ 总线带宽 = 频率 × 宽度 / 8（MB/s 一定要 ÷8）

**软件工程 / UML**（仍错或自评 ≤6 分就打 ☑）：

**数据结构**（仍错就打 ☑）：
