## 二、逐题解析（含知识点归属）

> 格式：`答案 | 【科目】知识点 | 解析`

**1. B**｜【计算机基础】RISC 与 CISC
RISC（精简指令集）的特点是**指令种类少、指令功能简单、长度固定、寻址方式少、大量通用寄存器、硬布线控制、适合流水线**。"指令种类多、指令功能强"是 **CISC**（复杂指令集）的特点，故 B 的叙述错误。A（限制访存操作使控制简单）、C（大量通用寄存器）、D（选取高频指令提高速度）均为 RISC 特点。

**2. B**｜【计算机基础】CPU 组成
CPU 由**算术逻辑单元（ALU）、控制单元（CU）、寄存器组**及内部总线等组成。**系统总线**是主板上各部件之间通信的公共线路（数据/地址/控制总线），属于计算机系统而非 CPU 内部的基本组成部件，故选 B。

**3. D**｜【计算机基础】可靠性计算
可靠度 R = （正常工作的系统数）/（系统总数）= (2000−4)/2000 = 1996/2000 = **0.998**，选 D。

**4. A**｜【计算机基础】存储器
**DRAM（动态随机存取存储器）**依靠**电容**存储电荷，电容会自然放电，故需**周期性刷新**（再生）才能保持信息，常用作主存。SRAM 用触发器存储，无需刷新（速度快、集成度低，用于 Cache）；EPROM、EEPROM 均为可擦除只读存储器（非易失），不需刷新。

**5. C**｜【计算机基础】浮点数表示
浮点数的**阶码位数决定表示范围**（阶码越长范围越大），**尾数位数决定表示精度**（尾数越长有效位越多、精度越高）。前者阶码长尾数短 ⇒ **范围更大但精度更低**，选 C。

**6. D**｜【计算机基础】补码
补码的设计目的是**将减法运算转换为加法运算**：负数用补码表示后，X−Y 可当作 X+(−Y) 的补码加法直接计算，从而**简化运算器（ALU）的硬件设计**（只需加法器）。这正是计算机采用补码表示有符号数的根本原因，选 D。

**7. C**｜【网络·信息安全】身份认证
**口令认证**（静态密码）最弱：口令可被穷举、字典破解、网络嗅探、键盘记录或社会工程学窃取。生物认证（指纹/人脸）具有唯一性、难复制；多因子认证需要两个以上独立凭据；U 盾认证基于数字证书与私钥（硬件载体），安全性均高于口令认证。

**8. A**｜【网络·信息安全】X.509 数字证书
X.509 数字证书标准**推荐使用 RSA**（基于大整数分解的非对称密码算法）作为公钥算法，故（8）选 A。

**9. D**｜【网络·信息安全】国密 SM2
国密 **SM2** 是我国自主研制的**基于椭圆曲线（ECC）**的非对称公钥密码算法，用于数字签名、密钥交换与公钥加密，SM2 数字证书采用的公钥算法是 **ECC**，故（9）选 D。

**10. C**｜【网络·信息安全】Web 应用防火墙
网站首页被恶意篡改属于**应用层（Web 层）攻击**（如 SQL 注入、跨站脚本、网页挂马）。**Web 应用防火墙（WAF）**专门针对 HTTP/HTTPS 流量进行深度检测，可识别并阻断针对 Web 应用的攻击，阻止网页被篡改。数据库审计用于数据库访问记录；包过滤防火墙工作在网络层，不识别应用层内容；入侵检测（IDS）以发现并告警为主，阻断能力弱于 WAF。

**11. A**｜【网络·信息安全】漏洞扫描
漏洞扫描系统通过比对漏洞特征库，**发现**目标系统存在的**高危风险与安全漏洞**并给出报告。**修复**漏洞需另行下载补丁、修补程序（B 错）；获取攻击日志是 IDS/审计系统的工作（C 错）；关闭非必要端口/服务是安全加固/基线检查的工作（D 错）。

**12. C**｜【知识产权】委托开发软件的著作权
《计算机软件保护条例》第十一条：委托开发的软件，其**著作权的归属由委托人与受托人签订书面合同约定**；**无书面合同或合同未作明确约定的，其著作权由受托人享有**。故 C 正确。A 的"仅依据合同约定"未涵盖无合同情形；B 的"无论是否有约定都共同享有"错误；D 的"由委托人享有"与法条相反。

**13. B**｜【知识产权】软件著作权·翻译权
按官方指定教材《软件设计师教程（第5版）》：软件著作权中的翻译权，是指**将原软件由一种程序设计语言转换成另一种程序设计语言**的权利，故选 B。
> ⚠️ **存疑题（教材与法条冲突）**：《计算机软件保护条例》第八条第一款第八项原文为"（八）翻译权，即**将原软件从一种自然语言文字转换成另一种自然语言文字**的权利"（中国网信网 cac.gov.cn 刊载），**逐字对应选项 D**。本题两大完整题库（软考达人、信管网）按教材口径给 B，考试采分以 B 为准；但若严格按法条原文则应为 D。记忆建议：**答题按 B（程序设计语言），但知悉法条原文为"自然语言文字"**。

**14. B**｜【知识产权】软件知识产权
软件产品开发完成即**自动享有软件著作权**（登记非取得条件）；注册商标 S 后享有**商标权**；对员工保密约束保护的是**商业秘密权**。而**专利权**需要就技术方案向专利局提出申请并经审查授权，M 公司仅为软件产品注册商标并保密约束，**未申请专利**，故不享有专利权，选 B。

**15. C**｜【软件工程】加工规格说明·判定表
该基本加工的输出取决于**多个条件的取值组合**（客户类型、订单金额、客户信用），判定表（决策表）能清晰列出全部条件组合与对应动作，最适合描述此类**多条件驱动**的加工规格说明。自然语言易歧义；流程图侧重控制流程而非条件组合；程序设计语言用于实现而非规格描述。

**16. C**｜【软件工程】模块结构优化
优化模块结构应：使模块功能完整（A）、消除重复功能改善结构（B）、避免或减少病态连接（D）。确定模块规模**不能只看模块本身功能**，还要考虑模块间的调用关系、扇入扇出与接口复杂度，"只根据模块功能确定规模大小"不适当，选 C。

**17. D**｜【软件工程】AOE 网与关键路径
关键路径是从源点到汇点的**最长路径**。（【存疑：图形复原】活动图见原卷 PDF 第 4 页，边集见题目附注。）最长路径为 **A→C→F→I→J**：16+9+18+15 = **58** 天，故选 D。

**18. B**｜【软件工程】关键活动
"一旦延期就会影响项目进度"的活动即**关键活动**（总时差为 0，位于关键路径上）。由上题关键路径为 A→C→F→I→J，其中 **C→F 是关键活动**，一旦延期直接影响总工期，选 B。（A→B、D→F、F→H 均为非关键活动，存在时差。）

**19. B**｜【软件工程】风险管理
风险管理应**承认风险客观存在、不可能完全避免**（A 对），**贯穿整个项目管理过程**（C 对），且**风险计划本身可能带来新的风险**（D 对）。但风险管理者应**按优先级管理风险**，资源有限，"同时管理所有的风险"既不现实也不经济，B 的叙述不正确。

**20. B**｜【计算机基础·程序设计语言】栈帧（活动记录）
栈帧用于支持被调用函数的执行，其中存放**形式参数变量、返回地址、局部变量、保存的寄存器**等。**全局变量**存放在静态存储区（数据段），生命周期为整个程序运行期，不随函数调用在栈上分配，故栈帧中不包括全局变量，选 B。

**21. D**｜【计算机基础·程序设计语言】编译器与解释器
**编译器先翻译（生成独立的目标程序）后执行**，目标程序可重复运行，用户程序**运行效率高**；但目标程序与具体机器/平台相关，**可移植性差**（换平台需重新编译）。解释器边翻译边执行，运行效率低，但可移植性较好（依赖解释器环境）。题干问"编译器"，故选 D。

**22. A**｜【计算机基础·程序设计语言】语法分析方法
**递归子程序法**（递归下降分析）对每个非终结符编写一个递归过程，从**开始符号自上而下**地为输入串建立语法树，属于**自上而下（自顶向下）**分析法。自下而上分析法如算符优先分析、LR 分析。

**23. C**｜【操作系统】进程调度方式
调度时**强行撤下正在运行进程的 CPU、让更高优先级进程运行**，称为**可剥夺（抢占）调度方式**：高优先级进程可剥夺低优先级进程的 CPU。不可剥夺方式下进程一旦获得 CPU 便运行至结束或主动让出。

**24. C**｜【操作系统】前驱图与 PV 操作
（【存疑：图形复原】前趋图见原卷 PDF 第 6 页，8 条边对应 8 个信号量 S1~S8。）
P1 有 **2 个后继**（P2、P3），执行后应做 2 个 V 操作通知后继 → ① = **V(S1)V(S2)**；P2 有 **2 个后继**（P3、P4），执行后应做 2 个 V 操作 → ② = **V(S3)V(S4)**。故空①和空②为 **V(S1)V(S2) 和 V(S3)V(S4)**，选 C。

**25. C**｜【操作系统】前驱图与 PV 操作
P3 有 **2 个前趋**（P1、P2），执行前需 2 个 P 操作；代码中 P3 已有 P(S2)（等待 P1），故空③补 **P(S3)**（等待 P2）。P4 有 **2 个后继**（P5、P6），执行后做 2 个 V 操作 → ④ = **V(S6)V(S7)**。故空③和空④为 **P(S3) 和 V(S6)V(S7)**，选 C。

**26. D**｜【操作系统】前驱图与 PV 操作
P5 有 **1 个后继**（P6），执行后做 1 个 V 操作 → ⑤ = **V(S8)**。P6 有 **2 个前趋**（P4、P5），执行前需 2 个 P 操作 → ⑥ = **P(S7)P(S8)**。故空⑤和空⑥为 **V(S8) 和 P(S7)P(S8)**，选 D。

**27. D**｜【操作系统】段页式地址结构
（【存疑：图形复原】地址结构图见原卷 PDF 第 6 页，各段边界位标注为 31、22 | 21、12 | 11、0。）
段号占位 31~22 = **10 位** → 最多 **2¹⁰ = 1024 个段**；页号占位 21~12 = **10 位** → 每个段最多 **2¹⁰ = 1024 个页**；页内地址占位 11~0 = **12 位** → 页大小 **2¹² = 4096 = 4K**。故"最多可有 1024 个段，每个段最大允许有 1024 个页，页的大小为 4K"，选 D。（"最大允许"而非"大小均为"：段内页数随段大小变化。）

**28. C**｜【操作系统】磁盘存取时间
读取一个数据块的时间 = **寻道时间 + 旋转延迟 + 传输时间**。逻辑相邻块平均移动 5 个磁道，每磁道 2ms ⇒ 平均寻道 = 5×2 = **10ms**；旋转延迟 10ms、传输 1ms ⇒ 每块 = 10+10+1 = **21ms**。100 块文件共 **21×100 = 2100ms**，选 C。

**29. B**｜【软件工程】快速原型模型
快速原型模型的优点：通过原型与用户交互**满足真实需求**（A 对）、**加速开发过程、节约成本**（C 对）、**规格说明文档经验证能正确描述需求**（D 对）。但原型模型**不适用于大型软件系统**：大型系统需求复杂、原型难以覆盖全貌、反复废弃原型成本高昂，"适用于大型软件系统的开发"不是其优点，选 B。
> ⚠️ **分歧题**：信管网给 C，系以讹传讹；软考达人、STATICHIT 等多数来源给 B，本题取 B。

**30. C**｜【软件工程】三层 C/S 结构
三层 C/S（表示层/功能层/数据层）允许合理划分功能、提高可维护性与可扩展性（A 对），可灵活选用软硬件平台（B 对），功能层隔离表示层与数据层便于安全管理（D 对）。各层可**并发（并行）开发**，且**可以采用不同的开发语言**（通过接口/标准协议交互），"需要相同的开发语言"错误，选 C。

**31. D**｜【软件工程】耦合类型
模块间通过**外部变量（全局变量、公共数据环境）**交换输入输出信息，属于**公共耦合**：多个模块共享同一公共数据区，一个模块的修改可能波及所有共享该公共区的模块。数据耦合通过参数传值；标记耦合传递数据结构；控制耦合传递控制信息。

**32. C**｜【软件工程】软件质量
高质量软件应：满足用户规定的需求（A 对）、遵循既定开发准则与标准（B 对）、满足可理解性与可维护性等隐含需求（D 对）。但"采用**最新**的开发技术"并非高质量的要求——技术选型应以适用、稳定、可控为原则，盲目追新反而增加风险，C 不属于高质量的内涵，选 C。

**33. B**｜【软件工程】白盒测试覆盖

**47. D**｜【软件工程·设计模式】适配器模式

中序遍历顺序为"左子树→根→右子树"。若中序遍历中 **n 排在 m 之前**，说明 n 在 m **之前被访问**。中序序列中某结点的**右子树中所有结点都在该结点之后被访问**——即 m 若在 n 之后被访问，n 必在 m 的**左子树**中，等价于 **m 在 n 的右边**，选 D。（m 是 n 的祖先或子孙时，n 可能在 m 之前或之后，取决于左右子树位置，故 A、B 不必然成立。）

**62. A**｜【数据结构】折半查找的算法策略
折半查找每比较一次就将搜索区间**对半划分**，在子问题上重复同一策略——这是**分治法**（分解→解决→合并）的典型应用。动态规划需重叠子问题与最优子结构；贪心需贪心选择性质；回溯是穷举解空间。

**64. C**｜【数据结构】Dijkstra 算法策略
Dijkstra 算法每一步都**贪心地**从未确定最短路径的顶点中选取当前距离最小者纳入，并对其邻接边做松弛——体现了**贪心算法**（局部最优逐步构造全局最优）策略。分治需分解为独立子问题；动态规划需记录重叠子问题；回溯是带剪枝的穷举。
