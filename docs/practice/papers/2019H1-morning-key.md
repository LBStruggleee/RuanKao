## 二、逐题解析（含知识点归属）

> 格式：`答案 | 【科目】知识点 | 解析`

**1. A**｜【计算机基础】CPU 组成
CPU 中的**控制器**用于控制整个 CPU 的工作，其功能之一是**产生每条指令的操作信号**并将信号送往相应部件（操作控制功能），以完成指令指定的操作。运算器（ALU）负责算术与逻辑运算；DMA 控制器负责外设与主存间的直接数据传送；Cache 控制器管理高速缓存，都不产生指令操作信号。

**2. C**｜【计算机基础】输入/输出控制方式
DMA（直接存储器存取）方式下，由 DMA 控制器接管总线，在**主存与外设（I/O 设备）**之间直接建立数据通路进行成块数据交换，传送期间不需要 CPU 干预。CPU 与主存之间是系统总线/Cache 通路；CPU 与外设之间是程序查询或中断方式的数据通路。

**3. C**｜【计算机基础】局部性原理
**空间局部性**：一旦程序访问了某个存储单元，其**邻近的存储单元**不久后也可能被访问（数据/指令在内存中连续聚集）。时间局部性指被访问过的单元不久后可能再次被访问；"数据局部性/指令局部性"不是标准表述。

**4. C**｜【计算机基础】系统可靠性
可靠度计算：两部件并联的可靠度为 1-(1-R)(1-R) = 1-(1-R)²；再与第三个部件**串联**得 [1-(1-R)²]·R，正是题给表达式，故为"前两个部件并联后与第三个部件串联"。3 个串联得 R³；3 个并联得 1-(1-R)³；D 的结构为 R·[1-(1-R)²]，与题给式不符。

**5. D**｜【计算机基础】校验码
**循环冗余校验（CRC）**在求编码时采用**模 2 运算**（模 2 除法/加法，即异或）来构造校验位。奇偶校验（水平/垂直）用模 2 加求奇偶性但"构造校验位"的典型表述指 CRC 的生成多项式除法；海明码使用多重奇偶校验分组，不是模 2 运算构造校验位。

**6. B**｜【计算机基础】CISC 与 RISC
"**指令功能强大、寻址方式复杂多样**"是 **CISC** 的特点，不是 RISC 的，故 B 叙述错误、选 B。RISC 的特点：指令长度固定、指令种类少、寻址方式简单、大量通用寄存器、硬布线控制、适合流水线（A、C、D 均为 RISC 特点）。

**7. B**｜【网络·信息安全】防火墙
**应用级网关（应用层防火墙）**工作在应用层，是内部网与外部网的隔离点，可对应用层的通信数据流进行监控和过滤。包过滤工作在网络层、只检查 IP/端口；数据库防火墙针对数据库流量；Web 防火墙（WAF）针对 Web 入侵防御。

**8. C**｜【网络·信息安全】安全协议
**MIME** 是多用途互联网邮件扩展，规定邮件**内容格式**（非 ASCII 文本、附件、多部分消息体），**与安全无关**，选 C。SSL 为数据通信提供加密（A 有关）；HTTPS = HTTP+SSL，是安全超文本传输（B 有关）；PGP 是基于 RSA 的邮件加密与数字签名软件（D 有关）。

**9. A / 10. D**｜【网络·信息安全】认证与不可否认
（9）**数字证书**由 CA 签发，用于**身份认证**（把公钥与持有者身份绑定）。排除：消息加密保证机密性、用户私钥用于签名/解密而非认证、数字签名用于不可否认。
（10）**数字签名**用私钥对信息签名，因私钥仅签名人拥有，可**确保消息不可否认**。数字证书用于认证不实现不可否认本身；消息加密保证机密性。

**11. D**｜【网络·信息安全】恶意代码类型
震网（Stuxnet）是一种**蠕虫病毒**：利用 Windows 系统漏洞自我传播并攻击西门子工业控制系统（PLC），无需用户干预即可通过网络扩散。选 D。（引导区病毒感染 MBR；宏病毒感染文档；木马伪装成合法程序但不自我复制。）

**12. B**｜【知识产权】职务发明
《专利法》第 6 条：**主要利用本单位的物质技术条件**（实验材料、实验室、不对外公开的技术资料）所完成的发明创造为**职务发明**，申请专利的权利属于单位；但"利用本单位的物质技术条件所完成的发明创造，单位与发明人**订有合同**对归属作出约定的，**从其约定**"。故 B"原则上归单位，有特别约定时遵从约定"最准确。A、D 太绝对；C 混淆了"执行本单位任务"与"利用物质技术条件"两种职务发明情形。

**13. A / 14. B**｜【知识产权】著作权与商标权
（13）购买正版软件后可安装使用并制作备份复制品，但**备份复制品不得通过任何方式提供给他人使用**，转让正版软件时应销毁复制品。甲公司向客户提供工具软件复制品，**侵犯了工具软件的著作权**，选 A（不涉及专利权，也未到不正当竞争程度）。
（14）我国对商标实行**申请在先（注册）原则**：未经注册的商标原则上不受保护。甲公司未注册"恒友"，乙公司将其注册，其行为**不构成侵权行为**，选 B。乙公司反而是取得商标权后可依法维权的一方。
> ⚠️ **分歧题**：部分网文给 14 题 A（侵犯了商标权），系误将"甲公司先使用"当作在先权利；解析书给 **B**，本文从之。

**15. B**｜【软件工程】数据流图（DFD）建模
DFD 是描述数据流从输入到输出变换流程的核心分析模型，建模即理解需求的过程，应遵循"**自顶向下、从抽象到具体**"的原则，构建一组分层的数据流图。选 B（A、C 把抽象层次关系搞反；D 自底向上不适合需求建模）。

**16. D**｜【软件工程】结构图基本成分
结构图（模块结构图）的基本成分包括**模块、调用和数据**（另有转接符号）。**控制**不是结构图的基本成分，故"不包括"的是 D。

**17. D**｜【软件工程·项目管理】沟通路径
n 个成员两两之间都有沟通路径，相当于完全图的边数 = **n(n-1)/2 = 10×9/2 = 45** 条。选 D。

**18. D**｜【软件工程·项目管理】关键路径（AOE 网）
（【存疑：图形复原】活动表见 `2019H1-morning-questions.md` 第 18 题，已核对与原卷一致。）
按依赖关系计算各活动最早完成时间 EF：A1=8；A2=15；A3=8+15=23；A4=10；A5=max(A2,A4)+10=25；A6=max(A1,A2)+5=20；A7=8+20=28；A8=10+25=35；A9=max(A3,A6)+15=38；A10=max(A5,A7)+15=43；A11=38+7=45；A12=max(A8,A10,A11)+10=45+10=**55**。

**19. A**｜【软件工程·项目管理】风险概念
风险是"带来**负面后果**的不确定性"。团队成员**可以进行良好沟通**是积极因素、不是风险，选 A。B（离职）、C（缺乏培训）、D（招不到人）都是常见的项目人员风险。

**20. A**｜【程序设计语言】控制结构
程序（算法）的三种基本控制结构为**顺序、分支（选择）、循环**。选 A。递归/递推是实现方式而非基本控制结构；函数是程序组织单位。

**21. C**｜【程序设计语言】编译过程
**语法分析**阶段在词法分析基础上，根据语法规则把单词符号序列分解为各类语法单位（表达式、语句等），并对**语句结构的合法性**进行分析。词法分析识别单词；语义分析检查静态语义错误；目标代码生成在最后。

**22. B**｜【程序设计语言】符号表
编译过程中需要不断收集、记录和使用源程序中符号的类型与特征等信息，存入**符号表**。符号表辅助语义检查与代码生成，可能从词法阶段建立并使用到运行阶段。选 B。

**23. A / 24. C**｜【操作系统】进程状态与调度
单处理机 + 先来先服务。若 P1 **时间片到**，调度程序将 P1 改为**就绪**、从就绪队列选 P2 投入**运行**，P3（等打印机）、P4（等扫描仪）仍为**等待**，故四进程状态为"**就绪、运行、等待、等待**"=（24）C。
排除（24）A：无进程处于运行状态，与单处理机必有进程运行矛盾；B：两个进程运行不可能；D：若 P1 释放扫描仪应唤醒 P4 而非 P4 仍等待且 P1 不会变就绪。
（23）若选 B"释放扫描仪"，P4 应被唤醒为就绪，不匹配 C；若选 C"释放打印机"，P3 被唤醒为就绪，也不匹配 C；若选 D"已完成"，P1 应为完成（非就绪）。只有 A 时间片到与 C 组合自洽。

**25. C**｜【操作系统】位示图
磁盘物理块数 = 1024×1024 MB ÷ 4 MB = **262144** 块；每字 64 位可记录 64 个块，位示图大小 = 262144 ÷ 64 = **4096** 个字。选 C。

**26. C**｜【操作系统】文件路径
（【存疑：图形复原】目录树：根 MyDrivers，其下有 user1、user2 等子目录，user2 下为 book2.doc。）
**绝对路径**从根目录开始：`\MyDrivers\user2\`；**相对路径**从当前工作目录 MyDrivers 开始：`user2\`。组合为"\MyDrivers\user2\ 和 user2\"= C。A、D 的绝对路径缺根的 `\`；B 的相对路径误加 `\`（变成从根出发）。

**27. B**｜【操作系统】PV 操作
PV 操作可实现进程的**同步与互斥**，其中**互斥使用临界资源**是其基本功能之一，选 B。但 PV 操作使用不当**可能导致死锁**（A 错）；它本身不直接"提高资源利用率"（C 是同步互斥的间接效果）；"推迟进程使用共享资源"不是其目的（D 错）。

**28. A**｜【操作系统】嵌入式操作系统特点
嵌入式操作系统特点包括微型化、**可定制**、实时性、可靠性、易移植性。其中**可定制**指"从减少成本和缩短研发周期考虑，要求嵌入式操作系统能运行在不同微处理器平台上，能针对硬件变化进行结构与功能上的配置"，正是题干描述，选 A。（易移植性强调代码移植的难易，不含"按需配置结构功能"的含义。）

**29. C**｜【软件工程】系统原型
原型可帮助导出并验证需求（A）、探索特殊解决方案（B）、支持用户界面设计（D）。但**原型用于需求与界面层面，不用于"指导代码优化"**，故 C 不正确、选 C。

**30. B**｜【软件工程】极限编程（XP）最佳实践
XP 强调**测试优先（先写测试代码再写程序）**，"编写完程序之后编写测试代码"违背该实践，故 B 不正确、选 B。A（简单设计/只处理当前需求）、C（持续集成/小版本可按日交付）、D（现场客户全程配合）均为 XP 最佳实践。

**31. A**｜【软件工程】ISO/IEC 9126 质量模型
ISO/IEC 9126 中，**功能性**特性包含的质量子特性有**安全性**（suitability、accuracy、interoperability、security）。故选 A。（可靠性含容错性、易恢复性等；效率含时间特性、资源特性；可维护性含易分析性、易改变性等。）

**32. D**｜【软件工程】模块耦合
两模块间传递的是**数据结构**（整体传送），属于**标记耦合**，选 D。数据耦合传递的是简单数据值（值传递）；公共耦合是共享公共数据区；外部耦合是通过软件之外的环境（设备、格式、协议）联结。

**33. B**｜【软件工程】界面设计黄金准则
Theo Mandel 的三条"黄金准则"为：**用户操纵控制、减轻用户的记忆负担、保持界面一致**。**界面美观整洁**不在其中，故"不包括"的是 B。

**34. D**｜【软件工程】软件测试
A 错：穷举测试不可能；B 错：错误多的程序段修改后往往仍引入新错误；C 错：测试是为了**发现**错误而非证明软件无错。D 正确：白盒测试中**路径覆盖是最强的覆盖、语句覆盖最弱**，路径覆盖往往比语句覆盖发现更多错误。

**35. C**｜【软件工程】测试用例设计
好的测试用例应能定位错误。A 各条件均符合规格说明（有效等价类）；B、D 各有**一个**条件不符合（年龄 18<20；专业生物学不在范围内），是检验边界处理的有效用例；C 有**两个**条件不符合（年龄 18 不符 + 学历大专不符），冗余且不能更有效地定位错误，**不是好的测试用例**，选 C。

**36. C**｜【软件工程】软件维护类型
交付使用后为**改善性能**（提升响应速度）而修改算法，属于**完善性/改善性维护**，选 C。改正性维护改错误；适应性维护适应环境变化；预防性维护为提高可维护性而主动修改。

**50. B**｜【程序设计语言】引用调用与值调用
