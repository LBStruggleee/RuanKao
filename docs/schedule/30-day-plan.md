# 30天详细备考日程表

> ⏰ 每日建议学习时长：6-8小时
> 📝 每完成一天学习，在对应日期后打 ✅

---

## 第一阶段：核心知识体系搭建（Day 1-10）

### Day 1 - 数据结构基础：线性表
- [ ] 学习目标：数组、链表（单向/双向/循环）的存储结构与操作
- [ ] 学习内容：
  - 顺序表：插入、删除的时间复杂度
  - 链表：头插法、尾插法、反转
  - 栈和队列的基本操作
- [ ] 刷题：15道选择题（线性表相关）
- [ ] 笔记：整理线性表操作的时间复杂度表

### Day 2 - 数据结构：树
- [ ] 学习目标：二叉树的遍历（前序/中序/后序/层序）、二叉搜索树、平衡二叉树
- [ ] 学习内容：
  - 二叉树5种基本形态
  - 遍历算法（递归+非递归）
  - 哈夫曼树与哈夫曼编码
- [ ] 刷题：15道选择题（树相关）
- [ ] 笔记：手绘各种遍历顺序示意图

### Day 3 - 数据结构：图
- [ ] 学习目标：图的存储结构、遍历算法、最小生成树、最短路径
- [ ] 学习内容：
  - 邻接矩阵 vs 邻接表
  - DFS和BFS
  - Prim算法和Kruskal算法
  - Dijkstra算法
- [ ] 刷题：15道选择题（图相关）
- [ ] 笔记：整理各算法伪代码和复杂度

### Day 4 - 数据结构：排序与查找
- [ ] 学习目标：常见排序算法和查找算法
- [ ] 学习内容：
  - 排序：冒泡、选择、插入、快速、归并、堆排序
  - 查找：顺序查找、折半查找、哈希查找
  - 时间复杂度对比表
- [ ] 刷题：15道选择题（排序查找相关）
- [ ] 笔记：排序算法对比表（稳定性、复杂度）

### Day 5 - 操作系统（一）：进程管理
- [ ] 学习目标：进程与线程、进程状态转换、PV操作
- [ ] 学习内容：
  - 进程五状态模型
  - 线程与进程的区别
  - 信号量与PV操作（重点！）
  - 经典同步问题（生产者消费者、读者写者）
- [ ] 刷题：15道选择题 + 1道PV操作大题
- [ ] 笔记：整理PV操作解题模板

### Day 6 - 操作系统（二）：内存管理
- [ ] 学习目标：分页、分段、虚拟内存
- [ ] 学习内容：
  - 页式存储：页表、地址转换
  - 段式存储
  - 页面置换算法（FIFO/LRU/OPT/Clock）
  - 缺页中断
- [ ] 刷题：15道选择题 + 1道计算题
- [ ] 笔记：地址转换计算步骤整理

### Day 7 - 操作系统（三）：磁盘调度与文件系统
- [ ] 学习目标：磁盘调度算法、文件组织方式
- [ ] 学习内容：
  - FCFS、SSTF、SCAN、C-SCAN
  - 文件的逻辑/物理结构
  - 索引文件
- [ ] 刷题：10道选择题 + 复习错题
- [ ] 总结：整理本周错题

### Day 8 - 计算机网络（一）：协议与模型
- [ ] 学习目标：OSI七层模型、TCP/IP四层模型
- [ ] 学习内容：
  - 各层协议与功能
  - 封装/解封装过程
  - 常见协议：HTTP/HTTPS/FTP/SMTP/DNS
- [ ] 刷题：15道选择题（网络基础）
- [ ] 笔记：画OSI与TCP/IP对照表

### Day 9 - 计算机网络（二）：TCP/IP深入
- [ ] 学习目标：TCP三次握手/四次挥手、拥塞控制、子网划分
- [ ] 学习内容：
  - TCP连接管理
  - 滑动窗口
  - 子网划分计算（重点！）
  - CIDR
- [ ] 刷题：15道选择题（TCP/子网划分）
- [ ] 笔记：子网划分计算模板

### Day 10 - 第一阶段复习日
- [ ] 复习Day 1-9所有笔记
- [ ] 做一套基础知识模拟卷（选择题部分）
- [ ] 整理薄弱知识点，列入重点复习清单
- [ ] 📊 记录：模拟卷得分

## 第二阶段：深入学习+真题训练（Day 11-20）

### Day 11 - 数据库系统（一）：关系模型与SQL
- [ ] 学习目标：关系代数、SQL查询语句
- [ ] 学习内容：

- [ ] 学习内容：

- [ ] 刷题：15道选择题 + 1道E-R图大题
- [ ] 笔记：范式判断流程图

### Day 13 - 软件工程（一）：过程与模型

- [ ] 学习内容：

  - UML用例图
- [ ] 刷题：15道选择题（软件工程基础）

### Day 14 - 软件工程（二）：设计原则与测试
- [ ] 学习目标：设计原则、测试方法

- [ ] 刷题：15道选择题（设计+测试）
- [ ] 笔记：测试覆盖类型总结

### Day 15 - 计算机组成与体系结构
- [ ] 学习目标：CPU结构、指令系统、存储体系
- [ ] 学习内容：
  - CPU组成：ALU/控制器/寄存器
  - 指令格式与寻址方式
  - Cache原理
  - 流水线
- [ ] 刷题：15道选择题（组成原理）
- [ ] 笔记：Cache映射方式对比
