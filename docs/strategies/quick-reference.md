## 🔴 数据结构（必考）

### 链表反转
```
prev = null, curr = head
while curr != null:
    next = curr.next
    curr.next = prev
    prev = curr
    curr = next
return prev
```

### 二叉树遍历
- 前序：根左右
- 中序：左根右
- 后序：左右根
- 层序：逐层

### 排序算法复杂度
- 快速排序：平均O(nlogn)，最坏O(n²)
- 归并排序：O(nlogn)稳定
- 堆排序：O(nlogn)不稳定

### 哈希表
- 查找O(1)平均
- 冲突解决：链地址法、开放地址法

## 🔴 操作系统（必考）

### PV操作模板
```
P(S): S--; if(S<0) block
V(S): S++; if(S<=0) wakeup
```

### 死锁条件
互斥 + 占有且等待 + 不可剥夺 + 循环等待

### 页面置换
- LRU：最近最少使用（常用）
- FIFO：先进先出
- OPT：最佳（理论）
