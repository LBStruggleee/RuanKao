# 备考资料推荐与索引

## 一、官方资料

### 1. 考试大纲
- **来源**：中国计算机技术职业资格网（www.ruankao.org.cn）
- **用途**：了解考试范围和重点，是备考的根本依据
- **建议**：打印出来放在书桌前，每天对照

### 2. 指定教材
- **《软件设计师教程》（第5版）** - 清华大学出版社
  - 官方指定教材，覆盖所有考点
  - 建议作为主要参考，但不需要逐字阅读

## 四、学习资源获取方式

### 快速获取真题
```
1. 访问中国计算机技术职业资格网
2. 下载历年真题PDF
3. 打印或导入刷题APP
```

### 视频学习路径
```
1. B站搜索"软考软件设计师"
2. 按章节顺序观看
3. 倍速1.5x-2x
4. 暂停做笔记
```

## 五、资料使用原则

1. **真题优先**：任何资料都不能替代真题
2. **一书多用**：教材+真题结合，不要买太多书
3. **电子化**：善用PDF和APP，利用碎片时间
4. **及时更新**：关注考试大纲是否有变化
