# 数据库系统 - 知识点精讲

## 一、关系模型基础

### 1.1 基本概念
- **关系**：一张二维表
- **元组**：一行记录
- **属性**：一列字段
- **码（键）**：能唯一标识元组的属性组合
  - 候选码：最小的超码
  - 主码：选定的候选码
  - 外码：引用其他关系的主码

### 1.2 关系运算
- **选择（σ）**：从表中选出满足条件的行
- **投影（π）**：从表中选出指定的列
- **连接（⋈）**：两个表的笛卡尔积中满足条件的元组
- **除（÷）**：用于查询包含所有...的元组

## 二、SQL语言

### 2.1 SQL基础语法

#### SELECT查询
```sql
SELECT 列名1, 列名2, ...
FROM 表名
WHERE 条件
GROUP BY 分组列
HAVING 分组条件
ORDER BY 排序列 ASC/DESC;
```

#### 执行顺序
FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY

### 2.2 常见SQL操作

#### 聚合函数
- COUNT()：计数
- SUM()：求和
- AVG()：平均值
- MAX()：最大值
- MIN()：最小值

#### 多表连接
```sql
-- 内连接
SELECT * FROM A INNER JOIN B ON A.id = B.a_id;

-- 左连接
SELECT * FROM A LEFT JOIN B ON A.id = B.a_id;

-- 自连接
SELECT * FROM A a1, A a2 WHERE a1.pid = a2.id;
```

#### 子查询
```sql
-- WHERE子查询
SELECT * FROM Students WHERE score > (SELECT AVG(score) FROM Students);

-- FROM子查询
SELECT T.name FROM (SELECT * FROM Students WHERE score > 60) T;

-- EXISTS子查询
SELECT * FROM Students S WHERE EXISTS (SELECT * FROM Courses WHERE sid = S.id);
```

### 2.3 SQL重点题型
- 多表连接查询
- 分组统计 + HAVING过滤
- 子查询（相关/不相关）
- 嵌套查询
- UNION合并结果

## 三、数据库设计

### 3.1 E-R模型

#### 基本要素
- **实体**：用矩形表示
- **属性**：用椭圆表示
- **联系**：用菱形表示
  - 1:1（一对一）
  - 1:n（一对多）
  - m:n（多对多）

#### E-R图转换为关系模式
- 1:1联系：任一方加对方主键为外码
- 1:n联系：n方加1方主键为外码
- m:n联系：新建关系，包含双方主键

### 3.2 范式

#### 第一范式（1NF）
- 所有属性都是原子性的（不可再分）

#### 第二范式（2NF）
- 满足1NF
- 非主属性完全依赖于主码（消除部分依赖）

#### 第三范式（3NF）
- 满足2NF
- 非主属性不传递依赖于主码（消除传递依赖）

#### BCNF
- 所有非平凡函数依赖 X→Y，X都包含码

#### 范式判断方法
1. 找出所有函数依赖
2. 找出候选码
3. 判断依赖类型：
   - 部分依赖 → 不满足2NF
   - 传递依赖 → 不满足3NF

## 四、数据库事务

### 4.1 ACID特性
- **A（原子性）**：事务要么全做，要么全不做
- **C（一致性）**：事务执行前后数据状态一致
- **I（隔离性）**：并发事务互不干扰
- **D（持久性）**：事务提交后永久保存

### 4.2 并发问题
| 问题 | 描述 | 解决级别 |
|------|------|---------|
| 脏读 | 读到未提交的数据 | READ COMMITTED |
| 不可重复读 | 同一查询结果不同 | REPEATABLE READ |
| 幻读 | 读到新增/删除的行 | SERIALIZABLE |

### 4.3 封锁协议
- **共享锁（S锁）**：读操作
- **排他锁（X锁）**：写操作
- **两段锁协议**：扩展阶段 + 收缩阶段

## 五、数据库索引

### 5.1 索引类型
- **聚簇索引**：物理排序，每个表只有一个
- **非聚簇索引**：逻辑排序，可以多个
- **B+树索引**：数据库默认索引结构

### 5.2 索引优缺点
- **优点**：加快查询速度
- **缺点**：减慢插入/更新/删除速度，占用空间

### 5.3 适合建索引的列
- WHERE条件频繁使用的列
- JOIN连接条件列
- ORDER BY/GROUP BY列

### 6.2 E-R图转关系模式
