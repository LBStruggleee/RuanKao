# 数据结构与算法 - 知识点精讲

## 一、线性表

### 1.1 顺序表（数组）
- **存储**：连续内存空间
- **插入**：平均移动 n/2 个元素，时间复杂度 O(n)
- **删除**：平均移动 n/2 个元素，时间复杂度 O(n)
- **查找**：顺序查找 O(n)，折半查找 O(log₂n)（要求有序）

### 1.2 链表
- **单向链表**：每个节点含数据和指向下一节点的指针
- **双向链表**：每个节点含前驱和后继指针
- **循环链表**：尾节点指向头节点

#### 常见操作
| 操作 | 单链表时间复杂度 |
|------|----------------|
| 查找 | O(n) |
| 插入（已知位置） | O(1) |
| 删除（已知位置） | O(1) |
| 插入（头插法） | O(1) |

#### 链表经典操作
- **反转链表**：三指针法（prev, curr, next）
- **找中间节点**：快慢指针
- **判断环**：快慢指针
- **合并有序链表**：归并思想

### 1.3 栈（Stack）
- **特性**：后进先出（LIFO）
- **应用**：括号匹配、表达式求值、递归调用
- **顺序栈和链栈**

### 1.4 队列（Queue）
- **特性**：先进先出（FIFO）
- **循环队列**：解决顺序队列的假溢出
- **双端队列**：两端都可进出

## 二、树

### 2.1 二叉树基础
- **性质**：
  - 第i层最多 2^(i-1) 个节点
  - 深度为k的二叉树最多 2^k - 1 个节点
  - 叶子节点数 = 度为2的节点数 + 1

### 2.2 二叉树遍历
| 遍历方式 | 顺序 | 应用 |
|---------|------|------|
| 前序遍历 | 根→左→右 | 复制树、表达式 |
| 中序遍历 | 左→根→右 | BST排序结果 |
| 后序遍历 | 左→右→根 | 删除树、计算大小 |
| 层序遍历 | 逐层从左到右 | BFS |

### 2.3 二叉搜索树（BST）
- 左子树所有节点 < 根节点
- 右子树所有节点 > 根节点
- 中序遍历得到有序序列
- 查找、插入、删除平均 O(log₂n)

### 2.4 平衡二叉树（AVL）
- 左右子树高度差不超过1
- 插入/删除后可能需要旋转
- 旋转类型：LL、RR、LR、RL

### 2.5 哈夫曼树
- **带权路径长度（WPL）**最小
- **构造方法**：每次选两个最小权值节点合并
- **应用**：数据压缩、编码
- **编码规则**：左0右1（或左1右0）

## 三、图

### 3.1 基本概念
- **有向图 vs 无向图**
- **度**：无向图-相连边数；有向图-入度+出度
- **连通图**：无向图中任意两点可达
- **强连通图**：有向图中任意两点互相可达

### 3.2 存储结构
- **邻接矩阵**：V×V矩阵，适合稠密图
- **邻接表**：每个节点的邻居链表，适合稀疏图

### 3.3 遍历算法
- **DFS（深度优先）**：栈实现/递归
- **BFS（广度优先）**：队列实现

### 3.4 最小生成树
- **Prim算法**：从一点开始，每次选最小边（适合稠密图）
- **Kruskal算法**：从小到大选边，不形成环（适合稀疏图）

### 3.5 最短路径
- **Dijkstra算法**：单源最短路径（无负权边）
- **Floyd算法**：所有顶点对最短路径

## 四、排序算法

### 4.1 排序算法对比表
| 算法 | 最好 | 平均 | 最坏 | 空间 | 稳定性 |
|------|------|------|------|------|--------|
| 冒泡排序 | O(n) | O(n²) | O(n²) | O(1) | 稳定 |
| 选择排序 | O(n²) | O(n²) | O(n²) | O(1) | 不稳定 |
| 插入排序 | O(n) | O(n²) | O(n²) | O(1) | 稳定 |
| 快速排序 | O(nlogn) | O(nlogn) | O(n²) | O(logn) | 不稳定 |
| 归并排序 | O(nlogn) | O(nlogn) | O(nlogn) | O(n) | 稳定 |
| 堆排序 | O(nlogn) | O(nlogn) | O(nlogn) | O(1) | 不稳定 |

### 4.2 重点算法
- **快速排序**：分治思想，选基准值，分区递归
- **归并排序**：分治思想，分裂后合并
- **堆排序**：大顶堆/小顶堆

## 五、查找算法

### 5.1 顺序查找
- 适用：无序表
- 时间复杂度：O(n)

### 5.2 折半查找
- 适用：有序顺序表
- 时间复杂度：O(log₂n)
- 判定树深度 = ⌈log₂(n+1)⌉

### 5.3 哈希查找
- **哈希函数构造**：除留余数法、平方取中法
- **冲突解决**：开放地址法（线性探测/二次探测）、链地址法
- **平均查找长度**：取决于装填因子

## 六、算法分析

### 时间复杂度计算
- 顺序结构：取最大
- 循环结构：看循环次数
- 嵌套循环：内外层相乘
- 递归：递归方程（主定理）

### 常见时间复杂度排序
O(1) < O(logn) < O(n) < O(nlogn) < O(n²) < O(n³) < O(2ⁿ) < O(n!)

## 七、树与二叉树遍历（补漏）

### 7.1 四种遍历的递归定义与实现

| 遍历 | 顺序 | 递归式 | 非递归实现 | 典型应用 |
|------|------|--------|-----------|---------|
| 先序（Pre） | 根 → 左 → 右 | 访根;Pre(L);Pre(R) | 栈（访问后先压右再压左） | 复制树、序列化、表达式前缀 |
| 中序（In） | 左 → 根 → 右 | In(L);访根;In(R) | 栈（一路左压栈） | **BST 排序结果**、表达式中缀 |
| 后序（Post） | 左 → 右 → 根 | Post(L);Post(R);访根 | 栈（双栈法或记录上次访问） | 释放树、计算高度/大小、表达式后缀 |
| 层序（Level） | 逐层、从左到右 | —— | **队列**（出队即访问，左右孩子入队） | BFS、求树宽、按层打印 |

- 四种遍历的时间复杂度均为 **O(n)**（每个节点访问一次），空间复杂度 O(h)（递归栈深度 = 树高，最坏 O(n)）。
- ⚠️ **非递归后序遍历最难**：栈中弹出节点时，若它有右孩子且右孩子**还没被访问**，必须把当前节点重新压回并转向右子树——直接弹出会变成"根右左"的中序镜像。

### 7.2 由遍历序列重建二叉树（核心考点）

**唯一性结论（必背）：**

| 已知序列 | 能否唯一确定二叉树 |
|---------|-------------------|
| 先序 + 中序 | ✅ 能 |
| 后序 + 中序 | ✅ 能 |
| 层序 + 中序 | ✅ 能 |
| **先序 + 后序** | ❌ **不能**（除非每个非叶子节点都有两个孩子，即"真二叉树"） |
| 单一序列 | ❌ 不能——除非**附带空节点标记**（此时任意一种遍历都能唯一重建，见下） |

> 补充：若把空子树也当作"节点"输出（如先序 `A B D ∅ ∅ E ∅ ∅ C ∅ F ∅ ∅`），则**单一序列**就能唯一重建二叉树——这就是"序列化/反序列化"的原理。考试中若无空节点标记，则必须靠两种序列（且含中序）。

> ⚠️ **易错点 1**：重建二叉树**必须要有中序**——中序提供"左右子树分界"，先/后/层序只提供"根是谁"。题目问"下列哪两组序列不能唯一确定二叉树"，答案永远是**不含中序的那一组**。
> ⚠️ **易错点 2**：先序 + 后序不能唯一确定的反例——两个节点的树 `A(B, ∅)` 和 `A(∅, B)` 的先序都是 `AB`、后序都是 `BA`，但是两棵不同的树。

**重建算法模板（先序 + 中序）：**
1. 先序序列的**第一个元素**是根；
2. 在中序序列中定位根，根**左边**的子序列 = 左子树中序，**右边** = 右子树中序；
3. 用左子树的长度 `L`，从先序序列中截出左子树先序（根之后的 `L` 个）、其余为右子树先序；
4. 对左右子树递归。

后序 + 中序同理：后序序列的**最后一个元素**是根。

**完整例题：** 已知先序 `A B D E C F`，中序 `D B E A C F`，画出二叉树并写出后序与层序。

```
第 1 轮：先序首元 A = 根；中序中 A 左边 [D B E] = 左子树(3 个)，右边 [C F] = 右子树(2 个)
        先序截取：左子树先序 = B D E，右子树先序 = C F
第 2 轮（左）：先序首元 B = 根；中序 D B E 中 B 左边 [D] = 左，右边 [E] = 右
        → B 的左孩子 = D，右孩子 = E
第 3 轮（右）：先序首元 C = 根；中序 C F 中 C 左边 [] = 空，右边 [F] = 右
        → C 的左孩子 = 空，右孩子 = F

结果：
        A
       / \
      B   C
     / \   \
    D   E   F
```

- **后序**：D → E → B → F → C → A（即 `D E B F C A`）
- **层序**：A → B → C → D → E → F（即 `A B C D E F`）
- **验证技巧**：重建后立刻用"中序的左根右"扫一遍核对：D B E A C F ✓。

**派生考法（高频）：** 不画树，直接由先序 + 中序**口算后序**。诀窍：先序从左往右依次是"根、左子树的根、右子树的根……"，配合中序的分界不断切分即可。上面这道题的后序 `D E B F C A` 必须能在 30 秒内写出。

### 7.3 遍历与表达式树

| 遍历 | 对应表达式 | 注意 |
|------|-----------|------|
| 先序 | **前缀**表达式（波兰式） | 运算符在操作数前 |
| 中序 | **中缀**表达式 | ⚠️ 中序**不保证括号正确**，需人为补括号才能还原运算优先级 |
| 后序 | **后缀**表达式（逆波兰式） | 计算机求值最常用，用**栈**：遇到操作数压栈、遇到运算符弹两个计算 |

- **中序遍历 BST 得到升序序列**——这是"二叉搜索树 ⟺ 中序有序"的判据，也是"判断一棵树是否为 BST"的标准做法（比"只比较左右孩子"更可靠，因为要保证**整棵子树**满足大小关系）。

### 7.4 线索二叉树（易漏点）

- n 个节点的二叉树有 **2n 个指针域**，其中 **n−1 个指向孩子**，故有 **n+1 个空指针域**。
- 线索化：把空指针域改成指向前驱/后继（中序线索最常用）。ltag/rtag = 0 表示指向孩子，= 1 表示指向线索。
- ⚠️ **中序线索化后，找某节点中序后继**：若其右指针是线索，直接跟过去；否则**去右子树的最左下角节点**。

## 八、图算法（补漏）

### 8.1 图的遍历 DFS / BFS

| | DFS（深度优先） | BFS（广度优先） |
|---|---|---|
| 数据结构 | **栈**（或递归） | **队列** |
| 邻接矩阵时间 | O(V²) | O(V²) |
| 邻接表时间 | **O(V+E)** | **O(V+E)** |
| 空间 | O(V)（递归深度） | O(V)（队列） |
| 生成树 | DFS 生成树（细长） | BFS 生成树（矮宽） |
| 典型应用 | 连通分量、拓扑排序、环检测、求割点 | **无权图最短路径（边数最少）**、层次遍历 |

- ⚠️ **BFS 求出的就是无权图的最短路径**（按层扩展，先到者路径最短）。带权图必须用 Dijkstra/Floyd。
- ⚠️ 遍历序列**取决于存储结构**：同一个图，邻接矩阵的遍历序列由顶点编号顺序决定，邻接表由边表链入顺序决定。所以"写出 DFS 序列"的题目必须给定存储结构。

### 8.2 最短路径

**Dijkstra（单源最短路径，贪心）：**

```
1. 初始化：源点 s 的 dist[s] = 0，其余 dist = ∞；集合 S = {s}
2. 从未确定集合 V−S 中选 dist 最小的顶点 u，加入 S
3. 对 u 的每条出边 (u,v,w)：若 dist[u]+w < dist[v]，则更新 dist[v]（"松弛"）
4. 重复 2-3，直到所有顶点入 S
```

- 时间复杂度：**O(V²)**（数组实现）；**O((V+E)log V)**（优先队列/堆）。
- ⚠️ **不能处理负权边**：算法的贪心正确性依赖"已入 S 的顶点 dist 不会再被减小"，负权边可能违反这个假设。要处理负权必须用 **Bellman-Ford（O(VE)）**。
- Dijkstra 也可以**输出最短路径本身**：每次松弛时记录 `path[v] = u`，最后从终点沿 path 回溯到源点。

**Dijkstra 手算例题：**

```
源点 V1，边（无向）：
V1-V2: 10   V1-V5: 100   V2-V3: 50   V3-V5: 10   V4-V5: 60   V3-V4: 20   V2-V5: 30

轮次  选点      更新过程                                   各点 dist
 1    V1(0)    松弛 V2→10, V5→100                         V2:10  V3:∞  V4:∞  V5:100
 2    V2(10)   松弛 V3→10+50=60, V5→min(100, 10+30=40)=40  V3:60  V4:∞  V5:40
 3    V5(40)   松弛 V4→40+60=100, V3→min(60, 40+10=50)=50  V3:50  V4:100
 4    V3(50)   松弛 V4→min(100, 50+20=70)=70               V4:70
 5    V4(70)   无更新

结果：V1→V2=10, V1→V5=40(V1→V2→V5), V1→V3=50(V1→V2→V5→V3), V1→V4=70(V1→V2→V5→V3→V4)
```

> ⚠️ **最典型错误**：第 2 轮就把 V5 定成 100（认为源点直接连的边最短），忘记后续中转可能更短——这正是 Dijkstra 每轮只锁定**一个**最小顶点的原因。

**Floyd（全源最短路径，动态规划）：**

- 状态：`d[k][i][j]` = 只允许经过顶点 {1..k} 时，i 到 j 的最短路径长度。
- 转移：`d[k][i][j] = min(d[k−1][i][j], d[k−1][i][k] + d[k−1][k][j])`。
- 三重循环 **O(V³)**，空间可优化到 O(V²)（滚动掉第一维，原地更新）。
- ⚠️ Floyd **可以处理负权边，但不能有负权回路**（有负回路时最短路径无下界）。
- ⚠️ **Floyd 的 k 循环必须在最外层**——写成 `for(i) for(j) for(k)` 是错的，那样不是动态规划的正确递推顺序。

| 算法 | 源 | 时间 | 负权边 | 负权回路 |
|------|----|------|--------|----------|
| Dijkstra | 单源 | O(V²) | ❌ 不支持 | ❌ |
| Bellman-Ford | 单源 | O(VE) | ✅ 支持 | 可检测并报告 |
| Floyd | 全源 | O(V³) | ✅ 支持 | ❌ 不允许 |

### 8.3 最小生成树（MST）

- **生成树**：连通图的极小连通子图，n 个顶点 + **n−1 条边**。
- MST 的权值之和最小。⚠️ **MST 不唯一**——只有当图中**所有边权互不相同时 MST 才唯一**。

| | Prim | Kruskal |
|---|---|---|
| 策略 | 从某顶点出发，每次选**连接已选集合与未选集合**的最小权边 | 把所有边按权值**从小到大排序**，依次选不构成环的边 |
| 数据结构 | 顶点集合 + lowcost 数组 | **并查集**（判连通/成环） |
| 时间 | **O(V²)**（邻接矩阵，适合稠密图） | **O(E log E)**（排序主导，适合稀疏图） |
| 适用 | 稠密图 | 稀疏图 |
| 结果 | 从任意起点开始，**MST 权值相同** | 与起点无关 |

**Prim 手算例题：** 顶点 {A,B,C,D}，无向边：AB=4, AC=3, BC=1, BD=2, CD=5

```
从 A 出发，已选 S={A}，候选边（S→V−S 取最小）：
 轮1: 候选 AB=4, AC=3        → 选 AC=3，S={A,C}
 轮2: 候选 AB=4, CB=1, CD=5  → 选 CB=1，S={A,C,B}
 轮3: 候选 BD=2, CD=5        → 选 BD=2，S={A,C,B,D}
MST = {AC, CB, BD}，权值 = 3+1+2 = 6
```

**Kruskal 手算例题（同一图）：**

```
边排序：BC=1 < BD=2 < AC=3 < AB=4 < CD=5
 BC=1: B,C 不连通 → 加入（并查集合并 B,C）
 BD=2: B,D 不连通 → 加入（合并 B,D，现 B,C,D 同集合）
 AC=3: A,C 不连通 → 加入（A 并入，全部连通）
 AB=4: A,B 已连通 → 跳过（会成环）
 CD=5: C,D 已连通 → 跳过（会成环）
MST = {BC, BD, AC}，权值 = 1+2+3 = 6   ← 与 Prim 结果一致 ✓
```

> ⚠️ **并查集判环的写法**：对每条边 (u,v)，若 `find(u) == find(v)` 则加入会成环，跳过；否则 `union(u,v)`。这一步的时间复杂度近乎 O(1)（路径压缩后）。

### 8.4 拓扑排序（AOV 网）

- **AOV 网**：顶点表示**活动**，边表示**先后次序**（<i,j> 表示 i 必须先于 j）。**仅适用于 DAG（有向无环图）**。
- **Kahn 算法（队列法）**：① 找入度为 0 的顶点入队；② 出队并输出，把它所有出边删除（相邻顶点入度 −1，新的入度 0 者入队）；③ 重复至队空。若输出顶点数 < V，则**有环**。
- 时间复杂度 **O(V+E)**。
- ⚠️ **拓扑排序不唯一**（同时多个入度为 0 的顶点，输出顺序任意）。所以"下列哪个不是该图的拓扑序列"是这类题的常见考法——逐项模拟即可。
- ⚠️ **反向应用**：判断有向图是否有环 ⟺ 拓扑排序能否输出全部顶点。

**拓扑排序例题：** 课程依赖 C1→C3、C2→C3、C3→C4、C2→C4

```
入度：C1=0, C2=0, C3=2, C4=2
初始队列：[C1, C2]
输出 C1 → C3 入度 1；输出 C2 → C3 入度 0(入队)、C4 入度 1
输出 C3 → C4 入度 0(入队)；输出 C4
合法序列：C1,C2,C3,C4 或 C2,C1,C3,C4（不唯一）
```

### 8.5 关键路径（AOE 网）—— 高频计算题

- **AOE 网**：顶点表示**事件**（状态），**边表示活动（工程/任务）**，边权 = 活动耗时。源点（入度为 0）= 开工，汇点（出度为 0）= 竣工。
- **关键路径** = 从源点到汇点的**最长路径**，其长度 = **最短工期**（不是最短路径！）

**四步算法：**
1. **正推求 ve（事件最早发生时间）**：`ve[j] = max{ ve[i] + w(i,j) }`（i 是 j 的所有前驱），源点 ve=0，**顺拓扑序取最大**。
2. **逆推求 vl（事件最迟发生时间）**：`vl[i] = min{ vl[j] − w(i,j) }`（j 是 i 的所有后继），汇点 vl = ve，**逆拓扑序取最小**。
3. **求活动的最早/最迟开始时间**：活动 <i,j> 的 `e = ve[i]`，`l = vl[j] − w(i,j)`。
4. **关键活动** = `l − e = 0` 的活动；关键活动组成的路径就是关键路径。

**完整例题：** AOE 网 V1(源) → V2(2), V1→V3(3), V2→V4(4), V3→V4(1), V4→V5(5)

```
第 1 步 ve（正推取最大）：
 ve(V1)=0
 ve(V2)=0+2=2
 ve(V3)=0+3=3
 ve(V4)=max(ve(V2)+4, ve(V3)+1)=max(6, 4)=6
 ve(V5)=6+5=11                    ← 最短工期 = 11

第 2 步 vl（逆推取最小，自汇点 vl=ve）：
 vl(V5)=11
 vl(V4)=11−5=6
 vl(V3)=vl(V4)−1=5
 vl(V2)=vl(V4)−4=2
 vl(V1)=min(vl(V2)−2, vl(V3)−3)=min(0, 2)=0

第 3 步 活动 e / l：
 活动        e(=ve[尾])  l(=vl[头]−w)   l−e
 V1→V2(2)      0          2−2=0         0    ← 关键
 V1→V3(3)      0          5−3=2         2
 V2→V4(4)      2          6−4=2         0    ← 关键
 V3→V4(1)      3          6−1=5         2
 V4→V5(5)      6          11−5=6        0    ← 关键

关键路径：V1 → V2 → V4 → V5，总长 2+4+5 = 11
```

> ⚠️ **易错点 1**：关键路径**可能不止一条**——只有缩短**所有**关键路径共有的关键活动**才能缩短工期**。
> ⚠️ **易错点 2**：`ve 取 max`、`vl 取 min`——方向记反是最常见的丢分点。口诀：**"最早看最长（max），最迟看最短（min）"**。
> ⚠️ **易错点 3**：AOV 用拓扑排序、AOE 用关键路径——两者考"顶点 vs 边谁表示活动"时极易混。**AOV 顶点=活动；AOE 边=活动**。
> ⚠️ **易错点 4**：关键活动的总机动时间（松弛）为 0，但**非关键活动也有机动时间**，l−e 就是它的时间余量。

## 九、排序稳定性与复杂度（补漏）

### 9.1 稳定性定义

若排序前 `a_i = a_j`（关键字相等）且 i 在 j 之前，排序后 i 仍在 j 之前，则称该排序**稳定**；否则**不稳定**。
- **稳定性的意义**：多关键字排序。例如"先按次要关键字（如年龄）排好，再按主要关键字（如部门）**稳定**排序"，就能保证同部门内仍按年龄有序。若主排序不稳定，前面的结果会被打乱。

### 9.2 完整对比表（必背）

| 算法 | 最好 | 平均 | 最坏 | 空间复杂度 | 稳定性 | 备注 |
|------|------|------|------|-----------|--------|------|
| 冒泡排序 | **O(n)** | O(n²) | O(n²) | O(1) | **稳定** | 最好 O(n) 需"一趟无交换则提前结束"的优化 |
| 选择排序 | O(n²) | O(n²) | O(n²) | O(1) | **不稳定** | 交换跨距离，破坏相等元素次序 |
| 插入排序 | **O(n)** | O(n²) | O(n²) | O(1) | **稳定** | 基本有序时接近 O(n)；希尔排序是其改进 |
| 希尔排序 | O(n^1.3) | O(n^1.3~1.5) | O(n²) | O(1) | **不稳定** | 分组后相同元素可能落在不同子序列 |
| 快速排序 | O(nlogn) | O(nlogn) | **O(n²)** | **O(logn)** | **不稳定** | 最坏发生在**已序/逆序**（划分极度不平衡） |
| 归并排序 | O(nlogn) | O(nlogn) | O(nlogn) | **O(n)** | **稳定** | 时间与输入无关；外部排序/链表排序首选 |
| 堆排序 | O(nlogn) | O(nlogn) | O(nlogn) | O(1) | **不稳定** | 建堆 **O(n)**（不是 O(nlogn)） |
| 基数排序 | O(d(n+r)) | O(d(n+r)) | O(d(n+r)) | **O(r+n)** | **稳定** | 位分配用稳定排序；d=位数，r=基数 |

**稳定性速记口诀：** 稳定 = **"冒（泡）插（入）归（并）基（数）"**；不稳定 = **"快（速）选（择）希（尔）堆"**。

> ⚠️ **高频陷阱**："下列排序中不稳定的是（ ）"——答案必在 **快/选/希/堆** 中；"时间复杂度与输入初始序列无关的是（ ）"——答案必是 **归并/堆/选择/基数**（它们最好=平均=最坏）。注意：**快速排序的空间 O(logn)** 是因为递归栈深度 = 划分树高，最坏情况（已序）退化为 **O(n)**。

### 9.3 为什么稳定 / 不稳定（原理级理解）

- **冒泡**：只比较**相邻**元素，相等时不交换 → 稳定。
- **插入**：新元素从已排序段**从后往前**比较，遇到**不大于**自己的就停（遇到相等就停下）→ 稳定。
- **归并**：合并时左半与右半的元素比较，**左半优先**放回 → 稳定。
- **基数**：每一位的分配与收集都借助**稳定**的计数排序 → 稳定。
- **选择**：选最小元素时与**远处**元素交换。例：序列 `5₁, 5₂, 2`，选出最小值 2 与 `5₁` 交换 → `2, 5₂, 5₁`，两个 5 的次序被破坏 → 不稳定。
- **快速**：划分时元素与基准交换可能**跨越**相等的元素 → 不稳定。
- **堆排序**：堆顶与末尾元素交换是**远距离**交换 → 不稳定。
- **希尔**：相隔 gap 的元素分组排序，相同关键字的元素可能落在**不同子序列**，相对次序无法保证 → 不稳定。

### 9.4 堆排序的三个高频数字

- 建堆时间 **O(n)**（从最后一个非叶子节点到根逐个下沉，而非逐个插入）。
- 堆是完全二叉树：n 个节点的堆高 = **⌊log₂n⌋**。
- 取最值：**大顶堆**的堆顶是最大值，**小顶堆**的堆顶是最小值。**优先队列**通常用堆实现。

## 十、哈希表与冲突处理（补漏）

### 10.1 装填因子（决定查找效率的核心量）

- **装填因子 α = 哈希表中记录数 n ÷ 哈希表长度 m**。
- ⚠️ **哈希表的查找效率（ASL）主要取决于 α，而不取决于记录数 n**——这是最核心的结论。α 越大，冲突越频繁，ASL 越高。
- 工程上通常把 α 控制在 **0.6~0.75** 以下，超过就"扩容 rehash"。

### 10.2 哈希函数构造

| 方法 | 说明 | 注意 |
|------|------|------|
| **除留余数法** | `H(key) = key mod p` | ⚠️ **p 应取不大于表长的最大素数**（或直接取表长），取合数会增大冲突 |
| 直接定址法 | `H(key) = a·key + b` | 无冲突，但要求关键字分布连续 |
| 平方取中法 | 取关键字平方的中间几位 | 关键字位数大时常用 |
| 折叠法 | 分段叠加 | 关键字位数多且分布不均 |
| 数字分析法 | 取分布均匀的几位 | 适合已知关键字集合 |

### 10.3 冲突处理方法

**(1) 开放定址法**：`H_i = (H(key) + d_i) mod m`

| 探测序列 d_i | 名称 | 特点 |
|--------------|------|------|
| 1, 2, 3, 4, … | **线性探测再散列** | 实现最简单；⚠️ 产生**聚集（堆积）**——冲突元素连成一片，形成长探测链 |
| 1², −1², 2², −2², … | **二次（平方）探测再散列** | 缓解聚集；⚠️ 只能探测到**表长的一半**位置（要求表长为 4k+3 型素数时可探测全表） |
| 伪随机序列 | 伪随机探测再散列 | 依赖 d_i 的生成，不实用 |

- ⚠️ **开放定址法不能"物理删除"元素**——删除会中断探测链，导致后续同义词查不到。只能**打删除标记（墓碑/软删除）**，并在适当时候重新整理表。
- ⚠️ **开放定址法装填因子必须 α < 1**，否则探测序列可能永远找不到空位（表满时）。

**(2) 链地址法（拉链法）**：所有同义词存成一条**单链表**，链表头指针存放在哈希数组中。
- ✅ 无聚集现象；删除方便（真正删除链表节点）；适合记录大小不固定的场景；表长可动态扩展。
- ⚠️ 查找时需要**在链表中顺序比较**，链表越长 ASL 越大。

**(3) 再哈希法**：`H_i = RHi(key)`（多个不同的哈希函数），冲突时换下一个函数。不易产生聚集，但计算开销大。

**(4) 建立公共溢出区**：冲突元素一律存入专门的溢出表（顺序查找）。

### 10.4 ASL 手算（必考计算题）

> **查找长度的定义**：比较关键字的次数，**包含"比较后找到"的那一次**。开放定址法中"遇到空位置"也算一次比较（但本次查找失败）。

**完整例题：** 哈希表长 m=7，`H(key) = key mod 7`，**线性探测**处理冲突，依次插入关键字 `12, 19, 26, 5, 8, 15`。求查找成功的 ASL。

```
12 mod 7 = 5 → 位置 5（空）      存 5      探测 1 次
19 mod 7 = 5 → 冲突 → 6（空）    存 6      探测 2 次
26 mod 7 = 5 → 冲突(5)→6(占)→0(空)  存 0   探测 3 次
 5 mod 7 = 5 → 冲突(5)→6(占)→0(占)→1(空) 存 1  探测 4 次
 8 mod 7 = 1 → 1(占)→2(空)      存 2      探测 2 次
15 mod 7 = 1 → 1(占)→2(占)→3(空) 存 3     探测 3 次

表内容（下标: 关键字）  0:26  1:5  2:8  3:15  4:_  5:12  6:19
装填因子 α = 6/7 ≈ 0.857

ASL(成功) = (1+2+3+4+2+3) / 6 = 15/6 = 2.5
```

**同一序列改用链地址法：**

```
位置 5 的链：12 → 19 → 26 → 5      （各需 1、2、3、4 次比较）
位置 1 的链：8 → 15                （各需 1、2 次比较）

ASL(成功) = (1+2+3+4+1+2) / 6 = 13/6 ≈ 2.17
```

> 结论：**同样 α 下，链地址法的 ASL 优于线性探测**（2.17 < 2.5），且没有聚集问题。
> ⚠️ **易错点 1**：算 ASL 时**分母是记录数 n**（成功查找）或**表长 m**（失败查找），两者不同，看清题目问哪个。
> ⚠️ **易错点 2**：`key mod p` 的 p 取素数——若题目给出 `mod 7` 而表长 8，**哈希地址范围仍是 0~6**，别把位置 7 当合法槽位。
> ⚠️ **易错点 3**：线性探测回绕——探测到表尾要 `mod m` 回到 0 继续。

### 10.5 理论 ASL 公式（随机哈希函数假设）

| 方法 | ASL（成功查找） |
|------|----------------|
| 链地址法 | **α + e^(−α) ≈ 1 + α/2**（小 α 时） |
| 线性探测 | **(1 + 1/(1−α)) / 2** |
| 二次探测/再哈希 | **−(1/α)·ln(1−α)** |

- 记住趋势即可：**同一 α 下，链地址 < 二次探测 < 线性探测**。
