# 数据结构与算法 - 知识点精讲

## 一、线性表

### 1.1 顺序表（数组）
- **存储**：连续内存空间
- **插入**：平均移动 n/2 个元素，时间复杂度 O(n)
- **删除**：平均移动 n/2 个元素，时间复杂度 O(n)
- **查找**：顺序查找 O(n)，折半查找 O(log₂n)（要求有序）

### 1.2 链表
- **单向链表**：每个节点含数据和指向下一节点的指针
- **双向链表**：每个节点含前驱和后继指针
- **循环链表**：尾节点指向头节点

#### 常见操作
| 操作 | 单链表时间复杂度 |
|------|----------------|
| 查找 | O(n) |
| 插入（已知位置） | O(1) |
| 删除（已知位置） | O(1) |
| 插入（头插法） | O(1) |

#### 链表经典操作
- **反转链表**：三指针法（prev, curr, next）
- **找中间节点**：快慢指针
- **判断环**：快慢指针
- **合并有序链表**：归并思想

### 1.3 栈（Stack）
- **特性**：后进先出（LIFO）
- **应用**：括号匹配、表达式求值、递归调用
- **顺序栈和链栈**

### 1.4 队列（Queue）
- **特性**：先进先出（FIFO）
- **循环队列**：解决顺序队列的假溢出
- **双端队列**：两端都可进出

## 二、树

### 2.1 二叉树基础
- **性质**：
  - 第i层最多 2^(i-1) 个节点
  - 深度为k的二叉树最多 2^k - 1 个节点
  - 叶子节点数 = 度为2的节点数 + 1

### 2.2 二叉树遍历
| 遍历方式 | 顺序 | 应用 |
|---------|------|------|
| 前序遍历 | 根→左→右 | 复制树、表达式 |
| 中序遍历 | 左→根→右 | BST排序结果 |
| 后序遍历 | 左→右→根 | 删除树、计算大小 |
| 层序遍历 | 逐层从左到右 | BFS |

### 2.3 二叉搜索树（BST）
- 左子树所有节点 < 根节点
- 右子树所有节点 > 根节点
- 中序遍历得到有序序列
- 查找、插入、删除平均 O(log₂n)

### 2.4 平衡二叉树（AVL）
- 左右子树高度差不超过1
- 插入/删除后可能需要旋转
- 旋转类型：LL、RR、LR、RL

### 2.5 哈夫曼树
- **带权路径长度（WPL）**最小
- **构造方法**：每次选两个最小权值节点合并
- **应用**：数据压缩、编码
- **编码规则**：左0右1（或左1右0）

## 三、图

### 3.1 基本概念
- **有向图 vs 无向图**
- **度**：无向图-相连边数；有向图-入度+出度
- **连通图**：无向图中任意两点可达
- **强连通图**：有向图中任意两点互相可达

### 3.2 存储结构
- **邻接矩阵**：V×V矩阵，适合稠密图
- **邻接表**：每个节点的邻居链表，适合稀疏图

### 3.3 遍历算法
- **DFS（深度优先）**：栈实现/递归
- **BFS（广度优先）**：队列实现

### 3.4 最小生成树
- **Prim算法**：从一点开始，每次选最小边（适合稠密图）
- **Kruskal算法**：从小到大选边，不形成环（适合稀疏图）

### 3.5 最短路径
- **Dijkstra算法**：单源最短路径（无负权边）
- **Floyd算法**：所有顶点对最短路径

## 四、排序算法

### 4.1 排序算法对比表
| 算法 | 最好 | 平均 | 最坏 | 空间 | 稳定性 |
|------|------|------|------|------|--------|
| 冒泡排序 | O(n) | O(n²) | O(n²) | O(1) | 稳定 |
| 选择排序 | O(n²) | O(n²) | O(n²) | O(1) | 不稳定 |
| 插入排序 | O(n) | O(n²) | O(n²) | O(1) | 稳定 |
| 快速排序 | O(nlogn) | O(nlogn) | O(n²) | O(logn) | 不稳定 |
| 归并排序 | O(nlogn) | O(nlogn) | O(nlogn) | O(n) | 稳定 |
| 堆排序 | O(nlogn) | O(nlogn) | O(nlogn) | O(1) | 不稳定 |

### 4.2 重点算法
- **快速排序**：分治思想，选基准值，分区递归
- **归并排序**：分治思想，分裂后合并
- **堆排序**：大顶堆/小顶堆

## 五、查找算法

### 5.1 顺序查找
- 适用：无序表
- 时间复杂度：O(n)

### 5.2 折半查找
- 适用：有序顺序表
- 时间复杂度：O(log₂n)
- 判定树深度 = ⌈log₂(n+1)⌉

### 5.3 哈希查找
- **哈希函数构造**：除留余数法、平方取中法
- **冲突解决**：开放地址法（线性探测/二次探测）、链地址法
- **平均查找长度**：取决于装填因子

## 六、算法分析

### 时间复杂度计算
- 顺序结构：取最大
- 循环结构：看循环次数
- 嵌套循环：内外层相乘
- 递归：递归方程（主定理）

### 常见时间复杂度排序
O(1) < O(logn) < O(n) < O(nlogn) < O(n²) < O(n³) < O(2ⁿ) < O(n!)
