## 附：Day 10 笔记「快速自测」速答

1. **CPU = 运算器 + 控制器**；ALU/ACC/PSW 属**运算器**，PC/IR/MAR/MDR 属**控制器**。
2. **PC** 存**下一条**指令地址，取指后自动 +1；**IR** 存**当前**指令。
3. **MAR 接地址总线（单向）**，**MDR 接数据总线（双向）**。
4. **CF** 看无符号进位、**OF** 看带符号溢出；二者相互独立。
5. **微程序控制器**的 CM（ROM）存**微程序（微指令）**；**硬布线速度快**；**RISC 用硬布线、CISC 用微程序**。
6. **地址码 m 位 → 直接寻址 2ᵐ 单元**；**间接寻址范围由存储字长决定**。
7. **基址 EA=(Rb)+A**（重定位，程序员不可见）；**变址 EA=(Rx)+A**（数组/循环，程序可改）；**相对 EA=(PC)+A**（PC 是**下一条**指令地址）。
8. **Δt = 最长段**；等长段 **T=(k+n−1)·Δt**、**S=kn/(k+n−1)**、**E=n/(k+n−1)**、**TP=n/T**、**TP_max=1/Δt**。
9. 不等长段 **T=Σt+(n−1)·Δt**、**S=n·Σt/T**。
10. **超标量 TP_max=m/Δt**；**超流水线 TP_max=n/Δt**；**超标量超流水线 TP_max=m·n/Δt**。

# 答案与解析

> 答案速查：1.B  2.C  3.B  4.C  5.B  6.C  7.B  8.B  9.C  10.C  11.B  12.B  13.A  14.D  15.A  16.B  17.B  18.C  19.B  20.C

---

**1. B。**
CPU = 运算器 + 控制器。**ALU（算术逻辑单元）**完成算术与逻辑运算，属于**运算器**；运算器还包括 ACC（累加器）、通用寄存器组、PSW（程序状态字）。
- A 错：控制器包含 PC、IR、MAR、MDR、指令译码器、时序发生器。
- 易错提醒：**PC、IR 属于控制器，不属于运算器**——这是最高频的"部件归属"题。

**2. C。**
**PC（程序计数器）**存放下一条要取的指令地址。取指时 PC → MAR，取指完成后 PC 自动 +1。
- A 错：**IR（指令寄存器）**存放**当前正在执行**的指令本身。
- B 错：**MDR** 存放与主存交换的数据。
- D 错：**PSW** 存放标志位（CF/ZF/SF/OF）与工作状态。
- 口诀：「PC 指路，IR 执令，MAR 管地址，MDR 管数据」。

**3. B。**
**MDR 与数据总线相连（双向）**——CPU 读主存时数据经数据总线 → MDR，写主存时 MDR → 数据总线。**MAR 与地址总线相连（单向）**。这是固定对应关系，不能混。

**4. C。**
无符号数运算最高位向更高位进位 → **CF（进位/借位标志）= 1**。
- A 错（本题最大陷阱）：**OF 是带符号数溢出标志**。本题明确是"无符号数"，且只说"产生进位"。
- 易错提醒：CF 与 OF 相互独立。例如 8 位运算 `11111111 + 00000001`：无符号 255+1=256 → **CF=1**；带符号 −1+1=0 未溢出 → **OF=0**。**问"无符号/进位"选 CF，问"带符号/溢出"选 OF。**

**5. B。**
控制存储器（CM）位于 **CPU 内部**，属于 **ROM**（只读），其中存放的是**微程序（即微指令序列）**。
- A 错：CM 不是主存 RAM，也不在 CPU 之外。
- 关键链条：**机器指令 →（对应）一段微程序 → 若干条微指令 → 若干个微操作控制信号**。

**6. C。**
硬布线控制器用门电路直接组合产生控制信号，**速度最快**；但修改困难、结构不规整，适合 **RISC**。
- A、B 正好相反：**修改容易、结构规整**是微程序控制器的优点。
- D 错：微程序控制器适合 CISC，硬布线适合 RISC。

**7. B。**
指令周期 = 取指周期 + （间址周期）+ 执行周期 + 中断周期。**间址周期**用于把间接寻址的形式地址转换为**有效地址**（即再访存一次取操作数地址）。
- A 是**取指周期**（PC → MAR、主存 → MDR → IR、PC+1）。
- C 是**中断周期**（保存断点、置中断向量地址）。
- D 是**执行周期**。
- 易错提醒：**间址周期不是每条指令都有的**——只有间接寻址才需要。

**8. B。**
直接寻址 **EA = A**，可访问的单元数 = 2^(形式地址位数) = 2⁸ = **256 个**。
- A 是 2⁶；C 是 2¹²；D 是 2¹⁶。
- 规律：**地址码有几位，直接寻址范围就是 2 的几次方**。

**9. C。**
间接寻址 **EA = (A)**：A 单元里存的是有效地址。一次间接寻址可访问的**最大存储空间由有效地址位数决定**，有效地址来自主存单元内容，位数 = **存储字长 = 16 位** → 可寻址 **2¹⁶ = 65536 个单元**。
- A、B 错：这是本题最大陷阱——**间接寻址的范围不由形式地址 A 的位数决定**（这正是间接寻址存在的意义：用短地址码访问大地址空间）。
- D 错：若由形式地址位数决定，则与第 8 题一样是 256，与"扩大寻址空间"的初衷矛盾。

**10. C。**
基址与变址的**有效地址公式形式相同**（都是 EA = (R) + A），区别在**语义与管理方式**：基址用于**程序重定位**，基址寄存器由操作系统/系统程序管理，**对程序员不可见**；变址用于**数组/循环遍历**，变址寄存器内容**由程序在执行中修改**。
- A 错：两者公式形式相同（加法可交换，EA=(Rb)+A 与 EA=A+(Rx) 是一回事）。
- B 错：说反了——基址用于重定位、变址用于数组遍历。
- D 错：两者都只需 **1 次**访存取操作数（公式算出 EA 后访存 1 次）。

**11. B。**
相对寻址 **EA = (PC) + A**，A 为 8 位补码。80H = 1000 0000₂，作为 8 位补码其真值 = **−128**。
```
EA = 2000H + (−128) = 2000H − 80H = 1F80H
（十进制验算：2000H = 8192，8192 − 128 = 8064 = 1F80H ✓）
```
- A 错（2080H）：把 A 当成无符号数直接相加（2000H + 80H = 2080H）——**相对寻址的 A 是补码位移量，可正可负**。
- C 错（2000H）：把位移量当成 0（以为 EA 就等于 (PC)），不符合题意。
- D 错（1F00H）：十六进制减法借位出错——2000H − 80H 应得 1F80H，若借位时多减一个 80H（80H + 80H = 100H）就会得到 2000H − 100H = 1F00H。
- 易错提醒：公式中的 (PC) 是**下一条指令**的地址（取指后 PC 已自动 +1）。本题题目已明确"已指向下一条指令"，故直接代入 2000H。

**12. B。**
变址寻址 **EA = (Rx) + A**，以形式地址 A 为基准、变址寄存器内容为偏移：
```
EA = (R3) + A = 0006H + 2000H = 2006H
```
即数组第 6 个元素（下标 6）所在的单元。
- A 错：忘了加变址寄存器内容。
- C 错：把 (R3) 当成基准、A 当成偏移，高低位写反（6002H）。变址寻址中 **A 是数组首址基准、(Rx) 是下标偏移**。
- D 错：有效地址唯一确定，不存在歧义。

**13. A。**
扩展操作码需逐级计算"可用编码数"（可用 = 上一级剩余前缀 × 2^新增位数）：
```
① 三地址：地址码 4+4+4 = 12 位 → 操作码 4 位 → 可用 2⁴ = 16 种
           用 4 条 → 剩 12 种作为扩展前缀
② 二地址：地址码 4+4 = 8 位 → 操作码 8 位 → 可用 12 × 2⁴ = 192 种
           用 8 条 → 剩 184 种
③ 一地址：地址码 4 位 → 操作码 12 位 → 可用 184 × 2⁴ = 2944 种 ≥ 180 ✓
④ 零地址：地址码 0 位 → 操作码 16 位 → 剩余前缀 2944 − 180 = 2764
           → 可用 2764 × 2⁴ = 44224 种 ≥ 16 ✓
```
故**一地址指令的地址码 = 4 位**（操作码 12 位，可寻址 2⁴ = 16 个单元）。
- B/C/D 错：没有逐级展开计算，或者误以为一地址指令的操作码仍是 4 位。

**14. D。**
**流水线周期（时钟周期）Δt = 最长段的时间 = max(30, 40, 60, 20) = 60 ns**。
- A（20 ns）是最短段；C（40 ns）接近四段的算术平均值（实际平均 = (30+40+60+20)/4 = **37.5 ns**）——流水线周期既不是最短段也不是平均值。
- B（30 ns）是第二段的时间，无任何依据。
- 提升手段：把 60 ns 的瓶颈段**再细分为若干子段**，或**重复设置**瓶颈段。

**15. A。**
等长段，k = 5、n = 10、Δt = 2 ns：
```
T  = (k + n − 1)·Δt = (5 + 10 − 1) × 2 ns = 14 × 2 = 28 ns
T₀ = k·n·Δt = 5 × 10 × 2 = 100 ns
S  = T₀/T = 100/28 ≈ 3.57
```
- B 错：T = 20 ns 少算了装满流水线的 5 个周期（误用 n·Δt）。
- C 错：加速比误取为段数 5（S 只是**接近** k，不可能等于或超过 k）。
- D 错（30 ns，3.33）：把 T 算成 **(k+n)·Δt = 15 × 2 = 30 ns**（分母漏掉 −1），或 **(k+n−1)·Δt + Δt = 28 + 2 = 30 ns**（多数了一个周期）；S = 100/30 ≈ 3.33。正确分母必须是 **k + n − 1 = 14**。
- 验算：E = n/(k+n−1) = 10/14 = 71.4%，S = k·E = 5 × 0.714 = 3.57 ✓

**16. B。**
不等长段，Δt = max(10,15,20,10) = 20 ns，Σt = 10+15+20+10 = 55 ns，n = 100，k = 4：
```
T  = Σt + (n − 1)·Δt = 55 + 99 × 20 = 55 + 1980 = 2035 ns
T₀ = n·Σt = 100 × 55 = 5500 ns
S  = T₀/T = 5500/2035 ≈ 2.70
```
- A 错（2000 ns，2.75）：把 T 误当成 **n·Δt = 100 × 20 = 2000 ns**（丢掉第 1 条指令装满流水线所需的 Σt 那一段），于是 S = 5500/2000 = 2.75。
- C 错（2035 ns，4）：T 算对了，但加速比误取段数 4（**S < k 恒成立**，加速比永远不可能等于段数）。
- D 错：T₀ 是**非流水线**时间，不是流水线时间。
- ⚠️ **不等长段的核心易错点**：T = Σt + (n−1)·Δt，**不是** k·Δt + (n−1)·Δt。第 1 条指令走完全程用的是 Σt（各段实际时间之和），之后每条只需一个周期 Δt。

**17. B。**
Δt = max(50,100,150,100,50) = 150 ns，Σt = 50+100+150+100+50 = 450 ns，n = 20，k = 5：
```
T  = Σt + (n − 1)·Δt = 450 + 19 × 150 = 450 + 2850 = 3300 ns
S  = n·Σt / T = (20 × 450) / 3300 = 9000/3300 ≈ 2.727
E  = S / k = 2.727 / 5 = 0.5455 = 54.5%
交叉验证：E = n·Σt / (k·T) = 9000 / (5 × 3300) = 9000/16500 = 54.5% ✓
```
- A 错（45.5%）：公式记成了 **E = S/(k+1)**——把除数"段数 k"误当成"段数+1"（把 5 段数成 6），于是 E = 2.727/6 = 45.5%。**效率的除数只能是段数 k**。
- C 错（60%）：算 T 时漏掉第 1 条指令装满流水线的那一段时间，误用 **T = n·Δt = 20 × 150 = 3000 ns**，于是 E = n·Σt/(k·T) = 9000/(5 × 3000) = 9000/15000 = **60%**。这是和第 15、16 题同一个错误——**T = Σt + (n−1)·Δt，不是 n·Δt**。
- D 错（83.3%）：误用了**只适用于等长段**的效率公式 **E = n/(k+n−1) = 20/24 = 83.3%**。本题主干是**不等长段**（各段 50/100/150/100/50 ns 不相等），必须先算出实际的 S 再用 **E = S/k = n·Σt/(k·T)**。
- 结论解释：效率只有 54.5%，说明流水线过半时间有部件在等瓶颈段（150 ns 的第 3 段）。

**18. C。**
等长段逆推：S = k·n/(k + n − 1) = 3.5，k = 4，解 n：
```
4n / (n + 3) = 3.5
4n = 3.5(n + 3) = 3.5n + 10.5
0.5n = 10.5  →  n = 21
验证：S = 4 × 21 / (21 + 3) = 84/24 = 3.5 ✓
```
故至少 **21 条**指令。
- D 错（28）：分母漏掉 −1，解 4n/(n+4) = 3.5 → 0.5n = 14 → n = 28——公式必须记成 **k + n − 1**。
- A（14）、B（18）：未解方程，凭感觉取值。
- 合理性检查：S₀ 必须 **< k**（加速比上限是段数 k），否则无解——本题 3.5 < 4 ✓。

**19. B。**
标量单流水线 TP_max = 1/Δt = 1/10 ns = 1 × 10⁸ 条/秒。
**超标量（度 m = 3）**：每个时钟周期同时发射 3 条 → TP_max = m/Δt = 3/10 ns = **3 × 10⁸ 条/秒**。
- C 错（3 × 10⁷ 条/秒）：**时间单位换算少除了一位**——把 3 条/10 ns 误算成 3 条/100 ns（或 ns→s 的 10⁻⁹ 换算少除了一次 10），得到 3/100 ns = 3 × 10⁷ 条/秒。正确是 3/10 ns。
- D 错（6 × 10⁸ 条/秒）：把度数误当成 **2m = 6**（误以为"超标量度数要翻倍"，或把超标量与超流水线的度数相乘且把 n 取成 2），于是 6/10 ns = 6 × 10⁸ 条/秒。**度数 m 就是题目给的 3，既不翻倍也不相乘**。
- 关联记忆：**超流水线（度 n）TP_max = n/Δt**；**超标量超流水线 TP_max = m·n/Δt**。
  口诀：「超标量靠并行多发（横向加宽），超流水线靠加深分段（纵向细分）」。

**20. C。**
RISC 的典型特征：指令少且长度固定、格式少、寻址方式少；**只有 Load/Store 访存**，其余为寄存器-寄存器运算；**硬布线控制**为主；大量通用寄存器；**高度依赖流水线与优化编译**。
- A 错：说的是 CISC 的特征（RISC 指令**少**、格式**少**、寻址**少**）。
- B 错：指令长度固定、硬布线控制是 **RISC** 的特征；CISC 指令**长度不固定**、多用**微程序**控制。
- D 错：**RISC 的通用寄存器更多**（甚至用寄存器窗口技术），CISC 相对较少。
