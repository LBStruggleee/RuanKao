# 操作系统 - 知识点精讲

## 一、进程管理

### 1.1 进程与线程

#### 进程
- **定义**：程序在数据集上的一次执行过程
- **三个基本状态**：就绪、执行、阻塞
- **五状态模型**：新建→就绪→执行→阻塞→终止
- **进程控制块（PCB）**：进程存在的唯一标志

#### 线程
- **定义**：进程内的执行单元
- **与进程的区别**：
  - 线程共享进程资源，进程独立资源
  - 线程切换快，进程切换慢
  - 线程间通信简单，进程间通信复杂

#### 进程状态转换
```
新建 → 就绪 → 执行 → 阻塞 → 就绪
                    ↓
                   终止
```

### 1.2 进程调度算法

| 算法 | 特点 | 优缺点 |
|------|------|--------|
| FCFS | 先来先服务 | 简单，但平均等待时间长 |
| SJF | 最短作业优先 | 平均等待时间短，但可能饥饿 |
| 优先级 | 按优先级调度 | 可能饥饿，需老化 |
| 时间片轮转 | 每个进程等时间片 | 公平，但时间片大小影响性能 |
| 多级反馈队列 | 综合多种算法 | 最常用，复杂 |

### 1.3 PV操作与信号量

#### 基本概念
- **信号量S**：整型变量
- **P操作（wait）**：S = S - 1；若S < 0则阻塞
- **V操作（signal）**：S = S + 1；若S ≤ 0则唤醒

#### 经典问题

**生产者-消费者问题**
```
// 互斥信号量
mutex = 1
// 资源信号量
empty = n  // 缓冲区空位数
full = 0   // 缓冲区产品数

// 生产者
P(empty); P(mutex); 生产; V(mutex); V(full)
// 消费者
P(full); P(mutex); 消费; V(mutex); V(empty)
```

**读者-写者问题**
```
// 读者优先
rw_mutex = 1  // 写互斥
mutex = 1     // 读计数互斥
count = 0

// 读者
P(mutex); count++; if(count==1) P(rw_mutex); V(mutex); 读; P(mutex); count--; if(count==0) V(rw_mutex); V(mutex)
// 写者
P(rw_mutex); 写; V(rw_mutex)
```

**哲学家进餐问题**
- 5个哲学家，5根筷子
- 解决方法：限制同时进餐人数、资源有序分配

### 1.4 死锁

#### 四个必要条件
1. **互斥**：资源一次只被一个进程使用
2. **占有且等待**：持有资源的同时等待新资源
3. **不可剥夺**：已分配资源不能被强行收回
4. **循环等待**：存在进程-资源循环等待链

#### 处理方法
- **预防**：破坏四个条件之一
- **避免**：银行家算法
- **检测与恢复**：资源分配图

## 二、内存管理

### 2.1 连续内存分配
- **首次适应**：从低地址开始找第一个足够大的空闲区
- **最佳适应**：找最小的足够大的空闲区
- **最坏适应**：找最大的空闲区

### 2.2 分页存储
- **页面大小**：固定（通常4KB）
- **页表**：逻辑页号→物理块号映射
- **地址转换**：逻辑地址 = 页号 + 页内偏移
  - 页号 = 逻辑地址 / 页面大小
  - 页内偏移 = 逻辑地址 % 页面大小

### 2.3 分段存储
- **段**：逻辑模块（代码段、数据段、堆栈段）
- **段表**：段号→基址+长度
- **逻辑地址** = 段号 + 段内偏移

### 2.4 虚拟内存
- **原理**：局部性原理（时间局部性+空间局部性）
- **页面置换算法**：

| 算法 | 描述 | 特点 |
|------|------|------|
| FIFO | 先进先出 | 简单，可能Belady异常 |
| LRU | 最近最少使用 | 性能好，实现复杂 |
| OPT | 最佳置换 | 理论最优，不可实现 |
| Clock | 循环置换 | LRU近似，实现简单 |

### 2.5 缺页中断
- 访问的页面不在内存中
- 触发中断 → 调入页面 → 重新执行
- 缺页率 = 缺页次数 / 总访问次数

## 三、磁盘调度

### 3.1 磁盘调度算法
| 算法 | 描述 | 特点 |
|------|------|------|
| FCFS | 按请求顺序 | 公平，可能长寻道 |
| SSTF | 最近磁道优先 | 平均寻道短，可能饥饿 |
| SCAN | 电梯算法 | 双向扫描，公平 |
| C-SCAN | 单向扫描 | 减少延迟变化 |

### 3.2 磁盘结构
- 盘面、磁道、扇区
- 寻道时间 + 旋转延迟 + 传输时间

## 四、文件系统

### 4.1 文件组织方式
- **顺序文件**：连续存储
- **链接文件**：离散存储，通过指针链接
- **索引文件**：索引表记录所有块地址
- **索引顺序文件**：索引 + 顺序

### 4.2 目录结构
- 单级目录
- 两级目录
- 多级目录（树形）

## 五、I/O管理

### 5.1 I/O控制方式
1. **程序I/O**：CPU轮询
2. **中断I/O**：中断通知
3. **DMA**：直接内存访问
4. **通道**：独立I/O处理器

## 六、核心公式速记

| 公式 | 说明 |
|------|------|
| 平均等待时间 | = 各进程等待时间之和 / 进程数 |
| 页表项大小 | = 物理块号位数 + 标志位 |
| 地址转换 | 页号 = 地址 / 页大小，偏移 = 地址 % 页大小 |
| 缺页中断率 | = 缺页次数 / 总访问次数 |
