第二层 · 线怎么连成面：三张「跨面接线图」

真正的体系感来自跨面的线——这三条是历年真题最爱考的「面与面的接口」：

  1. 存储大线（组成 ↔ OS）：0001 二进制/机器码 → 0003 局部性与 Cache（快）→ 0016 虚拟内存与页表（慢）→ 0017-0019 磁盘与文件（最慢）——一条从寄存器到磁盘的分级存储走廊，Cache 命中率与页面置换是同一件事在两层的表现。
  2. 策略大线（DS ↔ 下午卷）：0006 栈/队列 → 0009 贪心 → 0010-0011 遍历与图算法 → 0035 五大策略识别 → 0034 试题四填空——上午的策略题和下午的算法题是同一条线。
  3. 设计大线（软工 ↔ DB ↔ OO）：0027 DFD 结构化分析 → 0022 E-R 数据设计 → 0031 UML 面向对象设计 → 0032 模式——同一件事（把需求变成设计）的三种方法论，分别对应下午试题一、二、三。

第三层 · 体怎么收口：考前只看这四行

  1. 九个面的题量分布（本页第一层各面标题括号里的数字）——上午卷的复习时间按题量分；
  2. 五道大题对应五条线——试题一 ← 0027 的 DFD；试题二 ← 0022-0023 的 E-R 与 SQL；试题三 ← 0031 的 UML；试题四 ← 0034-0035 的算法；试题五/六 ← 0032 的模式；
  3. 三条跨面接线——能复述上面第二层的走廊/策略/设计三条大线，面就拼成体了；
  4. 按线推进——课程总目录的线性顺序就是把九个面串成的时间线，学到哪一课、线就铺到哪。
