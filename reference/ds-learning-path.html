Reference · 课程总目录

课程总目录：35 课全部建成，序号从小到大 = 学习顺序

依据：高频必考清单（各科目分值定位）

🎯 顺序这样定 全部 34 课已按新手小白的认知顺序重排（序号 = 学习顺序）：① 计算机组成（机器怎么存数算数）→ ② 程序语言（代码怎么变成程序）→ ③ 数据结构与算法（数据怎么组织，10 课大头）→ ④ 操作系统（程序怎么被管理）→ ⑤ 数据库 → ⑥ 网络 + 安全 → ⑦ 软件工程 → ⑧ 面向对象（UML + 设计模式）→ ⑨ 保底专项 → ⑩ 算法实战（试题四填空 + 五大策略识别）。每一环只依赖前面的环节，跟着序号走即可。

第一部分 · 计算机组成（0001–0003，机器怎么存数算数）

课号内容考试考法（考频）
0001 组成计算专题进制、补码与表示范围、IEEE754 浮点、海明/CRC/奇偶校验、可靠性串并联、RAID纯计算 3~4 题/年，公式送分
0002 CPU 寻址与流水线寄存器职责、8 种寻址方式有效地址、流水线 (k+n−1)Δt 与加速比寻址 + 流水线计算每年必考
0003 Cache 与总线命中率与平均访存时间、三种映射方式、总线带宽计算Cache 计算必考
