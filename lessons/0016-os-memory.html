OS 内存管理：分页地址转换、虚拟内存与页面置换

🎯 这课的赢面 两个「算分器」：①页式地址转换三步公式（P=LA÷S 取整、W=LA mod S、物理地址=块号×S+W）——用下面的计算挑战刷到条件反射；②置换算法缺页次数——用模拟器亲眼看 FIFO 怎么触发 Belady 异常（块数变多缺页反而变多）。

一、分页存储：把内存切成固定大小的页框

逻辑地址空间切成页，物理内存切成同样大小的块（页框），靠页表记录「第 i 页 → 第 b 块」。优点：无外部碎片（0020 Q10：只有内部碎片）；缺点：页表本身占内存、多一次访存。

页号 P = 逻辑地址 LA ÷ 页大小 S（取整）　页内偏移 W = LA mod S
物理地址 = 块号 × S + W　　（口诀：页式乘、段式加）

例：页大小 1 KB（1024 B），逻辑地址 5000 → P = 5000÷1024 取整 = 4，W = 5000 mod 1024 = 904；查页表第 4 页 → 块 8 → 物理地址 = 8×1024+904 = 9224。页大小是 2 的幂时可直接二进制切位：低位 = 偏移，高位 = 页号。

⚠ 对比：段式 段式 = 段基址 + 段内偏移（段长可变、利于共享保护、产生外部碎片）；段页式 = 先分段、段内分页（先查段表再查页表）。

二、访存次数与 TLB

一级页表：2 次访存（查表 1 + 取数 1）｜二级：3 次｜三级：4 次｜TLB 命中：1 次
  • TLB（快表） = 相联存储器实现的页表项缓存——硬件并行查找，不算访存；命中则页框号直接到手。
  • 有效访问时间 EAT = h×(t1+t2) + (1−h)×(t1+2t2)（t1 查表、t2 取数，h 为命中率；二级页表把 t1 展开）。
  • 缺页中断是内部异常，在指令执行期间产生，处理后重新执行该指令。

三、虚拟内存与置换算法

虚拟内存：进程只装部分页面即可运行（依据局部性原理）。三特征：多次性、对换性、虚拟性。访问不在内存的页 → 缺页 → 从磁盘调入 → 内存满则置换一页出去。谁出去？四种算法：

算法淘汰谁要点
OPT 最优未来最久不用的页理论最低缺页率，无法实现（要预知未来），作评价基准
FIFO 先进先出最早进入的页唯一会出现 Belady 异常（块数变多缺页反而变多）
LRU 最近最久未用最久未被访问的页看「过去」，硬件开销大；LRU ≠ LFU（LFU 数次数）
Clock（NRU）访问位循环扫描LRU 的低成本近似
