磁盘调度：一场「磁头怎么走」的贪心与折返

🎯 为什么是它 磁盘调度是考试大纲里 OS 板块的必考计算题（高频清单：SSTF/SCAN 计算寻道长度）。今天的 25 道综合练习里有 3 道寻道计算。学完本课，你应当能在 90 秒内独立算出任意算法的总寻道距离——这是今天上午输入时段的第一个「可带走的赢面」。

一、最小必要知识（先记住这三块）

1. 存取时间三段式：调度算法只优化其中一段

平均存取时间 Ta = 平均寻道时间 Ts + 平均旋转延迟 Tr + 传输时间 Tt
  • 寻道 Ts：磁头径向移动（机械，最慢）—— 磁盘调度算法优化的就是它
  • 旋转 Tr：平均按转半圈算：30 ÷ 转速（秒）
  • 传输 Tt：读一个扇区 = 转一圈 ÷ 每道扇区数；读一个磁道 = 转一圈
转速转一圈平均旋转延迟（半圈）
3600 r/min16.67 ms8.33 ms
5400 r/min11.11 ms5.56 ms
7200 r/min8.33 ms4.17 ms
10000 r/min6.00 ms3.00 ms
⚠ 易错 「读一个扇区」的传输时间 = 转一圈 ÷ 每道扇区数；「读一个磁道」= 转一圈。两者千万别混。

2. 六种算法一句话

算法一句话死穴
FCFS排队，来一个服务一个磁头反复横跳，最慢
SSTF就近原则，谁近先服务谁会饥饿，且不是最优
SCAN电梯：一路走到底（物理端点）再反向端点空走
C-SCAN单行道：单向服务，到端后空跳回另一端继续同向回程不服务但计入距离
LOOKSCAN 的聪明版：走到最远请求就折返—
C-LOOKC-SCAN 的聪明版：跳回最远请求而非端点—

3. 四条考场铁律

  1. SSTF ≠ 最优：贪心会折返跑（本课模拟器里 LOOK 比 SSTF 还少走 16 个柱面）。
  2. SCAN 走到端，LOOK 只到最远请求：SCAN − LOOK = 端点空走距离 × 2。
  3. C-SCAN 回程不服务、但计入距离：题干问「磁头移动总距离」→ 全程计入；只有明确说「只算服务过程」才可能扣掉。不确定就按全程并在解答写明口径。
  4. 平均寻道距离 = 总距离 ÷ 请求个数（分母不是移动段数！）。

二、动手：磁头到底怎么走？（核心交互）

下面是你原资料 §3.2 的同一道例题：200 个柱面（0–199），磁头起点 100，朝 0 方向移动，请求队列 108, 90, 88, 60, 130, 40, 160, 20。

玩法：先在心里推演下一步磁头服务哪个请求，再点选项。答对才前进，答错会给你该算法的判别口诀。六个算法都走一遍，看看四个总数 476 / 236 / 260 / 220 / 390 / 272 是怎么一步步加出来的。

💡 观察任务 走完 SSTF 和 LOOK 后对比：SSTF 第 1 步去了 108，导致后面必须一路折返；LOOK 一路向左到底再折返反而更短。这就是「SSTF 非最优」的具体形状——选择题考的就是这一眼。

三、检索练习（先回忆，再作答）

✅ 本课一页收获
  1. Ta = 寻道 + 旋转(半圈) + 传输；调度算法只优化寻道；7200 转 → 半圈 4.17 ms。
  2. 六算法顺序记住本例六个数：FCFS 476 → SSTF 236 → SCAN 260 → LOOK 220 → C-SCAN 390 → C-LOOK 272，且 LOOK 220 < SSTF 236 证明 SSTF 非最优。
  3. SCAN−LOOK = 端点空走×2；C-SCAN 回程计入距离；平均 = 总距离 ÷ 请求个数。
