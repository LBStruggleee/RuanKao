测试与 McCabe：覆盖六级 + 圈复杂度三算

课程总目录 ｜ 预计 40 分钟 ｜ 上一课：0027 过程模型与 DFD
考点定位：黑盒三法、白盒覆盖六级、McCabe 圈复杂度 V=E−N+2（必考计算，day13-test.md）

🎯 这课的赢面 一句定位词分清测试类型（单元/集成/系统/验收、黑盒看功能白盒看结构），六级覆盖按强度排序，McCabe 三个公式互相换算：V = E − N + 2 = 判定节点数 + 1 = 封闭区域数。

一、测试分类（一句定位词）

阶段谁来做定位词
单元测试开发者单个模块；常用白盒；需要驱动/桩模块
集成测试开发者/测试模块拼起来；接口；自顶向下需桩模块、自底向上需驱动模块
系统测试独立测试整个系统（性能/安全/恢复…）
验收测试用户主导Alpha 在开发方场地、Beta 在用户实际环境

黑盒（功能）三法：等价类（有效+无效类各取代表）、边界值（在等价类边界多测一发——最易出错的点）、因果图（条件组合）。白盒（结构）：逻辑覆盖，见下。

二、白盒覆盖六级（由弱到强）

语句 ⊂ 判定 ⊂ 条件/判定-条件 ⊂ 条件组合 ⊂ 路径
覆盖要求记忆
语句覆盖每条语句至少执行一次最弱
判定覆盖（分支）每个判定的真/假分支各走一次比语句强
条件覆盖每个原子条件真假各一次不保证判定覆盖（条件都对但判定结果可能同向）
判定-条件覆盖判定 + 条件都满足两者合体
条件组合覆盖每个判定内条件取值组合全覆盖组合爆炸
路径覆盖所有可能路径最强、通常不可行

三、McCabe 圈复杂度 V(G)（必考计算）

V(G) = E − N + 2（边−节点+2） = 判定节点数 + 1 = 封闭区域数
  • 控制流图化简：顺序语句合并成一个节点；if/while/for 每个判定算 1 个判定节点；case 分支按判定算。
  • V(G) = 线性独立路径数（再新增一条边都必是新路径）；经验值 V ≤ 10 为宜。
  • 例：两个串联 if 的程序：E=6、N=5 → V = 6−5+2 = 3；用判定数验证：2 个判定 + 1 = 3 ✓。

四、自查（先画图数一遍再点）

✅ 本课一页收获
  1. 测试定位：单元白盒、验收用户主导（Alpha/Beta）；集成自顶向下用桩、自底向上用驱动。
  2. 黑盒三法：等价类/边界值/因果图；白盒六级：语句→判定→条件→判定-条件→条件组合→路径。
  3. 条件覆盖不保证判定覆盖。
  4. V = E−N+2 = 判定数+1 = 区域数 = 独立路径数。
