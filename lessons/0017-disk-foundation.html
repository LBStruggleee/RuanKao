一、磁盘长什么样：一张「会转的黑胶唱片」

机械硬盘就是若干张涂了磁性涂层的圆盘（盘片）串在一根主轴上高速旋转，每张盘面的上方悬浮一根「唱针」（磁头）。数据就是盘面上一个个磁性小格子。

      一张盘片（像黑胶唱片）              三张盘片叠在同一根主轴上
    ┌─────────────────────────┐
    │   ╭─────────────────╮   │          盘面0 ─── 磁头0 ──┐
    │  ╭──╭───────────╮──╮  │          盘面1 ─── 磁头1 ──┤  所有磁头绑在
    │  │  │ ·扇区▓▓·  │  │  │          盘面2 ─── 磁头2 ──┘  同一根臂上，
    │  ╰──╰───────────╯──╯  │                              一起左右移动
    │   ╰─────────────────╯   │
    └─────────────────────────┘    同一半径的磁道垂直叠成一摞 = 柱面
     磁道 = 同心圆（一圈一圈）      扇区 = 磁道上的一段弧（最小读写单位）

四个名词，从大到小：

名词是什么一个比喻
盘面一张盘片的正/反面，每面一个磁头唱片的 A 面 / B 面
磁道盘面上的同心圆，从外向内编号 0,1,2…操场的一条条跑道圈
扇区磁道上的一段弧，磁盘读写的最小单位（通常 512 B 或 4 KB）跑道上划出的一段（100 m 处）
柱面所有盘面上半径相同的磁道的集合双层停车场的同一圈车道上下对齐成一摞
💡 为什么有「柱面」 所有磁头绑在同一根臂上、一起径向移动——磁头挪一次，每张盘面同时都停在了「同一个半径」上。所以「移动到第 X 柱面」是一步到位的，柱面号就是磁头的位置刻度。

二、读一个数据的四步（点着走一遍）

① 磁头臂沿半径移动 → 定位到目标柱面 ← 寻道时间（机械，最慢） ② 选中对应盘面的磁头（电子开关） ← 忽略不计 ③ 盘片旋转，目标扇区转到磁头正下方 ← 旋转延迟（平均半圈） ④ 扇区连续掠过磁头，数据被读出 ← 传输时间

💡 记住这个比例 第①步是机械大幅移动，毫秒级、占大头；②③④要么是电子动作、要么是「等盘自己转」。所以省时间 = 省第①步——这就是 Lesson 0018 磁盘调度算法唯一优化「寻道时间」的原因。公式 Ta = 寻道 + 旋转 + 传输 就是这四步去掉第②步。

三、换算三件套（0005 所有数字的来源）

1. 时间单位：每一级 ×1000

1 s（秒）= 1,000 ms（毫秒）= 1,000,000 μs（微秒）

跟米、毫米、微米一个道理，只是名字换成秒。所以 0.00833 s = 8.33 ms（小数点右移三位）。

2. 转速 → 转一圈时间：两步法

① 每秒圈数 = 转速 ÷ 60　② 转一圈 = 60 ÷ 转速（秒）

以 7200 转/分为例：7200 ÷ 60 = 120 圈/秒（一分钟 60 秒，所以除以 60）→ 一圈 = 60 ÷ 7200 = 0.00833 s → ×1000 → 8.33 ms。
每秒转 120 圈，一圈当然就是 1/120 秒——两条路殊途同归。

3. 存储单位：每一级 ×1024

1 KB = 1024 B　1 MB = 1024 KB　1 GB = 1024 MB

为什么不是 1000？计算机是二进制的，2¹⁰ = 1024 最接近一千。4 KB = 4 × 1024 = 4096 B——Lesson 0019 索引计算的第一个数字就是它。

四、为什么「平均旋转延迟」是半圈

磁头挪到目标磁道后，目标扇区此刻在圆周的哪个位置是随机的：

  • 运气最好：刚好在磁头下 → 等 0 圈；
  • 运气最差：刚掠过去 → 等整整 1 圈；
  • 所有位置等概率 → 平均等 1/2 圈。

就像「公交车每 10 分钟一班、你随机到站，平均要等 5 分钟」。所以公式是：

平均旋转延迟 = 半圈 = 30 ÷ 转速（转/分）秒　→　7200 转/分 = 4.17 ms

五、「距离」怎么算：柱面号就是数轴

把柱面 0~199 排成一条数轴，磁头从 a 挪到 b 的距离 = |a − b|（来回都算路程，方向不影响长度）：

移动算式距离
100 → 108|100 − 108|8
108 → 90|108 − 90|18
90 → 88|90 − 88|2

而磁盘调度算法的全部内容就是一句话：决定「按什么顺序访问这 8 个请求柱面」，让每段 |差| 加起来的总和最小。按到达顺序加 = FCFS（476）；就近挑 = SSTF（236）……Lesson 0018 的模拟器算的就是这个总和。

✅ 本课一页收获
  1. 盘面 ⊃ 柱面（同半径磁道一摞）⊃ 磁道（同心圆）⊃ 扇区（最小读写单位）。
  2. 读数据四步 = 寻道（磁头挪，唯一可优化）+ 选面（忽略）+ 旋转（平均半圈）+ 传输（一圈÷扇区数）。
  3. 时间单位 ×1000 链；转一圈 = 60÷转速；存储单位 ×1024 链。
  4. 调度算法 = 在数轴上决定访问顺序，让 |差| 之和最小。
