一、三大类怎么分

类别管什么成员（23 种）
创建型（5）对象怎么造单例、工厂方法、抽象工厂、建造者、原型
结构型（7）对象怎么拼适配器、桥接、组合、装饰、外观、享元、代理
行为型（11）对象怎么协作职责链、命令、解释器、迭代器、中介者、备忘录、观察者、状态、策略、模板方法、访问者

二、高频模式速查（题眼 → 模式）

题眼（场景关键词）模式意图一句话
全局唯一 / 一个类只有一个实例 / 提供全局访问点单例懒汉（用时才建，需防并发）/ 饿汉（加载即建，天然线程安全）
子类决定实例化哪个类 / 延迟到子类工厂方法定义创建接口，让子类决定造谁
创建一族相关产品（产品族）抽象工厂一个工厂造一整套
分步组装复杂对象 / 相同构建过程不同表示建造者把「组装步骤」与「表示」分离
复制克隆已有对象原型用克隆替代 new
接口不兼容要转换适配器把旧接口包成目标接口
抽象与实现分离各自独立变化桥接两个变化维度解耦
树形部分-整体（文件/文件夹）组合单个与容器统一对待
动态给对象加职责 / 不改类加功能装饰一层层包（Java IO 流）
统一复杂子系统的简单入口外观（门面）一个类包装一堆调用
共享细粒度对象 / 大量重复对象省内存享元共享内部状态（2021 下试题六）
控制访问 / 远程 / 保护代理占位并控制对目标的访问
请求沿链条逐级传递 / 谁处理看级别职责链审批流
把请求封装成对象 / 可撤销命令请求参数化、排队、日志
一对多通知 / 发布-订阅观察者主题变 → 订阅者全部收到通知
保存与恢复对象状态（撤销/存档）备忘录不破坏封装地存快照（2022 上试题五）
行为随状态改变（状态机）状态状态变 → 行为变
算法可整体替换（策略 interchangeable）策略同一接口不同算法
固定骨架、子类填细节模板方法父类定流程，子类填步骤

三、大题答题三步（试题五/六）

  1. 读说明找题眼（「唯一实例」→单例；「保存/恢复」→备忘录；「通知」→观察者）；
  2. 对类图填角色：抽象/具体、Subject/Observer、Memento/Originator/Caretaker……；
  3. 按签名填代码：看方法名和返回类型反推空缺内容，别自创变量名。

四、自查（全对过课）

✅ 本课一页收获
  1. 三大类：创建 5（单例/工厂方法/抽象工厂/建造者/原型）、结构 7（适配器/桥接/组合/装饰/外观/享元/代理）、行为 11。
  2. 题眼直查：唯一实例→单例；产品族→抽象工厂；树形→组合；动态加职责→装饰；发布订阅→观察者；保存恢复→备忘录；算法替换→策略；骨架细节→模板方法。
  3. 单例：懒汉用时建（防并发）、饿汉加载建（线程安全）。
  4. 大题三步：找题眼 → 填角色 → 按签名补码。
