面向对象基础：三大特征、接口抽象类与 OO 原则

🎯 这课的赢面 三组一句话判据：重载看参数、重看父子类（重载=编译期绑定，重写=运行期动态绑定）；接口是『能做什么』，抽象类是『是什么』；设计原则考场景对应——「对扩展开放对修改关闭」= 开闭原则。

🧭 体系定位：面 8 面向对象 · OO 基础线——三大特征/类接口抽象类/七原则。上游：新面起点（0027 的面向对象分支）；下游：0031/0032（回地图）

一、面向对象三大特征：封装、继承、多态

特征一句话定义带来的好处 / 考点
封装把数据与操作捆绑在类里，隐藏内部实现，只暴露接口信息隐藏、降低耦合；考法：private 字段 + public 方法 = 封装
继承子类自动拥有父类的属性与方法，并可扩展/重写复用 + 建立层次；继承是类之间的关系（ general→special 泛化）
多态同一消息发给不同对象，各自有不同的响应父类引用指向子类对象，调用的是实际对象的方法——动态绑定

多态的两种形态（必考区分）：

重载 Overload重写 Override
发生位置同一个类里父子类之间
方法签名同名不同参数（返回类型可同可不同）同名同参数（子类重新实现）
绑定时机编译期静态绑定运行期动态绑定

判断句式：「根据参数个数与类型在编译时确定调用哪个方法」= 重载；「运行时根据对象实际类型决定执行哪个版本」= 重写/动态绑定。

二、类、接口与抽象类：三者的边界

对比抽象类接口
语义『是什么』（is-a，抽取公共实现）『能做什么』（can-do，能力契约）
方法可有抽象方法 + 可有具体实现（传统）全抽象方法，不能有实现
继承单继承（一个类只有一个直接父类）可多实现（一个类实现多个接口）
成员变量可有实例字段只能是常量

考法：给场景选容器——多个鸟类共享 fly() 的公共代码 → 抽象类；要求「可序列化」「可比较」这类能力标签 → 接口。「一个子类只能继承一个父类，但可实现多个接口」是标准判断句。

三、OO 七大设计原则：给场景选原则

原则一句话场景关键词
开闭原则（OCP）对扩展开放，对修改关闭加新功能不改老代码（多态/策略实现）
单一职责（SRP）一个类只负责一件事「职责过多导致变化相互影响」
里氏替换（LSP）子类必须能替掉父类而不破坏程序「子类不应加强前置条件/削弱后置条件」
依赖倒置（DIP）依赖抽象，不依赖具体实现「高层模块不应依赖低层模块」
接口隔离（ISP）多个专用接口好过一个胖接口「不应强迫客户依赖用不到的方法」
迪米特法则（LoD）只与直接朋友通信，少知道别人内部「降低耦合、中介转达」
组合复用（CRP）优先用组合/聚合，少用继承「继承滥用导致强耦合」
⚠ 与设计模式的连接 每个模式都是若干原则的落地：0032 的策略模式 = 开闭 + 依赖倒置；外观模式 = 迪米特法则；装饰器 = 组合复用。先认原则再看模式，一眼就懂。

四、OO 分析与设计：概念题的另外几个钉子

  • 对象三要素：对象标识（OID）、属性（状态）、服务/方法（行为）。
  • 类 vs 对象：类是模板/抽象，对象是实例——「类是静态定义，对象是运行期动态创建」。
  • 用例图三要素：参与者、用例、关系；include = 必然包含的公共行为（抽取复用），extend = 可选/异常扩展。
  • OOA → OOD → OOP：分析建「做什么」的模型（用例/领域模型），设计建「怎么做」的模型（类图/交互图），编程落地。

五、自查（全对过课）

✅ 本课一页收获
  1. 封装隐藏实现、继承建立层次、多态一消息多响应。
  2. 重载同类不同参、编译期绑定；重写父子同签名、运行期动态绑定。
  3. 抽象类『是什么』可有实现、单继承；接口『能做什么』全抽象、多实现。
  4. 七原则场景映射：加功能不改码=开闭、只与直接朋友通信=迪米特、依赖抽象=依赖倒置。
  5. include 必然包含、extend 可选扩展——用例图两关系的分水岭。
