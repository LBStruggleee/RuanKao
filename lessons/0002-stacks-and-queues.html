栈与队列：只能在一头动的两种结构

课程总目录 ｜ 预计 35 分钟 ｜ 上一课：0001 数组与链表
考点定位：进出栈序列合法性（2021H2-Q58 原题考过辨析）、循环队列判满判空与元素个数计算（高频）

🎯 这课的赢面 学完你能：①秒判「一个出栈序列合不合法」；②背死循环队列三条公式（个数 / 判满 / 判空）。这两类题年年见。另外记住一条暗线：DFS 用栈、BFS 用队列——Lesson 0006 图遍历直接踩在这。

一、栈：叠盘子（后进先出 LIFO）

栈就是一摞只能动最上面那只的盘子：放盘子叫进栈（push），拿走最上面的叫出栈（pop），最上面那只叫栈顶。规则只有一条：后进先出——最后放的最先被拿走。

为什么要有它：凡是「最近发生的要先处理」的场景都是栈——

  • 函数调用 / 递归：调用的函数先返回（系统帮你用栈管现场）——递归的本质就是栈；
  • 表达式求值、括号匹配：最近出现的左括号最先被匹配；
  • 深度优先搜索 DFS（Lesson 0006 会亲手用到）。

二、必考：出栈序列合不合法？

元素按 1, 2, 3, … 顺序进栈（进栈时机可以自己选），问某个出栈序列是否可能。方法只有一种：亲手模拟——按出栈序列逐个处理，需要谁就先把比它小的全进栈：

例：判断 4, 3, 5, 2, 1 是否合法（进栈序 1–5）：

要出 4 → 先进 1,2,3,4 → 出 4；要出 3 → 栈顶正好 3 → 出 3；要出 5 → 进 5 → 出 5；要出 2 → 栈顶 2 → 出 2；要出 1 → 出 1。全程顺畅 → 合法 ✓

反例：5, 1, 2, 3, 4：要出 5 → 进 1,2,3,4,5 → 出 5；再要出 1 时，1 被 2,3,4 压在下面，而新元素已用完 → 不合法 ✗

💡 背一个数字 n 个元素的合法出栈序列共有卡特兰数种 = C(2n, n) ÷ (n+1)：n=3 → 5 种，n=4 → 14 种。小题直接选。另一个冷知识：n 个节点的二叉树形状数也是这个数（Lesson 0004 会见到同一个 5）。

三、队列：排队（先进先出 FIFO）

队列是排队：从队尾入队，从队头出队，先进先出。「入队出队分别在两端」——记牢这句，2021H2 真题就是把「同一端」的栈混进队列选项里。

应用场景：打印缓冲、消息队列、操作系统就绪队列（Day 1 的 RR 调度就是从队列头取进程）、广度优先搜索 BFS。

四、必考计算：循环队列

数组实现的队列会「假溢出」——出队后前面空着却不能再入队。解决办法：首尾相连成环（取模绕圈）。

入队：rear = (rear + 1) mod M　　出队：front = (front + 1) mod M
判断公式（必背）为什么
元素个数(rear − front + M) mod M加减 M 保证非负（rear 可能绕到了 front 后面）
队满(rear + 1) mod M == front牺牲一格：永远留一格空，否则满和空都是 front==rear，无法区分
队空front == rear进出追平了
⚠ 口径与陷阱 本课口径：rear 指向队尾元素的下一位置（进队先放元素再 rear+1）。题目若声明别的口径（如带 count 变量），按题干走——但「牺牲一格」是教材默认，最能出计算题。

五、动手：栈自己玩，循环队列盯指针

六、自查（全对过课）

✅ 本课一页收获
  1. 栈 = 后进先出、只能动栈顶（递归/DFS）；队列 = 先进先出、两端各管一头（BFS/就绪队列）。
  2. 出栈序列合法性：亲手模拟；n=3 共 5 种、n=4 共 14 种（卡特兰数）。
  3. 循环队列：个数 = (rear−front+M) mod M；队满 = (rear+1) mod M == front（牺牲一格）；队空 = front == rear。
  4. 暗线：DFS 用栈、BFS 用队列 → Lesson 0006。
