考点定位：补码表示范围、海明码校验位数、可靠性串联并联——每年 3~4 道纯计算题的集中地，公式背熟就是送分

🎯 这课的赢面 五个公式五个分：补码范围 −2n−1 ~ 2n−1−1；海明 2k ≥ n+k+1；串联 R=R₁R₂ / 并联 1−(1−R₁)(1−R₂)；奇偶校验只能检奇数位错；RAID5 坏 1 块可恢复。全是套公式，动笔就能拿分。

一、补码：让减法变成加法

计算机里整数一律用补码存储——加法器同时搞定减法。规则：正数的原码反码补码相同；负数：反码 = 原码按位取反，补码 = 反码 + 1。

n 位补码表示范围：−2n−1 ~ +2n−1−1（负数多一个，因为 0 只占一种编码）
位数表示范围记忆点
8 位−128 ~ +127−128 = 1000 0000，没有对应的 +128
16 位−32768 ~ +32767−2¹⁵ ~ 2¹⁵−1
通用−2n−1 ~ 2n−1−1『负多一』必考判断题

例：−1 的 8 位补码：|−1|=0000 0001 → 反码 1111 1110 → 补码 1111 1111。规律：全 1 就是 −1；从 1111 1111（−1）往上减 1 就是 −2、−3…

二、浮点数：阶码定范围，尾数定精度

浮点数 N = 尾数 × 2阶码。IEEE 754（32 位 float）：1 位符号 + 8 位移码阶码 + 23 位尾数（隐含首位 1，实际精度 24 位）。

  • 对阶原则：小阶向大阶看齐（小阶尾数右移，丢失的是最低位，误差小）——必考判断。
  • 阶码位数决定表示范围；尾数位数决定精度——两者此消彼长。
  • 规格化：尾数最高有效位必须是 1（原码尾数 0.1xxx 形式），提高精度。

三、校验码三兄弟：检一位、纠一位、检任意位

校验码原理能力
奇偶校验补 1 位使整个码字 1 的个数为奇/偶只能发现奇数个位错，不能纠错，不能发现偶数位错
海明码k 位校验位嵌入 2i 位置（1,2,4,8…），分组偶校验发现并纠正 1 位错（检测 2 位错）
CRC 循环冗余模 2 除法（异或）得校验位拼接在尾部检错能力极强（教材口径：只检错不纠错），靠硬件实现

海明码位数公式（必考）：信息位 n 位需校验位 k 位，满足：

2k ≥ n + k + 1

例：n=4 → 试 k=3：2³=8 ≥ 4+3+1=8 ✓ → 需 3 位校验。n=11 → k=4：16 ≥ 16 ✓ → 4 位。口诀：4 位信息 3 校验，11 位信息 4 校验，26 位信息 5 校验。

CRC 手算例：信息 10110，生成多项式 G(x) = x³+x+1（即 1011，r=3 位）：信息左移 3 位 → 10110000，对 1011 做模 2 除法（不借位异或）得余数 r₂r₁r₀，拼成 10110 r₂r₁r₀ 发送。接收方用同一多项式除：余数为 0 即无错。

四、可靠性：串联靠乘，并联靠补

串联（一个坏全坏）：R = R₁ × R₂ × … × Rn
并联（冗余备份）：R = 1 − (1−R₁)(1−R₂)…(1−Rn)

例：两个部件 R₁=R₂=0.9：串联 R = 0.81（更不可靠）；并联 R = 1 − 0.1×0.1 = 0.99（更可靠）。

混合系统：先并联成组，再串联相乘。如「子系统 A（两个 0.9 并联）与子系统 B（0.9）串联」：A = 0.99 → 总 R = 0.99 × 0.9 = 0.891。

MTBF 平均无故障时间：可靠性 R(t) = e−λt，MTBF = 1/λ。失效率 λ 越小越可靠。

五、RAID：冗余磁盘阵列速查

级别技术特点
RAID 0条带化（数据分块分布到多盘）读写最快、无冗余，坏一块全丢——利用率 100%
RAID 1镜像（两两互备）可靠性最高，利用率 50%，成本最高
RAID 5分布式奇偶校验（校验信息分散在各盘）坏任意 1 块可恢复，利用率 (n−1)/n，最常用
RAID 6双重校验坏 2 块可恢复，写性能更低

✅ 本课一页收获
  1. 补码范围 −2n−1 ~ 2n−1−1（8 位 −128~127）；全 1 = −1。
  2. 浮点：对阶小阶向大阶；阶码管范围、尾数管精度。
  3. 奇偶校验检奇数位错；海明 2k ≥ n+k+1 可纠 1 位；CRC 只检错不纠错、余 0 无错。
  4. 串联相乘、并联 1−∏(1−R)；MTBF = 1/λ。
  5. RAID0 快无冗余、RAID1 镜像 50%、RAID5 坏 1 块可恢复。
