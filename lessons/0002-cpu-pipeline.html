一、CPU 里谁管什么（寄存器职责）

部件职责考点一句话
PC 程序计数器存下一条指令的地址『自动 +1』指向下一条，转移指令改写它
IR 指令寄存器存当前正在执行的指令PC 管地址、IR 管指令本体
指令译码器解析操作码控制器的一部分
MAR / MDR存储器地址/数据寄存器访问内存的『门牌』与『包裹』
ALU + ACC + PSW算术逻辑运算、累加器、状态字（进位/溢出/零标志）运算器侧

指令执行三步：取指 → 译码（分析） → 执行。控制器 = PC/IR/译码器/时序；运算器 = ALU/ACC/PSW。

二、8 种寻址方式（有效地址公式表）

方式有效地址 EA特点/速度典型用途
立即寻址操作数就在指令里最快（不访存）常数赋值
直接寻址EA = A访存 1 次—
间接寻址EA = (A)访存 2 次以上，最慢—
寄存器寻址EA = Ri（操作数在寄存器）最快访问之一—
寄存器间接EA = (Ri)访存 1 次指针
基址寻址EA = 基址寄存器 + 偏移系统管理基址，程序不可改程序重定位/浮动
变址寻址EA = 变址寄存器 + 形式地址用户可改变址数组循环遍历
相对寻址EA = PC + 偏移与位置无关转移指令
⚠ 高频辨析 基址 vs 变址：都是「寄存器 + 偏移」，区别在谁能改——基址寄存器由操作系统管理（程序浮动），变址寄存器由用户修改（数组下标）。

三、指令流水线（必考计算）

等长 Δt，k 段 n 条：T = (k + n − 1)Δt　　加速比 S = nk / (k + n − 1)（极限 → k）
不等长各段 ti：T = Σti（首条） + (n − 1) × max(ti)　　吞吐率 TP = n / T

例（原资料 §4 原题）：4 段流水线，各段 10/15/20/10 ns，共 100 条指令：

T = (10+15+20+10) + (100−1)×20 = 55 + 1980 = 2035 ns；
S = 100×55 ÷ 2035 ≈ 2.70；TP = 100 ÷ 2035ns ≈ 4.91×10⁷ 条/秒。

等长例：5 段 × Δt=1ns × 10 条 → T = (5+9)×1 = 14ns，S = 50/14 ≈ 3.57。

CISC vs RISC：RISC = 指令定长、种类少、寻址方式少、寄存器多、以硬布线/组合逻辑为主、适合流水线；CISC = 指令变长、种类多、微程序控制。

✅ 本课一页收获
  1. PC 存下一条指令地址、IR 存当前指令；控制器 vs 运算器各管一摊。
  2. 寻址：立即最快；间接最慢；基址=系统管理（浮动）、变址=用户改（数组）、相对=PC+偏移。
  3. 流水线：T = (k+n−1)Δt；不等长 T = Σti + (n−1)maxΔt；S = nk/(k+n−1) 极限 k；TP = n/T。
  4. RISC：定长、少种类、多寄存器、硬布线、宜流水线。
