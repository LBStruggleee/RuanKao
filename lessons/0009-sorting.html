排序总表：一张表 + 一句口诀收官

考点定位：稳定性判别、复杂度对比（2021H1-Q63 原题）、一趟排序结果手算

🎯 这课的赢面 排序题的答案 90% 在一张表里：复杂度 + 稳定性。口诀记不稳定家族「快选希堆」（快排、简单选择、希尔、堆），其余都稳定。再用步进实验室亲眼看完三种 O(n²) 排序的每一步比较。

💡 口诀 不稳定家族：「快选希堆」（快排、简单选择、希尔、堆排序）；其余全稳定（插入、冒泡、归并、基数）。考试问『哪些稳定/不稳定』，先写这四个再验。

二、稳定性是什么（配一个反例）

稳定 = 值相等的两个元素，排完序后相对先后次序不变。为什么快排/选择会变？看简单选择的反例：

  [ 3a, 3b, 1 ]  →  第一趟选最小 1，与第 0 位交换 → [ 1, 3b, 3a ]
  3a 和 3b 次序颠倒了 → 简单选择排序不稳定 ✘

稳定有什么用？多关键字排序：先按姓名排、再按部门稳定排——同部门内仍保持姓名序。不稳定做不到。

三、三个高频结论（从表里读出来）

  1. 序列基本有序：直接插入最快（≈O(n)，几乎不用移）；快排最坏（枢轴总选在头上，切不均匀 → O(n²)）。
  2. 只想要前 k 大/小：堆排序（topK 用小顶堆/大顶堆）。
  3. 一趟排序之后：冒泡把最大值顶到末尾；快排把枢轴放到它的最终位置——「第 k 趟后某元素是否就位」就按这两句验算。

四、动手：三种 O(n²) 排序逐步看

💡 观察任务 同一个序列 [5,2,8,3,9,1] 分别跑三种算法，盯住右下角的比较次数：选择排序的比较次数固定不变；插入排序在基本有序序列（如 [1,2,3,5,8,9]）上会骤降——把序列换成基本有序的再跑一遍插入试试。

五、自查（全对过课）

✅ 本课一页收获
  1. 不稳定家族「快选希堆」；其余（插入/冒泡/归并/基数）稳定。
  2. 基本有序：直接插入 ≈O(n) 最爽、快排 O(n²) 最惨。
  3. 快排一趟 = 枢轴归位；冒泡一趟 = 最大值沉底。
  4. 堆建堆 O(n)、堆排 O(n log n) 不稳定；归并稳定但要 O(n) 辅助空间。
