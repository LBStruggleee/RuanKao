📝 书写规范（本课及全站通用） 数字后缀的字母标注它是什么进制——B = 二进制、O = 八进制、D = 十进制、H = 十六进制（取英文首字母：Binary / Octal / Decimal / Hexadecimal，汇编语言与软考通用写法）。
例：1011B 是二进制、332O 是八进制、25D 是十进制、1AH 是十六进制（A~F = 10~15）。不带标注的数字默认就是十进制；真题里偶尔用括号下标 (1011)₂，写法不同、读法一样，和 1011B 是同一个数。注意 O 是字母 O不是数字 0——手写笔记时写得圆一点以示区分。

一、R 进制 → 十进制：按权展开（一切转换的原点）

先从你最熟的十进制说起：25 为什么是 25？因为它是 2×10 + 5×1——「2」站在十位上所以乘 10，「5」站在个位上所以乘 1。每一位都有一个「座位值」，这个座位值就叫「权」；十进制的权从右往左是 1、10、100、1000…（每个是前一个的 10 倍），因为十进制逢十进一。

任何 R 进制都一样，只是「座位值」翻倍的节奏变了：

  • 基数 R = 这个进制用几个数码：二进制用 2 个（0、1），八进制用 8 个（0~7），十六进制用 16 个（0~9 和 A~F，A=10…F=15）；
  • 每一位的权 = R 的若干次方：从最右边那位开始数，第 1 位是 R⁰（个位，值是 1）、往左每一位都乘一次 R——第 2 位是 R¹、第 3 位是 R²……就像十进制从个位往左是 1、10、100 一样；
  • 按权展开就是一句话：把每位数字乘上它所在位的权，再全部加起来。

例 1：1011B = 1×2³ + 0×2² + 1×2¹ + 1×2⁰ = 8+0+2+1 = 11

例 2（带字母）：1AH = 1×16 + 10 = 26（A 就是 10，别看到字母就慌）

例 3（小数）：小数点往右，权依次减半——小数点后第 1 位权是 0.5（=2⁻¹）、第 2 位是 0.25（=2⁻²）……11.01B = 1×2 + 1×1 + 0×0.5 + 1×0.25 = 2+1+0+0.25 = 3.25（0.25 就是小数点后第 2 位那个 1 贡献的）

🎬 像素小剧场 · 按权展开 约 10 秒动画：1011B 的四个数字格下方依次落下位权条（8 4 2 1）和乘积条，最后汇聚成 8+0+2+1 = 11——「逐位相乘再相加」这一招，看一遍就长在脑子里。
按权展开通式：把每位数字（d）乘上它所在位的权（R 的幂），再全部加起来——所有「×进制转十进制」都是这一个动作。
选读：教材里会写成 (dn…d1d0.d-1)R = Σ di × Ri，Σ 是「把各项加起来」的求和记号——看不懂可跳过，不影响做题。

二、十进制 → R 进制：整数除基取余，小数乘基取整

  • 整数部分：除基取余，余数逆序读——除到商 0 为止。为什么这样做？每次除以 2，余数就是「这个数是奇还是偶」：奇数余 1、偶数余 0——这正好是二进制最低位（个位）的值；除完剩下的商，就是去掉最低位后剩下的部分，继续除它就拆出了更高一位。所以先算出来的余数是最低位，最后算出来的才是最高位——写的时候就得倒过来（逆序）。用 25 = 16+8+1 对照：25 除以 2 余 1（个位是 1），商 12 除以 2 余 0（第二位是 0）……一路拆到 0，逆着读正好是 11001；
  • 小数部分：乘基取整，整数顺序读——每步取走整数部分，用剩下的小数继续乘（道理对称：乘 2 后整数部分进到了小数点左边第一位）；
  • 巧算（二进制专用）：把十进制拆成 2 的幂之和，有幂的位写 1——25 = 16+8+1 = 11001B，考场比竖除快一倍（这招和除基取余结果一样，可以互相验算）。

例（整数）：25 ÷ 2 = 12 余 1；12 ÷ 2 = 6 余 0；6 ÷ 2 = 3 余 0；3 ÷ 2 = 1 余 1；1 ÷ 2 = 0 余 1。余数逆序 → 11001B（除了 5 次 → 二进制 5 位）。

例（小数）：0.625 × 2 = 1.25；0.25 × 2 = 0.5；0.5 × 2 = 1.0（小数部分归 0 即终止）。整数顺序 → 0.101B。

🎬 像素小剧场 · 除基取余 同一个 25，换他法：除法阶梯一行行落下，每一步的余数被收进右栏（注意收集方向——先得到的在最低位），最后拼出 11001B 还顺手验算一遍。
⚠ 高频陷阱 ① 余数逆序读、小数整数位顺序读——方向背反是最常见丢分；② 十进制小数转二进制可能除不尽（如 0.3 → 无限循环），题目会限定取几位；③ 除不尽时二进制无法精确表示该小数——这句本身就是判断题考点。

三、二进制 ↔ 八进制 / 十六进制：分组换算（秒杀技）

因为 8 = 2³、16 = 2⁴：二进制转八进制按 3 位一组、转十六进制按 4 位一组，分组方向：以小数点为界，整数部分向左、小数部分向右，两端不足补零。反向转换每位展开即可——完全不用经过十进制。

例 1（二 → 十六）：11011010B → 分组 1101 | 1010 → D | A → DAH

例 2（二 → 八）：11011010B → 整数向左分组 11 | 011 | 010（左端补 0 成 011）→ 3 | 3 | 2 → 332O

例 3（十六 → 二）：3CH → 3=0011，C=1100 → 00111100B（每位拆 4 位，原样拼接）

记忆钩子：8 = 2³ → 三位一组；16 = 2⁴ → 四位一组；分组从小数点向两侧，补零补在两端

四、两个必考题型：进制等式 与 位数范围

4.1 进制等式题（解方程）

题面给「(41)x = (29)D，求 x」——把左边按权展开，解一元一次方程即可：

4x + 1 = 29 → x = 7　　（自查一句：基数必须比这个数里出现的最大数码大——本例最大数码是 4，所以 x > 4，x 至少是 5；解出的 7 满足，答案成立）

为什么要自查？因为「41」里写着一个数码 4，x 进制必须装得下 4 这个数码（比如二进制只有 0 和 1，写不出 4）——所以基数要比最大数码大。这道题光看约束只能框出 x ≥ 5，具体是几得靠方程解出来。

4.2 位数与表示范围

  • R 进制 n 位能表示的数共 Rn 个；最大值 = Rn − 1（每一位都顶格）；
  • 二进制 8 位：0 ~ 2⁸−1 = 255（这就是子网划分里「一个字节 0~255」的来源——0025 直接用）；
  • 十进制数 D 转成二进制后共几位？人人能算的判断法：找最大的 2ⁿ 不超过它——25 夹在 16（2⁴）和 32（2⁵）之间：2⁴ ≤ 25 < 2⁵，所以 25 至少要 5 位（16 只需 5 位 1，25 比 16 大、32 又装不下它）→ 5 位。教科书里的对数公式（位数 = ⌊logRD⌋ + 1，⌊⌋ 表示「向下取整、抹掉小数」）说的就是同一件事，看不懂可跳过，用上面的判断法足够做题。
