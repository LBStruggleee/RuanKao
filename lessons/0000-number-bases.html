一、R 进制 → 十进制：按权展开（一切转换的原点）

每一位数字 × 它所在位的权（基数的幂）再相加。基数 R = 用几个数码（二进制 2 个、八进制 8 个、十六进制 16 个，A=10…F=15）；第 i 位（从右数、从 0 起）的权 = Ri。

例 1：1011₂ = 1×2³ + 0×2² + 1×2¹ + 1×2⁰ = 8+0+2+1 = 11

例 2（带字母）：1A₂₆? —— 1A₁₆ = 1×16 + 10 = 26（A 就是 10，别看到字母就慌）

例 3（小数）：11.01₂ = 2+1+0.25 = 3.25（小数点后的权是 2⁻¹=0.5、2⁻²=0.25，往右减半）

🎬 像素小剧场 · 按权展开 约 10 秒动画：1011₂ 的四个数字格下方依次落下位权条（8 4 2 1）和乘积条，最后汇聚成 8+0+2+1 = 11——「逐位相乘再相加」这一招，看一遍就长在脑子里。
按权展开通式：(dn…d1d0.d-1)R = Σ di × Ri　　——所有「×进制转十进制」都是它

二、十进制 → R 进制：整数除基取余，小数乘基取整

  • 整数部分：除基取余，余数逆序读——除到商 0 为止，先得的余数是低位；
  • 小数部分：乘基取整，整数顺序读——每步取走整数部分，用剩下的小数继续乘；
  • 巧算（二进制专用）：把十进制拆成 2 的幂之和，有幂的位写 1——25 = 16+8+1 = 11001₂，考场比竖除快一倍。

例（整数）：25 ÷ 2 = 12 余 1；12 ÷ 2 = 6 余 0；6 ÷ 2 = 3 余 0；3 ÷ 2 = 1 余 1；1 ÷ 2 = 0 余 1。余数逆序 → 11001₂（除了 5 次 → 二进制 5 位）。

例（小数）：0.625 × 2 = 1.25；0.25 × 2 = 0.5；0.5 × 2 = 1.0（小数部分归 0 即终止）。整数顺序 → 0.101₂。

🎬 像素小剧场 · 除基取余 同一个 25，换他法：除法阶梯一行行落下，每一步的余数被收进右栏（注意收集方向——先得到的在最低位），最后拼出 11001₂ 还顺手验算一遍。
⚠ 高频陷阱 ① 余数逆序读、小数整数位顺序读——方向背反是最常见丢分；② 十进制小数转二进制可能除不尽（如 0.3 → 无限循环），题目会限定取几位；③ 除不尽时二进制无法精确表示该小数——这句本身就是判断题考点。

三、二进制 ↔ 八进制 / 十六进制：分组换算（秒杀技）

因为 8 = 2³、16 = 2⁴：二进制转八进制按 3 位一组、转十六进制按 4 位一组，分组方向：以小数点为界，整数部分向左、小数部分向右，两端不足补零。反向转换每位展开即可——完全不用经过十进制。

例 1（二 → 十六）：11011010₂ → 分组 1101 | 1010 → D | A → DA₁₆

例 2（二 → 八）：11011010₂ → 整数向左分组 11 | 011 | 010（左端补 0 成 011）→ 3 | 3 | 2 → 332₈

例 3（十六 → 二）：3C₁₆ → 3=0011，C=1100 → 00111100₂（每位拆 4 位，原样拼接）

记忆钩子：8 = 2³ → 三位一组；16 = 2⁴ → 四位一组；分组从小数点向两侧，补零补在两端

四、两个必考题型：进制等式 与 位数范围

4.1 进制等式题（解方程）

题面给「(41)x = (29)₁₀，求 x」——把左边按权展开，解一元一次方程即可：

4x + 1 = 29 → x = 7　　（注意：算出的基数必须 ≤ 该数用到的最大数码 + 1）

4.2 位数与表示范围

  • R 进制 n 位能表示的数共 Rn 个；最大值 = Rn − 1（每一位都顶格）；
  • 二进制 8 位：0 ~ 2⁸−1 = 255（这就是子网划分里「一个字节 0~255」的来源——0025 直接用）；
  • 十进制数 D 转成 R 进制后的位数 = ⌊logRD⌋ + 1（如 25 → 二进制 5 位：2⁴ ≤ 25 < 2⁵）。

七、自查（全对过课）

✅ 本课一页收获
  1. R→十：按权展开（小数点后权为 R⁻¹、R⁻²…）；十→R：整数除基取余逆序、小数乘基取整顺序。
  2. 二↔八（3 位一组）/ 二↔十六（4 位一组）：分组从小数点向两侧、两端补零——不经过十进制。
  3. 进制等式 = 按权展开解方程；(41)ₓ=(29)₁₀ → x=7 这类题 30 秒拿下。
  4. 速记：2¹⁰=1024、2⁸=256、FF=255、A~F=10~15——0001 补码、0025 子网全靠它。
