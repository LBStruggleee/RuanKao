四种遍历与序列重建：先序定根，中序分家

课程总目录 ｜ 预计 40 分钟 ｜ 上一课：0007 二叉树概念
考点定位：遍历还原必考（2019H2-Q58 原题）；「先序+后序不能唯一确定二叉树」高频陷阱

🎯 这课的赢面 考卷最爱问「给先序+中序，求后序」。套路只有一句话：先（后）序定根，中序分左右——反复做，直到 3 分钟内算完。本课还把 Lesson 0006 的「5」再次带回来：n 个节点的二叉树形状数也是卡特兰数。

一、四种遍历（口诀 + 亲手点）

遍历 = 把树上每个节点恰好访问一次。四种方式的区别只在根什么时候被访问：

方式口诀访问顺序
先序根 → 左 → 右一路先挖根
中序左 → 根 → 右左子树全挖完才轮到根
后序左 → 右 → 根根最后被访问（销毁树/求子树大小时用）
层序一层一层，从左到右用队列实现（Lesson 0006！）

先序/中序/后序是递归定义（对每棵子树同样适用），实现时用栈。我们的样例树：

        A
       / \
      B   C
     / \    \
    D   E    F
先序中序后序层序
A B D E C FD B E A C FD E B F C AA B C D E F

二、必考套路：两个序列重建二叉树

原理：先序/后序的第一个/最后一个一定是根；拿根回中序里一切，左边 = 左子树，右边 = 右子树；对左右子树递归。

例：先序 A B D E C F + 中序 D B E A C F →

  1. 先序首 = A = 根；中序切成 D B E ｜ A ｜ C F → 左子树 {D,B,E}，右子树 {C,F}；
  2. 左子树先序 B D E → 根 B；中序 D ｜ B ｜ E → 左 D、右 E；
  3. 右子树先序 C F → 根 C；中序 C ｜ F → 右孩子 F；
  4. 得到样例树 → 要后序？后序 = 左右根 = D E B F C A。✔
⚠ 高频陷阱：先序 + 后序 ≠ 唯一 只有「先+中」或「中+后」能唯一重建；先序+后序不行——当某节点只有一个孩子时，无法分辨它是左孩子还是右孩子。反例：先序 A B、后序 B A，B 可以是 A 的左孩子也可以是右孩子，两棵树都满足。判断题/选择题年年设这个坑。

三、动手：亲手点出四种序列

💡 练法 四个游戏各点一遍，点之前先在纸上默写（口诀：根左右 / 左根右 / 左右根 / 一层层）。中序最绕——记住「左子树全部挖完才轮到根」。点完再看上一节那张表对答案。

四、自查（全对过课）

✅ 本课一页收获
  1. 口诀：先序根左右 / 中序左根右 / 后序左右根 / 层序一层层（队列）。
  2. 重建套路：先（后）序定根，中序分左右，递归切分。
  3. 先序+后序不能唯一确定二叉树（单孩子分不清左右）——判断题高频。
  4. 后序的最后一个 = 根；中序里根的左边全在左子树。
