分层模型与协议归属：把协议放对楼层

课程总目录 ｜ 预计 35 分钟 ｜ 上一课：0015 OS 内存管理
考点定位：OSI/TCP-IP 对照、协议层级归属（day04-protocols.md，20 题里 12 道层级判断）、设备所在层

🎯 这课的赢面 网络第一题永远是「某某协议/设备在第几层」。背下一张归属总表 + 三个高频陷阱（ARP 在网际层、ICMP 在网络层、端口在 TCP/UDP 头部），这部分分就稳了。

一、两层楼对照：OSI 七层 vs TCP/IP 四层

OSI 七层TCP/IP 四层干什么（一句话）代表协议/设备
7 应用4 应用给用户软件用的接口HTTP/FTP/SMTP/DNS/Telnet/SNMP
6 表示格式转换、加密压缩（JPEG/加密在此概念层）
5 会话建立/管理/终止会话（RPC/SQL 会话概念）
4 传输3 传输端到端可靠/不可靠传输TCP / UDP（端口在这层）
3 网络2 网际路由选路、逻辑地址IP/ICMP/ARP/RARP/IGMP；路由器
2 数据链路1 网络接口成帧、MAC 寻址、差错检测以太网/PPP；交换机、网桥
1 物理比特流上媒介网线/光纤；中继器、集线器 Hub

数据发送时逐层封装（加头部），接收时逐层解封装——顺序：应用 → 传输(段) → 网际(包) → 链路(帧) → 物理(比特)。

二、归属总表（必背，按楼层背）

层协议（全称顺一遍）记忆锚点
应用HTTP 万维网 / FTP 20+21 文件 / SMTP 25 发邮件 / POP3 110 收邮件 / DNS 53 域名→IP / Telnet 23 远程登录 / SNMP 161 网管 / DHCP 67-68 自动分配 IP / TFTP 69 简单文件「上网收发找名字，远程网管自动配」
传输TCP 可靠连接 / UDP 无连接快速端口（0–65535）装在 TCP/UDP 头部
网际/网络IP 寻址 / ICMP 差错报告（ping 用它）/ ARP IP→MAC / RARP MAC→IP / IGMP 组播ARP/ICMP 都在网际层，不在应用层！
数据链路以太网 Ethernet / PPP / VLAN(802.1Q) / CSMA/CDMAC 地址 48 位
物理RJ45 / 光纤 / 比特流只管信号
⚠ 三个高频陷阱 ① ARP 在网际层（不是应用层）——它服务于 IP 到 MAC 的解析；② ICMP 在网络层（ping 是应用但承载它的 ICMP 在网络层）；③ 端口号在传输层 TCP/UDP 首部（不在 IP 头部）。

三、设备在几层（一个判断口诀）

看设备「读到了哪一层地址」：只转发电信号 = 物理（中继器/Hub）；认 MAC = 数据链路（交换机/网桥）；认 IP = 网络（路由器）；还要管应用内容 = 网关/应用层防火墙。

四、自查（全对过课）

✅ 本课一页收获
  1. OSI 七层 ↔ TCP/IP 四层对照；发送封装、接收解封装。
  2. 应用层协议背端口号：FTP 21/SMTP 25/DNS 53/HTTP 80/HTTPS 443/Telnet 23/POP3 110/SNMP 161。
  3. 三个陷阱：ARP 网际层、ICMP 网络层、端口在传输层头部。
  4. 设备按「读到哪层地址」归层：Hub 物理、交换机链路、路由器网络。
