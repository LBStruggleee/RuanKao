一、机器数四兄弟：原码 → 反码 → 补码 → 移码

计算机里整数一律用补码存储、浮点数阶码用移码（下一节就用到），但题目会来回考四种码的互换。按「发明顺序」走一遍，规则就不用死记：

  1. 原码：最高位当符号位（0 正 1 负），其余位是绝对值。最直观，但有两个死穴：0 占了两个编码（[+0]=0000 0000、[−0]=1000 0000）；加减法要判断符号再挑运算，电路复杂。
  2. 反码：正数不变；负数 = 原码符号位不动、其余位按位取反。它把「减一个数」变成「加它的反码」，但 −0 依然存在（1111 1111）——编码不唯一，只能当过渡方案。
  3. 补码：负数 = 反码 + 1（正数：原码反码补码三码相同）。+0 与 −0 合并成唯一的 0000 0000，省出的 1000 0000 让给 −128 → 「负多一」。为什么加补码 = 减原数？时钟比喻：倒拨 2 小时 = 正拨 10 小时（模 12）——模运算里减一个数和加它的「补」是同一件事，于是减法全部变成加法，一套加法器通吃加减。
  4. 移码：补码的符号位取反（等价说法：真值 + 2n−1 后按无符号数存）。它最大的好处：按无符号比大小 = 按真值比大小——浮点数「对阶」要反复比较阶码大小，就用它（下一节 IEEE 754 的 8 位阶码）。
8 位示例原码反码补码移码

n 位表示范围对照：原码/反码 ±(2n−1−1)（0 占两个编码）；补码 −2n−1 ~ 2n−1−1（负多一）；移码与补码同范围（偏移 2n−1）
位数补码表示范围记忆点
8 位−128 ~ +127−128 = 1000 0000，没有对应的 +128
16 位−32768 ~ +32767−2¹⁵ ~ 2¹⁵−1

正向例：−1 的 8 位补码：|−1|=0000 0001 → 反码 1111 1110 → 补码 1111 1111。规律：全 1 就是 −1；从 1111 1111（−1）往上减 1 就是 −2、−3…

反向转换（考得更多）：补码 → 十进制，符号位 0 就按无符号直接读；符号位 1 就「取反 +1」求出绝对值再添负号。例：补码 1100 1100 → 取反 0011 0011 → +1 得 0011 0100 = 52 → 原数是 −52。

变形补码（双符号位）一句带过：加减运算用两位符号位（00 正、11 负），算完若符号位是 01 → 正溢出、10 → 负溢出——「判断定点加减是否溢出」的标准答案。

二、浮点数：阶码定范围，尾数定精度

浮点数 N = 尾数 × 2阶码。IEEE 754（32 位 float）：1 位符号 + 8 位移码阶码（§一的④——对阶要反复比大小，移码按无符号比就是真值比）+ 23 位尾数（隐含首位 1，实际精度 24 位）。

  • 对阶原则：小阶向大阶看齐（小阶尾数右移，丢失的是最低位，误差小）——必考判断。
  • 阶码位数决定表示范围；尾数位数决定精度——两者此消彼长。
  • 规格化：尾数最高有效位必须是 1（原码尾数 0.1xxx 形式），提高精度。

三、校验码三兄弟：检一位、纠一位、检任意位

校验码原理能力
奇偶校验补 1 位使整个码字 1 的个数为奇/偶只能发现奇数个位错，不能纠错，不能发现偶数位错
海明码k 位校验位嵌入 2i 位置（1,2,4,8…），分组偶校验发现并纠正 1 位错（检测 2 位错）
CRC 循环冗余模 2 除法（异或）得校验位拼接在尾部检错能力极强（教材口径：只检错不纠错），靠硬件实现

海明码位数公式（必考）：信息位 n 位需校验位 k 位，满足：

2k ≥ n + k + 1

例：n=4 → 试 k=3：2³=8 ≥ 4+3+1=8 ✓ → 需 3 位校验。n=11 → k=4：16 ≥ 16 ✓ → 4 位。口诀：4 位信息 3 校验，11 位信息 4 校验，26 位信息 5 校验。

CRC 完整手算（模 2 除 = 按位异或、不借位不进位）：信息 1101，G(x)=x³+x+1 → 除数 1011（r=3 位）。

信息左移 r 位 → 1101000，逐「4 位窗口」异或（首位 1 商 1 异或除数；首位 0 商 0 直接落下一位）：
1101 ⊕ 1011 = 0110 ，落下一位 0 → 1100
1100 ⊕ 1011 = 0111 ，落下一位 0 → 1110
1110 ⊕ 1011 = 0101 ，落下一位 0 → 1010
1010 ⊕ 1011 = 0001 → 余数 = 001

发送码字 = 信息 ⊕ 余数 = 1101 001。接收方用同一 1011 除码字：余数为 0 → 无错。口诀：首位是 1 就异或除数、是 0 就商 0 直落——除到最后剩 r 位就是校验位。

四、可靠性：串联靠乘，并联靠补

串联（一个坏全坏）：R = R₁ × R₂ × … × Rn
并联（冗余备份）：R = 1 − (1−R₁)(1−R₂)…(1−Rn)

例：两个部件 R₁=R₂=0.9：串联 R = 0.81（更不可靠）；并联 R = 1 − 0.1×0.1 = 0.99（更可靠）。

混合系统：先并联成组，再串联相乘。如「子系统 A（两个 0.9 并联）与子系统 B（0.9）串联」：A = 0.99 → 总 R = 0.99 × 0.9 = 0.891。

MTBF 平均无故障时间：可靠性 R(t) = e−λt，MTBF = 1/λ。失效率 λ 越小越可靠。

五、RAID：冗余磁盘阵列速查

级别技术特点
RAID 0条带化（数据分块分布到多盘）读写最快、无冗余，坏一块全丢——利用率 100%
RAID 1镜像（两两互备）可靠性最高，利用率 50%，成本最高
RAID 5分布式奇偶校验（校验信息分散在各盘）坏任意 1 块可恢复，利用率 (n−1)/n，最常用
RAID 6双重校验坏 2 块可恢复，写性能更低

✅ 本课一页收获
  1. 补码范围 −2n−1 ~ 2n−1−1（8 位 −128~127）；全 1 = −1。
  2. 浮点：对阶小阶向大阶；阶码管范围、尾数管精度。
