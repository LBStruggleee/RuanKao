一、最小生成树 MST：Prim vs Kruskal

给带权连通图，挑 n−1 条边把所有点连起来且总权最小。两种贪心：

Prim（加点法）Kruskal（加边法）
策略从某点出发，每次把「离已长成部分最近」的顶点拉进来边按权排序，从小到大挑，成环就跳过
判环不需要（永远长在同一个连通块上）需要（并查集思想）
适合稠密图稀疏图（先排序）

二、最短路：Dijkstra（单源）

求一个起点到其余各点的最短路径：贪心——每轮把「当前距离最小的未确定点」定型，再用它松弛邻居。考试要点：①适用于无负权边；②贪心逐步扩大「已确定集」；③求两点间最短路也用它（从起点算出到终点的答案）。

微例：A→B 权 1，A→C 权 4，B→C 权 2。A 到 C？直接走 4，但 A→B→C = 3 更短 → 3。Dijkstra 的「松弛」就是干这件事：看经过中间点会不会更近。

三、拓扑排序：AOV 网排先后

课程有先修关系、任务有依赖——有向无环图（DAG）排出一个合法顺序：每次取「入度为 0」的点输出并删掉它的出边，直到全部输出；中途找不到入度 0 的点 = 有环（依赖死锁）。

⚠ 考点 拓扑序列不唯一（同一时刻可能多个入度 0 的点，选谁都行）；题干给一个序列问「是否可能」→ 逐点模拟入度即可；「拓扑序列存在 ⇔ 图无环」是判断题常客。

四、必考计算：关键路径（AOE 网）

AOE 网边=活动（带工期），点=事件。问整个工程最少多少天、哪些活动一天都不能拖（关键活动）。

ve（最早）从前往后取 MAX：ve[j] = max(ve[i] + w(i,j))
vl（最迟）从后往前取 MIN：vl[i] = min(vl[j] − w(i,j))　　关键活动：e = l（无余量）

样例 AOE（背熟这张表）：V1→V2 权3（a1）、V1→V3 权2（a2）、V2→V4 权4（a3）、V3→V4 权3（a4）、V4→V5 权2（a5）。

✅ 本课一页收获
  1. Prim 加点（稠密）、Kruskal 加边跳环（稀疏）；边权互异 ⇒ MST 唯一。
  2. Dijkstra = 贪心松弛，单源最短路，不能有负权边。
  3. 拓扑排序 = 每次摘入度 0 的点；有序列 ⇔ 无环；序列不唯一。
  4. 关键路径：ve 前 max、vl 后 min、关键活动 e=l；工期 = 终点 ve。样例答案：9 天，V1→V2→V4→V5。
