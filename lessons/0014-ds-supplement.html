数据结构补遗：矩阵地址计算、串、森林与平衡树

课程总目录 ｜ 预计 35 分钟 ｜ 上一课：0001 组成计算专题
考点定位：数组/矩阵地址计算（几乎每年 1 题纯计算）、树/森林与二叉树转换、平衡树概念——补上 0005~0013 之外的散点

🎯 这课的赢面 一个公式吃一题：行优先 Loc(a[i][j]) = 基址 + (i×n + j)×L（n 为列数）。再带三句话：树转二叉树「左孩子右兄弟」；树的后序 = 对应二叉树的中序；平衡树左右高度差 ≤ 1。

一、多维数组地址计算：先数前面排了多少个

地址计算的本质就一句话：目标元素前面一共存了多少个元素 × 每个元素的字节数，加到基址上。

行优先（按行存）：Loc(a[i][j]) = Loc(a₀₀) + ( i × n + j ) × L　　（n = 列数，i/j 从 0 起）
列优先（按列存）：Loc(a[i][j]) = Loc(a₀₀) + ( j × m + i ) × L　　（m = 行数）

例：a[5][6] 二维数组（5 行 6 列），基址 1000，每元素 4 字节，行优先，求 a[2][3] 的地址：

前面有 2 整行（2×6=12 个）+ 本行前 3 个 = 15 个 → 1000 + 15×4 = 1060。

若列优先：前面有 3 整列（3×5=15 个）+ 本列前 2 个 = 17 个 → 1000 + 17×4 = 1068。行列数或存储方式一变，答案立刻变——审题两件事：几行几列？行优先还是列优先？

⚠ 下标从 1 开始的坑 若题目说 a[1..5, 1..6]（下标从 1 起），则 a[2,3] 前面有 (2−1)×6 + (3−1) = 8 个 → 1000+8×4 = 1032。公式随下标起点变，别背死公式，数清前面有几个。

对称矩阵与稀疏矩阵

压缩方式做法考试点
下三角/对称矩阵只存下三角（含对角线），共 n(n+1)/2 个元素给 i、j 求一维下标（数第 i 行前共有几行）
三对角矩阵只存主对角线及上下两条斜线，3n−2 个元素下标换算
稀疏矩阵非零元素极少，用三元组 (行,列,值) 或十字链表存三元组表失去了随机存取特性（判断题）

二、串：KMP 的思想一句话

串是内容受限的线性表（元素是字符）。空串长度为 0；空格串只有空格、长度为空格数——两者不相等（判断题）。

朴素模式匹配最坏 O(n×m)（主串回溯）。KMP 改进：主串指针永不回溯，失配时利用 next 数组把模式串滑到合适位置继续比，复杂度 O(n+m)。中级只考思想判断，不考手推 next。

三、树、森林与二叉树的互转：左孩子右兄弟

任何树/森林都能唯一转成二叉树（0007 的二叉树是万能底座）：

转换规则要点
树 → 二叉树左孩子、右兄弟：节点的左指针指向第一个孩子，右指针指向下一个兄弟转换后根没有右子树
森林 → 二叉树各棵树先各自转换，第二棵树作为第一棵树根的右子树依次连上转换后根仍有右子树
遍历对应树的前序 = 对应二叉树的前序；树的后序 = 对应二叉树的中序森林的中序 = 对应二叉树的中序

例：树有根 R，孩子 A、B（A 的孩子 C）。转二叉树：R 左指 A；A 左指 C，A 右指 B；C、B 无孩子。前序遍历（根左右）：R A C B —— 与树的前序（根 R → 孩子 A → C → B）完全一致 ✓。

四、平衡二叉树（AVL）：不让二叉搜索树退化成链

二叉搜索树 BST：左 < 根 < 右，查找走折半的路径。但按 1,2,3,… 顺序插入会退化成一条链，查找从 O(log n) 掉到 O(n)。AVL 平衡二叉树在 BST 上加一条约束：

任意节点：左子树高度 − 右子树高度 ∈ {−1, 0, 1}

插入导致失衡时靠旋转（LL/RR/LR/RL 四种）恢复平衡。中级只考概念判断：AVL 是平衡的二叉搜索树；n 个节点的 AVL 高度是 O(log n)；哈夫曼树不是 AVL（先记住两者目的不同：0009 哈夫曼管带权路径最短）。

六、自查（全对过课）

✅ 本课一页收获
  1. 行优先：基址 + (i×n + j)×L；列优先：基址 + (j×m + i)×L——先确认行列数、下标起点、存储顺序。
  2. 下三角压缩 n(n+1)/2 个；三对角 3n−2；稀疏矩阵三元组失去随机存取。
  3. 空串 ≠ 空格串；KMP 主串指针不回溯，O(n+m)。
  4. 树转二叉树「左孩子右兄弟」，树的前序 = 二叉树前序、树的后序 = 二叉树中序。
  5. AVL：左右高度差 ≤ 1 的二叉搜索树，靠旋转防退化。
