算法设计策略：题目没说用的什么，你也要一眼认出来

课程总目录 ｜ 预计 50 分钟 ｜ 上一课：0034 算法填空
考点定位：上午卷每年 2~3 题考「这段算法是什么策略 / 该问题适合什么策略」（考查形式：给算法描述或伪代码选策略名）；下午卷试题四问题 2 也固定问策略 + 复杂度。官方教程第 8 章整章只讲这一件事。

🎯 这课的赢面 五大策略的识别关键词 + 两两对比是唯一的考点：题目从不问「策略的定义」，只给一段「分解子问题→递归求解→合并」或「填表」或「每次取当前最优」的描述让你认名字。把 §二 的总览表背熟 + §四 的易混对比讲清楚，这 2~3 题就是送分题。

🧭 体系定位：面 1 数据结构 · 算法策略线——五大策略识别（分治/DP/贪心/回溯/分支限界）。上游：0009/0011 的策略直觉；下游：0034 试题四问题 2（回地图）

一、先分清三个层次：策略 ≠ 算法 ≠ 复杂度

  • 算法设计策略（本课）：解决问题的通用思路框架——分治、动态规划、贪心、回溯、分支限界；
  • 算法：用某个策略对具体问题写出的求解步骤（如「用贪心策略构造哈夫曼树」）；
  • 复杂度：算法的时间/空间开销，是某个具体算法的属性，不是策略的属性（同样是贪心，Prim 是 O(n²)、Kruskal 是 O(eloge)）。
📌 考题姿势 上午题的典型问法：「求解 TSP 问题常用的（　）策略能获得近似解」「该算法采用的算法策略是（　）（附一段递归+合并的伪代码）」「（　）算法不需要（能获得）问题的精确最优解」。选项永远是五大策略名 + 概率/近似。

二、五大策略总览表（必背）

策略核心思想子问题关系经典问题识别关键词
分治法 分解 → 递归求解 → 合并 相互独立、不重叠 二分查找、归并/快速排序、大整数乘法、Strassen 矩阵乘法 「分成两半」「递归求解子问题」「合并结果」；复杂度常为 O(nlogn)
动态规划 最优子结构 + 重叠子问题，自底向上填表记住子问题解 重叠（重复出现，结果存表不重算） 矩阵连乘、编辑距离、最长公共子序列、0/1 背包、最短路径（Floyd） 「递推公式/递归式」「表格 dp[i][j]」「最优子结构」「自底向上」
贪心法 每步取局部最优，不回退，期望凑出全局最优 一次定夺，子问题规模单调缩小 哈夫曼编码、Prim/Kruskal、Dijkstra、活动安排、部分（分数）背包 「每次选取当前最优」「不回溯」「贪心选择性质」；通常还要先排序
回溯法 解空间树上 DFS，走不通就退回换分支（能进能退） 沿路径扩展，可行性剪枝 N 皇后、图着色、哈密顿回路、子集和、迷宫 「深度优先」「试探—回退」「剪枝」「求所有解 / 任一解」
分支限界法 解空间树上 BFS / 最佳优先，用限界函数剪掉不可能更优的分支 按层扩展，界函数剪枝 旅行商（TSP）、任务分配、0/1 背包的精确求解 「广度优先」「限界函数」「目标函数界」「求一个最优解」

补充两位常当选项的配角：概率算法（允许随机，数值型/蒙特卡洛/拉斯维加斯/舍伍德四类——蒙特卡洛可能有错但时间可控、拉斯维加斯一定对但可能不给出解、舍伍德消除最坏情形行为）；近似算法（NP 难问题放弃精确最优，换可证明的近似比，如 TSP 的近似解）。

三、两两对比（上午题最爱在缝里出题）

3.1 分治 vs 动态规划——看子问题重不重叠

维度分治动态规划
子问题相互独立，重复出现也少大量重叠，反复用到同一子问题
记忆化不存子问题解填表存储，每个子问题只算一次
典型归并排序（左右两半各排各的，合并即可）最短路 Floyd（k 层循环反复用前面结果）
自顶向下递归？典型自顶向下典型自底向上（也有记忆化递归版）

一句话：子问题独立 → 分治；子问题重复 → 把分治改造成「算过就记」就是动态规划。考试里「分治法求解的子问题往往重复出现」这类说法是错误选项。

3.2 贪心 vs 动态规划——看能不能一次定夺

  • 贪心：每一步只看当前，做出选择后永不回头；只在使用「贪心选择性质」的问题上正确（哈夫曼、最小生成树、Dijkstra、活动安排）。做得快（通常 O(nlogn)，排序主导），但不是所有问题都适用——0/1 背包用贪心（按单位价值装）会得到错误解。
  • 动态规划：每步要比较多个子问题的结果才做决定，慢但保证最优。0/1 背包 DP 能拿到精确解。
  • 考题句式：「贪心法总能得到最优解」→错（要加「满足贪心选择性质的问题」）；「动态规划、贪心都要求问题具有最优子结构」→对。
  • 附带辨析：部分背包（物品可分割，按单位价值贪心装）贪心对；0/1 背包（不可分割）只能 DP/回溯/分支限界。

3.3 回溯 vs 分支限界——都是搜解空间树，遍历方式不同

维度回溯法分支限界法
遍历方式深度优先（DFS）广度优先 / 最佳优先（队列/优先队列）
剪枝手段约束（可行性）函数：剪掉不可行分支限界函数：剪掉「不可能优于当前界」的分支
求解目标找所有解或任一可行解尽快找到一个（近似意义下的）最优解
内存只存当前路径，省要维护活结点表，费
记忆钩子「能进能退」——迷宫走不通就折返「广撒网+划掉没希望的」——按层扩展层层筛选

共同点也要会：两者都在问题的解空间树上搜索，都利用剪枝避免整个解空间（指数级）被遍历，最坏复杂度仍是指数级——但实际远快于暴力枚举。

四、策略识别决策树（题面特征 → 策略名）

题面出现什么？                                    →  策略
────────────────────────────────────────────────────────
「分解成规模更小的同类子问题，递归求解后合并」      →  分治法
「递推/递归式 + 表格记录子问题解 + 最优子结构」      →  动态规划法
「每次选取当前（局部）最优，且不再改变」            →  贪心法
「深度优先试探，不可行就回退，找全部解/可行解」      →  回溯法
「广度优先扩展结点 + 限界函数剪枝，求最优解」        →  分支限界法
「引入随机数，可能出错/可能无解但期望快」           →  概率算法
「NP难问题，放弃精确解，保证近似比」               →  近似算法
────────────────────────────────────────────────────────
按「经典问题」反查（更快的考场路径）：
  二分查找/归并/快排 → 分治      矩阵连乘/编辑距离/LCS/0-1背包 → DP
  Huffman/MST/Dijkstra/活动安排 → 贪心
  N皇后/图着色/哈密顿 → 回溯     TSP精确求解/任务分配 → 分支限界

五、每个策略一道「真题手感」例题

  1. 分治：n 个元素排序，「每次把序列对半分，分别排序后合并两个有序序列」——归并排序，T(n)=2T(n/2)+O(n) → O(nlogn)。
  2. DP：「求两字符串的最长公共子序列，用 c[i][j] 记录前缀的 LCS 长度，按递推式自底向上填表」——O(mn)；问题 2 答策略：动态规划（表格+最优子结构+重叠子问题）。
  3. 贪心：「构造哈夫曼树时每次从集合中取出权值最小的两棵树合并」——每次局部最优、不回退，贪心法。
  4. 回溯：「在 8×8 棋盘上放 8 个皇后，逐行放置，冲突时退回上一行换列」——DFS + 剪枝，回溯法。
  5. 分支限界：「求解 TSP，从根结点按层扩展，用当前最短回路长度作为界剪去下界不优的结点」——分支限界法。

七、细节辨析（第二关，5 题）

八、高频丢分点自查

  • 「分治的子问题相互独立」——对；说成「重叠」就错（重叠 → 那是 DP）；
  • 「贪心法一定得到最优解」——错，必须满足贪心选择性质（哈夫曼/ MST / Dijkstra 可以，0/1 背包不行）；
  • 「分支限界用深度优先」——错，它是广度/最佳优先；深度优先的是回溯；
  • 「回溯法求一个最优解最有效」——它的主场是全部解/可行解；要「最优」且带界函数 → 分支限界；
  • 复杂度张冠李戴：O(nlogn) 是二分/归并（分治）的，不是 DP 的；DP 看表格是 O(n²) 或 O(n³)；
  • 蒙特卡洛 vs 拉斯维加斯：前者「总有解但可能有错」，后者「总正确但可能不给解」——方向别背反；
  • 下午卷问题 2：策略名要写全称「动态规划法」（只写「DP」按错处理）。
✅ 本课一页收获
  1. 五大策略一句话：分治=独立分解再合并；DP=重叠子问题填表；贪心=局部最优不回头；回溯=DFS 试探能进能退；分支限界=BFS+限界函数求最优。
  2. 两个判断轴：子问题重不重叠（分治 vs DP）；每步能不能一次定夺（贪心 vs DP）；遍历深还是广（回溯 vs 分支限界）。
  3. 经典问题对号入座：二分/归并→分治；矩阵连乘/编辑距离/LCS/0-1背包→DP；Huffman/MST/Dijkstra→贪心；N皇后/图着色→回溯；TSP→分支限界。
  4. 配角：概率算法四类（蒙特卡洛可能有错/拉斯维加斯必对/舍伍德消最坏/数值型）；NP 难 → 近似算法。
