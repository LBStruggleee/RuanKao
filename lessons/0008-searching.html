一、折半查找：每次砍一半

在有序序列里找 x：看中间那个，大了往左半、小了往右半。两个前提缺一不可：①序列有序 ②顺序存储（数组）——链表没法跳到中间（Lesson 0001：数组才能按下标直达）。

二、哈希：算出地址直接住进去

不想比较，想用关键字直接算出存储地址：H(key) = key mod p（除留余数法，p 取不大于表长的最大质数，让散布均匀）。两个 key 算出同一地址 = 冲突，处理办法三种：

方法做法要点
线性探测占了就往后挪一格（di = 1,2,3…）简单，但会堆积（连片占满，越堵越堵）
二次探测跳 1², −1², 2², −2²…跳跃式，缓解堆积
链地址同义词挂成一条链表本质就是 Lesson 0001 的链表；删除方便
装填因子 α = 元素数 ÷ 表长（越大越挤，冲突越多，ASL 越大）　　ASL(成功) = Σ每个元素的比较次数 ÷ 元素数

样例手算（背熟流程）

H(k) = k mod 7，表长 7，依次插入 16, 24, 9, 3（线性探测）：

16 → 16 mod 7 = 2（空 → 入格2，比较1次）；24 → 3（空 → 格3，1次）；9 → 2（被 16 占）→ 探 3（被 24 占）→ 探 4（入，3次）；3 → 3（占）→ 探 4（占）→ 探 5（入，3次）。

ASL(成功) = (1 + 1 + 3 + 3) ÷ 4 = 2；装填因子 α = 4/7 ≈ 0.57。

四、自查（全对过课）

✅ 本课一页收获
  1. 折半 = 有序 + 顺序存储；最多比较 ⌊log₂n⌋ + 1 次（n=15→4，n=100→7，n=1023→10）。
  2. H(k)=k mod p，p = 不大于表长的最大质数；线性探测会堆积、二次探测跳跃、链地址挂链表。
  3. α = 元素数/表长，越大越挤；ASL(成功) = 比较次数总和 ÷ 元素数（样例表 = 2）。
  4. 判定树 = 折半过程的树形化，深度就是比较次数上限。
