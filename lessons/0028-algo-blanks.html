试题四算法填空：不写代码，只「反推空位」

课程总目录 ｜ 预计 45 分钟 ｜ 上一课：0027 保底专项
考点定位：下午卷试题四（C 算法填空 15 分，15 分全在空上）；本课 = patterns-algo-notes.md 答题策略的交互版

🎯 这课的赢面 试题四不要求你会写算法，只要求你看懂骨架、反推空位。四步法 + DP 状态转移三件套 + 下面的填空推演器，目标：4~8 个空里稳拿 5–6 个（≥10 分）。

一、题目长什么样（结构固定）

部分内容分值
【说明】算法思想 + 递归式/公式/算例（免费的验算数据！）—
变量说明每个数组/变量的含义——抄到草稿上，所有空都围绕它
C 代码4~8 个空（(1)…(n)）问题 1：填空 ≈8 分
问题 2算法策略 / 复杂度2~4 分
问题 3小数据手算模拟3~5 分

二、填空四步法（每道题都走一遍）

  1. 读【说明】，一句话写下「这个算法在算什么」——编辑距离 =「把 str1 变成 str2 的最少操作次数」；矩阵连乘 =「最少乘法次数」。把变量含义抄在草稿上（d[i][j] 是什么？）。
  2. 标出循环不变量：每层循环在干什么写在旁边（外层=子问题规模、中层=起点、内层=决策）。循环边界就是高频空位。
  3. 从已知反推空位：①对称法——给出的边界对面那个就是空；②赋值链法——空在等号右边，看左边变量被谁用；③公式法——把【说明】的算例数字代进空位验算。
  4. 代入实例自检：用问题 3 的小数据手算一遍，查下标越界（i−1、k+1）与类型匹配。

三、DP 题三件套（试题四的绝对主力）

① 初始化（边界 for）　② 状态转移（主递推循环体）　③ 结果返回（规模最大的那格）
  • 识别特征（问题 2 答「动态规划」的四要素）：表格记录子问题解 + 最优子结构 + 自底向上填表 + 重叠子问题（区别于分治：分治子问题独立、不记忆）。
  • 复杂度口诀：填表格子数 × 每格决策数——双重循环 → O(n²)（编辑距离 O(mn)）；三重循环（枚举断点）→ O(n³)（矩阵连乘）。

四、常考骨架（与原资料 2.3 清单一致）

【一维/二维序列型 DP】                     【区间型 DP（矩阵连乘）】
for (i = 0; i <= len1; i++) d[i][0] = i;   cost[i][i] = 0;
for (j = 0; j <= len2; j++) d[0][j] = j;   for (p = 1; p < n; p++)        /* 区间长度 */
for (i = 1; i <= len1; i++)                  for (i = 0; i < n-p; i++) {  /* 起点 */
  for (j = 1; j <= len2; j++)                  j = i + p;                /* 终点 */
    if (str1[i-1] == str2[j-1])                for (k = i; k < j; k++) { /* 断点 */
      d[i][j] = d[i-1][j-1];                     temp = cost[i][k] + cost[k+1][j]
    else                                                    + 合并代价;
      d[i][j] = min(d[i-1][j]+1,               if (更小) { cost 更新; trace 记录; }
                 d[i][j-1]+1,                } cost[i][j] = tempCost; }
                 d[i-1][j-1]+1);
return d[len1][len2];                      合并代价维数口诀：seq[i]×seq[k+1]×seq[j+1]

其他骨架（原资料 2.3）：二分查找（low=mid+1 / high=mid−1 防死循环）、树递归（终止条件 + 左右子递归）、希尔/堆排序挖空、贪心（排序+局部最优）。挖空点永远在这几处：边界、比较条件、递推表达式、返回值。

五、动手：填空推演器（4 个典型骨架，逐空反推）

💡 使用方法 每个空先遮住选项自己说出答案再点选项——练的是「反推」不是「认对」。答错会告诉你错在哪一类（下标 ±1 / 边界对称 / 漏加一）——这些正是阅卷统计里的丢分大户。

六、高频丢分点自查（原资料 3.1 精选）

  • 下标 ±1：前缀长度 vs 数组位置差 1（str1[i-1]、seq[k+1]）；
  • 边界对称没看出来：一个边界已给，对面那个就是空；
  • 区间换算：j = i+p 还是 i+p−1——用循环边界核对；
  • 结果格子定位：返回 d[len1][len2]（不是 len1−1）；
  • 断点上界：k < j（写成 k<=j 右段为空）；
  • 空要写完整语句：分号、等号左边都算分；
  • 策略题：看到「表格记录 + 最优子结构 + 自底向上」→ 动态规划，别答分治。

七、自查（全对过课）

✅ 本课一页收获
  1. 结构：问题 1 填空 ≈8 分 + 问题 2 策略/复杂度 + 问题 3 手算——15 分全在空上。
  2. 四步法：读说明抄变量含义 → 标循环不变量 → 对称/赋值链/公式反推 → 代入自检查 ±1。
  3. DP 三件套：初始化（对称边界）、主递推（三操作取 min/max）、返回（d[len1][len2]）。
  4. 识别：表格+最优子结构+自底向上+重叠子问题 = DP；复杂度 = 格子数×每格决策数（三重循环 O(n³)）。
