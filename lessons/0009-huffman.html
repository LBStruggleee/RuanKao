哈夫曼树与编码：贪心合并，短码给高频

课程总目录 ｜ 预计 35 分钟 ｜ 上一课：0008 四种遍历与重建
考点定位：WPL 计算必考（2019H2-Q64/65 原题）、节点总数 2n−1、前缀码判别

🎯 这课的赢面 两件事：①给出几个权值，3 分钟算出 WPL（带权路径长度）——用「内部节点求和」这条捷径，比逐叶算深度快一倍；②记住哈夫曼树的三个数字特征（n−1 次合并、2n−1 个节点、没有度为 1 的节点）。

一、它解决什么问题

压缩：字符出现频率不同，高频字符用短编码，总长才能最短。哈夫曼树 = 让「总长」最省的那棵二叉树——带权路径长度（WPL）最小的二叉树。

路径长度 = 从根到该节点的边数　　WPL = Σ（权值 × 路径长度），对所有叶子求和

二、构造：每步合并最小的两个（贪心）

  1. 把所有权值看成一片「小树森林」；
  2. 取当前权值最小的两棵合并，新根权 = 两权之和，放回森林；
  3. 重复直到只剩一棵树。

例：权 {2, 3, 4, 5, 8}：

2+3=5 → 4+5=9 → 5+8=13 → 9+13=22。合并了 4 次（= n−1）。

WPL 捷径：每次合并产生的新权 = 这棵子树所有叶子的深度贡献 → WPL = 所有内部节点（新权）之和 = 5+9+13+22 = 49。不用逐叶数深度。

💡 三个数字特征（必背） n 个叶子的哈夫曼树：合并 n−1 次；节点总数 2n−1；没有度为 1 的节点（n₁=0）。第三条与 Lesson 0007 的 n₀=n₂+1 联立：n = n₀+n₂、n₀=n₂+1 → n = 2n₀ − 1。

三、哈夫曼编码：左 0 右 1 的前缀码

从根走到每个叶子，左转记 0、右转记 1，得到的 0/1 串就是该字符的编码。因为字符都在叶子上（没有谁的路经过谁），任何编码都不可能是另一个编码的前缀——这叫前缀码，解码时不会歧义。

⚠ 判别技巧 集合 {0, 10, 110, 111} ✔ 合法（画出正好 4 个叶子）；{1, 10, 11} ✘——1 既是 10 又是 11 的前缀（对应「1」不是叶子而在路径上）。判断题就考这一眼。

四、动手：亲手贪心合并，看 WPL 怎么长出来

💡 观察任务 合并完成后看 WPL 的两行验证：内部节点求和（快）与 Σ权×深度（慢）必须相等。之后用 {1,2,3,4,5} 重置再走一遍——下面测验里就有它。

五、自查（全对过课）

✅ 本课一页收获
  1. 构造 = 每步合并当前最小两权（贪心）；WPL 捷径 = 所有内部节点权之和。
  2. n 叶哈夫曼树：合并 n−1 次、共 2n−1 节点、n₁ = 0。
  3. 编码 = 左 0 右 1 的前缀码；判合法 = 没有任何编码是别人的前缀。
  4. WPL 最小 ⇒ 高频权值离根近（路径短）。
