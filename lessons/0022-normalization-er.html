范式与 E-R 图：候选码判定 + 模式转换

课程总目录 ｜ 预计 40 分钟 ｜ 上一课：0021 关系代数与 SQL
考点定位：候选码 4 步判定、1NF–BCNF 分界、M:N 联系转换（day08-er.md，下午大题 E-R 的根基）

🎯 这课的赢面 范式题的解题起点永远是候选码——4 步判定法（L/R/N/LR 分类 → L、N 直接入码 → 求闭包 → 不够再配 LR）。加上三条范式快解和 E-R「M:N 独立成表」铁律，上午判断题 + 下午 E-R 大题一起吃。

一、函数依赖（FD）三兄弟

依赖定义例子引发问题
完全依赖码的全部才能决定它(学号,课号) → 成绩—
部分依赖码的一部分就能决定非主属性(学号,课号) → 学生姓名违反 2NF（冗余/异常）
传递依赖A→B、B→C（B 不依赖于 A）学号→系名→系主任违反 3NF

二、候选码判定 4 步法（一切范式题的起点）

  1. 把属性按在依赖中出现的位置分类：L（只出现在左部）、R（只在右部）、N（不出现）、LR（两边都有）；
  2. L 和 N 一定在候选码里；R 一定不在；
  3. 求 (L∪N) 的属性闭包（用 Armstrong：自反/增广/传递推）——若已含全部属性，它就是候选码；
  4. 若没含全部，把 LR 属性逐个/组合加入再求闭包，恰好覆盖全属性的即为候选码（可能有多个）。

例：R(A,B,C,D)，F = {A→B, B→C}。分类：A 是 L，D 是 N，B、C 是 R。候选码必含 A、D → (AD)⁺ = {A,D,B,C}（A→B→C）→ 覆盖全部 → 候选码 AD。

三、范式：1NF → 2NF → 3NF → BCNF

1NF 属性原子 → 2NF 消除非主属性对码的部分依赖 → 3NF 消除传递依赖 → BCNF 所有决定因素都是候选码

三条考场快解（原资料口径）：

  • 候选码都是单属性 → 不存在部分依赖 → 至少 2NF；
  • 全部属性都是主属性（都在某候选码里）→ 至少 3NF；
  • 每个函数依赖的左部都是候选码 → BCNF。

3NF vs BCNF 分界例（背）：R(A,B,C)，F = {AB→C, C→B}。候选码：AB 与 AC。C→B 的左部 C 不是候选码 → 不是 BCNF；但 B 是主属性、不存在非主属性传递依赖 → 仍是 3NF。结论：3NF 但非 BCNF。

四、E-R 图与模式转换（下午大题铁律）

  • E-R 三要素：实体、属性、联系；联系类型判定：两个方向各取一端问「最多几个」→ 1:1 / 1:N / M:N。
  • 转换规则：实体 → 一个关系模式；1:1 联系：并入任意一端；1:N 联系：并入 N 端（加对方主键做外键）；M:N 联系：必须独立成一个关系模式，主键 = 双方主键的组合。
⚠ 高频判断 『M:N 联系可以合并进任何一端』——错！只有 1:1 和 1:N 能并入；M:N 独立成表，这是 E-R 大题判分点。

五、自查（先动笔推候选码再点）

✅ 本课一页收获
  1. 候选码 4 步：L/R/N/LR 分类 → L、N 直接入码 → 求闭包 → LR 补齐。
  2. 范式链：1NF 原子 → 2NF 消部分依赖 → 3NF 消传递依赖 → BCNF 决定因素皆候选码。
  3. 快解：单属性码≥2NF；全主属性≥3NF；左部皆码=BCNF。R(A,B,C) F={AB→C,C→B} → 3NF 非 BCNF。
  4. E-R 转换：1:1 并任一端、1:N 并 N 端、M:N 独立成表（主键 = 双方主键组合）。
