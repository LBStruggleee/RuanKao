Day 13软件工程② 练习题：设计原则 / 耦合内聚 / 测试方法 / 项目管理（20 选择 + 3 计算）

说明：本题是 Day 13 的章节题，对应笔记 day13-test.md。 题目分布：设计原则 3 题（1–3）、耦合与内聚 5 题（4–8）、黑盒测试 3 题（9–11）、白盒测试与 McCabe 5 题（12–16）、软件维护 2 题（17–18）、项目管理 2 题（19–20），另加 3 道独立路径 / 逻辑覆盖计算题（21–23）。 完整答案与解析在文件末尾。建议独立闭卷完成（选择题约 30 分钟，计算题约 25 分钟）再对答案。 做题纪律： - 第 4–7 题（耦合 / 内聚）是本日必考内容，两级的七级顺序必须能默写；场景题错了就回 day13-test.md §2.2、§3.2 把两张分级表整表重背。 - 第 13–16 题 + 计算第 21–23 题（覆盖标准 + 圈复杂度）是软考软件工程的最高频计算考点，分值占比高。做计算题时必须自己先画控制流图、自己数边和节点，再与解析对照——只看答案是学不会的。 - 计算题第 21–23 题的所有数字均已用两种方法交叉验算（V(G)=E−N+2 与 V(G)=判定节点数+1，独立路径数用矩阵秩验证），可放心对答案。

附：Day 13 笔记「一页纸结论」速答

  1. 设计七大原则：单一职责（SRP）、开闭（OCP）、里氏替换（LSP）、依赖倒置（DIP）、接口隔离（ISP）、迪米特法则（LoD）、组合/聚合复用（CARP）。
  2. SRP = 一个类只有一个引起它变化的原因；OCP = 对扩展开放、对修改关闭；LSP = 子类必须能替换父类，行为不变。
  3. DIP = 高层不依赖低层，两者都依赖抽象；抽象不依赖细节，细节依赖抽象（面向接口编程）。
  4. 耦合七级（低→高）：非直接、数据、标记、控制、外部、公共、内容。口诀："非数标控外公内"。
  5. 内聚七级（低→高）：偶然、逻辑、时间、过程、通信、顺序、功能。口诀："偶逻时过通顺功"（偶然逻辑时间过程通信顺序功能）。
  6. 数据耦合传简单参数；标记耦合传整个数据结构（记录）；控制耦合传"决定对方走哪段逻辑"的标志。
  7. 过程内聚 = 按固定顺序执行；顺序内聚 = 前一元素的输出是后一元素的输入（有数据链）；功能内聚 = 只为完成一个功能（最强）。
  8. 设计目标：高内聚、低耦合——两者是度量模块独立性的两个标准。
  9. 黑盒依据 = 需求规格说明书（功能/行为）；白盒依据 = 程序内部结构与执行逻辑（源代码）。
  10. 测试四阶段：单元（编码后、开发者做）→ 集成（概设/详设后）→ 系统（SRS 后）→ 验收（用户参与）。
  11. 黑盒三方法：等价类划分、边界值分析、因果图（输入间有组合/约束关系时用因果图）。
  12. 覆盖强度（弱→强）：语句 < 判定 < 条件 < 判定-条件 < 条件组合 < 路径。
  13. 条件覆盖不保证判定覆盖（反例：a=1,b=0 与 a=0,b=1 把 C1/C2 的真假都覆盖了，但 D1=假恒成立，真分支从未执行）。
  14. McCabe 圈复杂度 V(G) = E − N + 2 = 判定节点数 + 1（三种算法等价）。
  15. V(G) 的意义 = 独立路径数 = 基本路径测试所需的最少测试用例数；V(G) 越大越复杂，建议 V(G) ≤ 10。
  16. 基本路径测试四步：①画 CFG ②算 V(G) ③列出 V(G) 条独立路径 ④每条路径设计一个用例。
  17. 维护四类型：改正性（改错，~20%）、适应性（适应环境变化，~25%）、完善性（加功能/改进，~50% 最大）、预防性（提高可维护性）。
  18. 维护判别两步法：先问"系统错了吗"→改正性；再问"是环境变了还是用户想要更多"→环境变了=适应性，用户要更多/更好=完善性。
  19. 甘特图直观显示任务起止时间与进度，但难以反映任务间依赖关系与关键路径。
  20. 关键路径 = 从源点到汇点路径长度最长的路径，其长度 = 项目最短工期；关键路径上的任务延期会导致整个项目延期。

第 21 题（两个串联判定，V(G) = 3）

int bonus(int a, int b) {
    if (a > 0 && b > 0) {     // 判定 D1：条件 C1=(a>0), C2=(b>0)
        a = a + 2;            // 语句 S1
    }
    if (a > 5) {              // 判定 D2：条件 C3=(a>5)  —— 注意 a 可能已被 S1 修改
        a = a * 3;            // 语句 S2
    }
    return a;
}

（1） 画出控制流图，计算 V(G)； （2） 列出全部可能路径与独立路径； （3） 为每条独立路径给出一个测试输入，并验算返回值； （4） 若要达到判定覆盖，最少需要几个用例？达到语句覆盖呢？

第 22 题（三个判定 + 提前返回，V(G) = 4）

int fee(int w, int v) {
    if (w <= 0 || v <= 0) {                 // 判定 D1：C1=(w<=0), C2=(v<=0)
        return -1;                          // 非法输入
    }
    int f;
    if (w <= 5 && v <= 5) {                 // 判定 D2：C3=(w<=5), C4=(v<=5)
        f = 10;                             // 小件：一口价
    } else {
        f = 10 + (w - 5) * 3;               // 超重部分每单位 3 元
    }
    if (f > 50) {                           // 判定 D3：C5=(f>50)
        f = f + 20;                         // 大宗运费加价
    }
    return f;
}

（1） 画出控制流图，计算 V(G)； （2） 列出全部可能路径与独立路径，并指出哪条结构上存在、但实际不可行； （3） 为每条独立路径给出一个测试输入，并验算返回值。

第 23 题（含循环的回边处理，V(G) = 3）

int sum(int n, int k) {
    int i = 1, s = 0;
    while (i <= n) {      // 判定 D1（循环条件）
        s = s + i;        // 语句 S1
        i = i + 1;        // 语句 S2
    }
    if (k > 0) {          // 判定 D2
        s = s * k;        // 语句 S3
    }
    return s;
}

（1） 画出控制流图（注意 ③→② 的回边），计算 V(G)； （2） 列出独立路径（提示：循环体执行 0 次 / 至少 1 次，是构造独立路径的关键）； （3） 为每条独立路径给出一个测试输入并验算； （4） 用输入 (n=3, k=2) 执行程序，说明它走的是哪条（非独立）组合路径，返回值是多少。

答案与解析

答案速查：1.A　2.A　3.C　4.D　5.D　6.C　7.C　8.A　9.A　10.C　11.B　12.A　13.D　14.C　15.C　16.D　17.D　18.B　19.B　20.D

1. 答案：A - 解析：单一职责原则（SRP）的定义是：一个类应该只有一个引起它变化的原因——即一个类只承担一类职责。职责越多，引起它变化的"触发点"就越多，类就越脆弱。 - B 干扰项：把"职责"等同于"方法数量"。SRP 限制的是职责维度，一个承担单一职责的类完全可以有多个方法（如 Order 类有 addItem、removeItem、getTotal，都服务于"订单"这一职责）。 - C 干扰项：类被多少个其他类引用属于耦合问题，与 SRP 无关。D 干扰项：一个类只有一个直接父类是 Java/C# 的单继承语言机制，不是设计原则。 - 知识点：day13-test.md §1.1、§1.2。

2. 答案：A - 解析：里氏替换原则（LSP）：所有引用基类的地方，必须能透明地使用其子类对象，且程序行为不变。子类可以扩展功能，但不能改变父类已有的行为约定（不能加强前置条件、不能削弱后置条件）。 - B 干扰项（最易选错）：子类重写父类方法时必须遵守父类的契约，"任意改写"恰恰是违反 LSP 的典型（如经典的"正方形不是长方形"反例）。 - C 干扰项：子类当然可以新增方法，LSP 从未禁止扩展。D 干扰项：父类的抽象方法，子类必须实现（否则子类仍是抽象类，无法实例化）。 - 知识点：day13-test.md §1.1、§1.3。

3. 答案：C - 解析：开闭原则（OCP）：对扩展开放，对修改关闭——增加新功能时应该通过新增类/扩展来实现，而不是修改已有代码。"每加一种支付方式就要改 PaymentProcessor 源代码"，正是"对修改不关闭"的教科书式违反。正确做法：定义 Payment 接口，每种支付方式是一个实现类，通过多态/策略模式扩展。 - A 干扰项：SRP 强调"一个类只有一个变化原因"；本题的核心矛盾不是"职责过多"，而是"加新类型被迫改旧代码"。B 干扰项：LSP 讨论的是子类替换父类的行为一致性。D 干扰项：DIP 强调依赖抽象而非具体；本题虽然也能用 DIP 改善，但题干描述的直接症状是 OCP 违背。 - 知识点：day13-test.md §1.2、§1.3（三组易混辨析）。

4. 答案：D - 解析：耦合七级（从低到高）：非直接耦合 → 数据耦合 → 标记耦合 → 控制耦合 → 外部耦合 → 公共耦合 → 内容耦合。口诀："非数标控外公内"。耦合越低，模块独立性越强。 - A 干扰项：把"非直接耦合"错放到最高级——非直接耦合是最低级（两模块无直接关系，仅通过主程序间接联系）。 - B 干扰项：把"数据/标记"和"外部/公共"的顺序都颠倒了。数据耦合只传简单参数，标记耦合传完整数据结构，所以数据耦合低于标记耦合。 - C 干扰项："标记"在"数据"之前错位。 - 知识点：day13-test.md §2.2、§2.3。

（2）全部路径与独立路径

全部可能路径 4 条：

路径 节点序列 条件组合 (D1, D2) 测试输入 (a, b) 执行过程与返回值
P1 ①→③→⑤ (假, 假) (0, 0) D1 假 → a 不变；D2：0>5 假 → 返回 0

逐条验算（用输入实际代入函数）：

  • (0,0)：0>0 && 0>0 = 假 → a 保持 0；0>5 = 假 → 返回 0 ✓
  • (6,0)：6>0 && 0>0 = 假（b=0）→ a 保持 6；6>5 = 真 → a = 18 → 返回 18 ✓
  • (2,1)：2>0 && 1>0 = 真 → a = 4；4>5 = 假 → 返回 4 ✓
  • (4,1)：4>0 && 1>0 = 真 → a = 6；6>5 = 真 → a = 18 → 返回 18 ✓

独立路径：V(G) = 3，故独立路径只有 3 条（4 条路径中有 1 条可由其余线性组合得到）。

取 P1、P2、P3 为独立路径集（基），则：

  • P4 = P2 + P3 − P1（边向量线性组合可验证）

即第 4 条路径在"独立"意义上是冗余的。这也解释了：为什么"基本路径测试"只要 V(G) 个用例，而不是全部路径个用例。

（4）判定覆盖与语句覆盖

  • 语句覆盖：要让 S1、S2 都执行一次 → 需要 D1 真（执行 S1）且 D2 真（执行 S2）→ 1 个用例即可，如 (4, 1)。

小结：本题 E=6、N=5、V(G)=3、全部路径 4 条、独立路径 3 条、语句覆盖最少 1 个用例、判定覆盖最少 2 个用例。

P5 ①→③→④→⑥→⑦→⑧ (假, 真, 真) ❌ 不可行

不可行路径 P5 的证明：走 ④ 意味着 D2 为真（w<=5 && v<=5），则 f = 10；而 D3 的条件是 f > 50，10 > 50 恒为假——所以"经过 ④ 又经过 ⑦"这条路径在逻辑上不可能被任何输入触发。

考点提示：V(G) 度量的是结构性的独立路径数，它不区分可行与不可行。考试中若问"基本路径测试需要几个用例"，答案仍是 V(G) = 4（选可行的 4 条），而不是 5。

独立路径：V(G) = 4，取 B1、B2、B3、B4 为独立路径集（矩阵秩验证为 4）。第 5 条满足线性关系 P5 = B2 + B4 − B3（边向量组合可验证），故 P5 是冗余的。

（3）为每条独立路径设计测试输入并验算

独立路径 测试输入 (w, v) 执行过程 返回值
B1：①→②→⑧ (0, 0) D1：0<=0 真 → 提前返回 −1
B2：①→③→④→⑥→⑧ (1, 1) D1 假；D2：1<=5 && 1<=5 真 → f=10；D3：10>50 假 → 返回 f 10
B3：①→③→⑤→⑥→⑧ (10, 1) D1 假；D2：10<=5 假 → f=10+(10−5)×3=25；D3：25>50 假 → 返回 f 25
B4：①→③→⑤→⑥→⑦→⑧ (30, 1) D1 假；D2 假 → f=10+(30−5)×3=85；D3：85>50 真 → f=85+20 105

逐条验算：

  • (0,0)：0<=0 || 0<=0 = 真 → 返回 −1 ✓
  • (1,1)：D1 假；1<=5 && 1<=5 = 真 → f = 10；10>50 = 假 → 返回 10 ✓
  • (10,1)：D1 假；10<=5 = 假 → f = 10 + 5×3 = 25；25>50 = 假 → 返回 25 ✓
  • (30,1)：D1 假；30<=5 = 假 → f = 10 + 25×3 = 85；85>50 = 真 → f = 105 → 返回 105 ✓

小结：本题 E=10、N=8、V(G)=4、结构路径 5 条（其中 1 条不可行）、独立路径 4 条。

第 23 题详解

（1）控制流图（注意回边 ③→②）与 V(G)

                             ┌────────────────────────┐
                             │ ①  i = 1, s = 0        │
                             └────────────┬───────────┘
                                          │
                                          ▼
                             ┌────────────────────────┐
           └────────────────▶│ ②  i <= n ?     (D1)   │
           │                 └───────┬─────────────┬──┘
           │         真               │           假 │
           │                         ▼             ▼
           │     ┌───────────────────────┐       ┌───────────────────────┐
           │     │ ③   s = s+i; i = i+1  │       │ ④   k > 0 ?   (D2)    │
           │     └─────────┬─────────────┘       └───────┬─────────┬─────┘
           ┌───────────────└                             │         │
                                                         │         │
                                                         ▼         │
                                                 ┌─────────────┐   │

                                                 └──────┬──────┘   │
                                                        │          │
                                                        ▼          ▼
                                                 ┌───────────────────┐
                                                 │ ⑥  return s       │
                                                 └───────────────────┘
  • 节点 N = 6（①–⑥），边 E = 7（①→②、②→③、②→④、③→②【回边】、④→⑤、④→⑥、⑤→⑥）
  • 方法一：V(G) = E − N + 2 = 7 − 6 + 2 = 3
  • 方法二：判定节点 D1（while）、D2（if）共 2 个，V(G) = 2 + 1 = 3 ✓ 两种方法一致

回边处理要点：含循环时，"全部可能路径"是无穷多条（循环可执行任意次）。McCabe 的基本路径测试正是为此设计：每条独立路径中，循环体最多被"展开"一次——即只区分"循环执行 0 次"与"循环执行至少 1 次"，再加上其他判定的分支组合。

（2）独立路径（3 条）

独立路径 节点序列 语义 测试输入 (n, k) 返回值
B1 ①→②→④→⑥ 循环 0 次，且 k≤0 (0, 0) 0
B2 ①→②→③→②→④→⑥ 循环执行 1 次，k≤0 (1, 0) 1
B3 ①→②→④→⑤→⑥ 循环 0 次，且 k>0 (0, 3) 0

（3）逐条验算

  • (0, 0)：i=1，1<=0 假 → 循环 0 次，s=0；0>0 假 → 返回 0 ✓
  • (1, 0)：i=1，1<=1 真 → s=0+1=1，i=2；2<=1 假 → 退出；0>0 假 → 返回 1 ✓
  • (0, 3)：i=1，1<=0 假 → 循环 0 次，s=0；3>0 真 → s=0×3=0 → 返回 0 ✓

（4）组合路径 (n=3, k=2)

执行过程：i=1→1<=3 真→s=1,i=2；i=2→2<=3 真→s=1+2=3,i=3；i=3→3<=3 真→s=3+3=6,i=4；i=4→4<=3 假→退出；此时 s=6；k=2>0 真 → s=6×2=12 → 返回 12。

所走路径：①→②→③→②→③→②→③→②→④→⑤→⑥（循环体 ③ 被执行了 3 次，最后经过 ⑤）。

它为什么不是独立路径：这条路径在"路径向量空间"中等于 B2 + B3 − B1（循环每多执行一次，就多叠加一次"③→②"这个环）。独立路径只取每个环的一次代表，所以 V(G)=3 已经足够覆盖所有"环"与分支的组合。这也再次说明：V(G) = 独立路径数 = 基本路径测试的最少用例数。

小结：本题 E=7、N=6、V(G)=3、独立路径 3 条（回边 ③→② 贡献 1 个环、D2 贡献 1 个分支，加上主干共 3）。
