计算机组成与体系结构 - 知识点精讲

一、计算机基本结构

1.1 冯·诺依曼结构

  • 五大部件：运算器、控制器、存储器、输入设备、输出设备
  • 核心思想：存储程序，程序控制
  • 指令和数据：统一存储（二进制表示）

1.2 现代计算机结构

  • CPU = 运算器 + 控制器
  • 存储器 = Cache + 主存 + 辅存
  • 总线 = 数据总线 + 地址总线 + 控制总线

二、CPU

2.1 CPU组成

  • ALU（算术逻辑单元）：执行算术和逻辑运算
  • CU（控制单元）：指令译码和控制信号生成
  • 寄存器：
  • 程序计数器（PC）：下一条指令地址
  • 指令寄存器（IR）：当前指令
  • 累加器（ACC）：运算结果
  • 状态寄存器（PSW）：标志位
  • 地址寄存器（MAR）：地址
  • 数据寄存器（MDR）：数据

2.2 指令系统

  • 指令格式：操作码 + 地址码
  • 寻址方式：
  • 立即寻址：操作数在指令中
  • 直接寻址：操作数地址在指令中
  • 间接寻址：地址的地址
  • 寄存器寻址：操作数在寄存器中
  • 寄存器间接寻址：地址在寄存器中

三、存储系统

3.1 存储层次

寄存器 → Cache → 主存 → 辅存
 速度快    较快     一般     慢
 容量小    小       较大     大

3.2 Cache

  • 作用：缓解CPU与主存速度差异
  • 映射方式：
映射方式 特点 适用场景
直接映射 固定对应，简单 通用
全相联映射 任意映射，灵活 小容量Cache
组相联映射 分组内灵活 折中方案
  • 替换算法：LRU、LFU、随机
  • 写策略：写直达、写回

3.3 主存

  • RAM：随机存取（SRAM/DRAM）
  • ROM：只读存储器
  • DRAM刷新：集中刷新/分散刷新/异步刷新

四、指令流水线

4.1 流水线原理

  • 将指令执行分为多个阶段
  • 不同指令的不同阶段重叠执行

4.2 流水线阶段

取指令 → 译码 → 执行 → 访存 → 写回

4.3 流水线性能

  • 加速比 = 不流水线时间 / 流水线时间
  • 吞吐率 = 单位时间完成指令数
  • 最大吞吐率 = 1 / 流水线周期

4.4 流水线冲突

  • 结构冲突：硬件资源冲突
  • 数据冲突：数据依赖
  • 控制冲突：分支指令

五、总线

5.1 总线类型

  • 数据总线：传输数据（双向）
  • 地址总线：传输地址（单向）
  • 控制总线：传输控制信号（双向）

5.2 总线带宽

总线带宽 = 总线频率 × 总线宽度 / 8

六、I/O系统

6.1 I/O控制方式

  1. 程序I/O：CPU不断查询
  2. 中断I/O：I/O完成通知CPU
  3. DMA：直接内存访问
  4. 通道：专用I/O处理器

6.2 中断系统

  • 中断类型：硬件中断、软件中断
  • 中断向量：中断号→中断处理程序入口
  • 中断优先级：可屏蔽/不可屏蔽

七、计算题公式

7.1 存储器相关

主存地址位数 = log₂(主存容量/字节)
Cache块大小 = 块内字节数
Cache块数 = Cache容量 / 块大小
主存块号 = 地址 / 块大小

7.2 Cache地址计算

直接映射：
  Cache块号 = 主存块号 % Cache块数
  地址 = Tag + Cache块号 + 块内偏移

全相联/组相联：
  地址 = Tag + 组号 + 块内偏移

7.3 流水线计算

执行n条指令时间 = 流水线周期 + (n-1) × 流水线周期
加速比 = 串行时间 / 流水线时间

7.4 总线带宽

总线带宽 = 总线工作频率 × 总线位宽 / 8 (字节/秒)

八、常见考点

  1. 指令寻址方式：判断不同寻址方式的操作数位置
  2. Cache映射计算：给定地址求Cache块号/Tag
  3. 流水线性能：加速比、吞吐率计算
  4. 总线带宽：数据传输率计算
  5. 中断处理：中断向量、中断优先级
  6. 补码运算：加减法运算、溢出判断
