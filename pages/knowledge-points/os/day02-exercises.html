Day 2（9/22）操作系统② 练习题：内存管理（20 选择题 + 3 地址转换计算题）

说明：第 1–20 题为「内存管理」选择题（覆盖分页/分段/段页式/虚拟内存/置换算法/缺页/TLB）；第 21–23 题为地址转换计算题（必考，含完整解答步骤）。 完整答案解析在文件末尾。建议先独立完成（选择题约 40 分钟，计算题再 40 分钟），再对答案。

附：Day2 笔记「快速自测」速答

  1. 逻辑地址（按 32 位补齐为 0x0001A2B3）切低 12 位：页内偏移 = 0x2B3，剩下的高位 = 0x1A，即页号 = 0x1A。
  2. 页号 = 7000 ÷ 2048 = 3，偏移 = 7000 − 3×2048 = 856；物理地址 = 8 × 2048 + 856 = 17240。
  3. 3 次（外层页表 + 内层页表 + 数据）。
  4. 能，叫 Belady 异常（FIFO 特有）。
  5. LRU 的近似（NRU 算法）。

第二部分：地址转换计算题（21–23）

21.（页式地址转换） 某分页系统，页面大小为 4KB，页表（部分）如下：

页号 块号（页框号）
0 2
1 5
2 8
3 1

求： （1）逻辑地址 10240 对应的页号、页内偏移； （2）该逻辑地址转换后的物理地址（十进制）。

22.（多级页表访存次数 + TLB 平均访存次数） 某系统采用二级页表（无快表）。

（1）访问一次内存数据，最少需要多少次访存？请说明分别是哪几次。 （2）若增加快表 TLB，命中率为 90%（忽略快表本身的访问时间），平均每次访问数据需要多少次访存？ （3）若快表命中率 90%、快表访问时间 20ns、内存访问时间 100ns，求平均有效访问时间 EAT。

23.（综合：页表大小 + 置换算法） 某进程逻辑地址空间 32 位，页大小 4KB，页表项（含状态位、访问位、修改位等控制位）每项 4 字节。

（1）该进程逻辑地址空间最多可划分为多少个页面？ （2）该进程的页表最多占用多少内存（用 MB 表示）？ （3）若该进程某段时间的页面访问序列为 3, 2, 1, 0, 3, 2, 4, 3, 2, 1, 0, 4，内存分配 3 个物理块（初始为空），分别用 FIFO 和 LRU 计算缺页次数。

答案解析

第一部分（1–20）

1. C 分页中页与页框大小相等（都是固定的 2 的幂次方字节，如 4KB）。这是地址转换"页内偏移原样搬运"成立的前提。（知识点：分页基本概念）

2. B 页大小 4KB = 2^12，故页内偏移占 12 位；页号占 32 − 12 = 20 位。（知识点：逻辑地址结构拆分）

3. B 物理地址 = 块号 × 页大小 + 页内偏移。块号来自页表，页内偏移原样搬。A 把页号当块号，C/D 漏乘页大小。（知识点：地址转换公式）

4. B 段式物理地址 = 段基址 + 段内偏移（段基址本身是内存字节地址，直接加）。与页式"乘页大小"形成对照。（知识点：段式地址转换）

5. B 页式把进程切成等大小页，离散装入任意页框，消除了连续分配带来的外部碎片（页内的小浪费属内部碎片，依然存在）。（知识点：碎片）

6. C 段式保护利用段长：段内偏移 ≥ 段长即越界，产生分段越界中断。段基址用于合成地址，不是越界判断依据。（知识点：段式越界检查）

7. D 分段存储按程序的逻辑单位变长分配、段内连续完整使用，不存在"分配的空间大于实际需要"的浪费，故没有内部碎片（但会产生段间空闲的外部碎片）。A 分页（最后一页装不满的页内零头）、B 固定分区（分区大于进程）、C 段页式（每段内部分页，同样有页内零头）都属于"分配固定大小的块"，都会产生内部碎片。（知识点：内部碎片 vs 外部碎片）

8. B 段页式先按段号查段表得该段页表地址，再按页号查页表得块号，顺序为「段表 → 页表」。（知识点：段页式地址转换）

9. B 无快表时一级页表：查内存页表 1 次 + 访内存数据 1 次 = 2 次。（知识点：访存次数）

10. A TLB 命中时，快表访问算寄存器/硬件级不算访存，只需再访数据 1 次。（知识点：TLB 命中访存次数）

11. B TLB 是相联存储器实现的高速页表项缓存，只存活跃项。A 是慢表定义，C/D 无关。（知识点：快表）

12. A 虚拟内存的理论基础是局部性原理（时间局部性 + 空间局部性）。（知识点：局部性原理）

13. B 虚拟存储三特征：多次性、对换性、虚拟性。A/C/D 的"一次性/驻留性/内存性"是错误拼凑。（知识点：虚拟内存特征）

14. C 缺页中断是内部中断（异常），在指令执行期间产生；处理完后需重新执行被中断的那条指令。（知识点：缺页中断性质）

15. B 缺页且无空闲块时，先按置换算法选一页换出（若被修改需先写回磁盘），再调入所需页。A 错：一条指令可跨页、含多个操作数，可能产生多次缺页；C/D 明显错误。（知识点：缺页处理流程）

16. C OPT 是理论最优参照。FIFO/LRU/Clock 都是可实现但性能次于 OPT 的算法。（知识点：置换算法定位）

17. C OPT 淘汰将来最长时间内不再被访问的页面（无法预知未来，故实际不可实现）。（知识点：OPT）

18. A Belady 异常只出现在 FIFO：增加物理块，缺页次数反而增多。LRU/OPT/Clock 都是栈式算法，无 Belady 异常。（知识点：Belady 异常）

19. B Clock（NRU）是 LRU 的近似，用访问位近似"最近未使用"信息，硬件开销远小于精确 LRU。（知识点：Clock 算法）

20. B EAT = (1−p)×100 + p×8×10^6 = 0.99×100 + 0.01×8,000,000 = 99 + 80,000 = 80099ns ≈ 80μs。（知识点：含缺页的有效访问时间）

第二部分（21–23）

21. 页式地址转换

（1）页大小 S = 4KB = 4096B。

  • 页号 P = 10240 ÷ 4096 = 2（10240 = 2 × 4096 + 2048）。
  • 页内偏移 W = 10240 mod 4096 = 2048。

（2）查页表：页号 2 → 块号 8。

  • 物理地址 PA = 8 × 4096 + 2048 = 32768 + 2048 = 34816。

验证：块号 8 起始地址 = 8 × 4096 = 32768，加偏移 2048 → 34816。✅ 也可二进制切位：4096 = 2^12，逻辑地址 10240 = 0x2800，低 12 位 0x800 = 2048（偏移），高位 = 2（页号）。✅

22. 多级页表访存次数 + TLB

（1）二级页表（无快表）访问一次数据 = 访问外层（顶级）页表 + 访问内层（二级）页表 + 访问数据 = 3 次访存。

（2）TLB 命中率 90%（忽略快表时间）：

  • 命中：TLB 直接得块号，只需访数据 1 次；
  • 未命中：查二级页表 2 次 + 访数据 1 次 = 3 次；
  • 平均访存次数 = 0.9 × 1 + 0.1 × 3 = 0.9 + 0.3 = 1.2 次。

（3）快表访问 20ns、内存访问 100ns、命中率 90%：

  • 命中：20（快表）+ 100（数据）= 120ns；
  • 未命中：20（快表）+ 100×2（两级页表都在内存）+ 100（数据）＝ 320ns； （这里未命中需访问内存 3 次：两次页表 + 一次数据，故 t_mem 出现 3 次。）
  • EAT = 0.9 × 120 + 0.1 × 320 = 108 + 32 = 140 ns。

23. 综合题

（1）页大小 4KB = 2^12，页号位宽 = 32 − 12 = 20 位 → 最多 2^20 = 1,048,576 个页面。

（2）页表大小 = 页表项数 × 每项大小 = 2^20 × 4B = 4,194,304 B = 4 MB。

（3）访问序列 3,2,1,0,3,2,4,3,2,1,0,4，3 个物理块。

FIFO（框0 = 队头，最早进入）：

页:    3   2   1   0   3   2   4   3   2   1   0   4
框0:   3   3   3   2   1   0   3   3   3   2   4   4
框1:   -   2   2   1   0   3   2   2   2   4   1   1
框2:   -   -   1   0   3   2   4   4   4   1   0   0
缺页   ×   ×   ×   ×   ×   ×   ×   ✓   ✓   ×   ×   ✓

缺页次数 = 9 次（第 1,2,3,4,5,6,7,10,11 步缺页；第 8、9、12 步命中）。

LRU（框0 = 最久未用，框2 = 最近使用；每次访问都把该页挪到框2）：

页:    3   2   1   0   3   2   4   3   2   1   0   4
框0:   3   3   3   2   1   0   3   2   4   3   2   1   ← 最久未用
框1:   -   2   2   1   0   3   2   4   3   2   1   0
框2:   -   -   1   0   3   2   4   3   2   1   0   4   ← 最近使用
缺页   ×   ×   ×   ×   ×   ×   ×   ✓   ✓   ×   ×   ×

缺页次数 = 10 次（第 1,2,3,4,5,6,7,10,11,12 步缺页；第 8、9 步命中）。

说明：该序列下 FIFO 缺页 9 次、LRU 缺页 10 次——LRU 并非对每个引用串都优于 FIFO。这正说明必须逐格手算，不能背"谁一定比谁少"的结论。两者的演进过程（每一步淘汰哪一页）不同，逐格核对上面的表即可看到： - 第 4 步：FIFO 淘汰 3（队头），LRU 也淘汰 3（最久未用，恰好一致）； - 第 7 步：FIFO 淘汰 0，LRU 也淘汰 0； - 第 10 步：FIFO 淘汰 3、LRU 淘汰 4（开始分道扬镳）； - 第 12 步：FIFO 命中 4，LRU 缺页（淘汰 2 换入 4）——这正是两者相差 1 次的来源。

更直观的「块数变多反而缺页变多」现象，见笔记 7.3 节的 Belady 序列 1,2,3,4,1,2,5,1,2,3,4,5：FIFO 在 3 块缺页 9 次、4 块缺页 10 次（Belady 异常），而 LRU 不会出现此现象。
