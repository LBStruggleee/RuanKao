计算机网络 - 知识点精讲

一、网络体系结构

1.1 OSI七层模型

应用层 (7) - HTTP, FTP, SMTP, DNS
表示层 (6) - 编码/加密/压缩
会话层 (5) - 会话管理

网络层 (3) - IP/ICMP/ARP
数据链路层 (2) - 以太网/PPP
物理层 (1) - 比特流传输

1.2 TCP/IP四层模型

应用层 - HTTP, FTP, DNS, SMTP
传输层 - TCP, UDP
网际层 - IP, ICMP, ARP

二、传输层

2.1 TCP

TCP三次握手

  1. 客户端 → 服务端：SYN=1, seq=x
  2. 服务端 → 客户端：SYN=1, ACK=1, seq=y, ack=x+1
  3. 客户端 → 服务端：ACK=1, seq=x+1, ack=y+1

TCP四次挥手

  1. 客户端 → 服务端：FIN=1
  2. 服务端 → 客户端：ACK=1
  3. 服务端 → 客户端：FIN=1
  4. 客户端 → 服务端：ACK=1（TIME_WAIT状态持续2MSL）

TCP核心机制

  • 滑动窗口：流量控制
  • 拥塞控制：慢开始、拥塞避免、快重传、快恢复
  • 确认应答：累计确认
  • 超时重传

2.2 UDP

  • 无连接，不可靠
  • 适用于实时应用（视频/语音）
  • 端口号范围：0-65535

三、网络层

3.1 IP地址

IPv4地址分类

类型 范围 默认掩码
A 1.0.0.0 - 126.255.255.255 255.0.0.0 (/8)
B 128.0.0.0 - 191.255.255.255 255.255.0.0 (/16)
C 192.0.0.0 - 223.255.255.255 255.255.255.0 (/24)

子网划分

步骤： 1. 确定子网数需要的位数：从主机位借位 2. 子网掩码 = 网络位全1 + 子网位全1 + 主机位全0 3. 每个子网可用主机数 = 2^主机位数 - 2 4. 子网数 = 2^借位数

示例：192.168.1.0/24 划分为8个子网 - 借3位（2³=8） - 新掩码：/27 = 255.255.255.224 - 每个子网可用主机：2⁵-2 = 30台 - 子网：0, 32, 64, 96, 128, 160, 192, 224

CIDR（无类别域间路由）

  • 格式：IP地址/前缀长度
  • 路由聚合：合并连续网络

3.2 ARP协议

  • 地址解析协议：IP→MAC
  • 工作流程：广播ARP请求 → 单播ARP应答
  • ARP缓存表

3.3 ICMP协议

  • 网际控制报文协议
  • 应用：ping（测试连通性）、traceroute（追踪路径）
  • 差错报告：目的不可达、超时

四、应用层

4.1 HTTP/HTTPS

  • HTTP：无状态，明文传输，默认80端口
  • HTTPS：HTTP + TLS/SSL加密，默认443端口
  • HTTP方法：GET/POST/PUT/DELETE
  • 状态码：
  • 2xx：成功
  • 3xx：重定向
  • 4xx：客户端错误（404 Not Found）
  • 5xx：服务端错误（500 Internal Server Error）

4.2 DNS

  • 域名解析：域名→IP地址
  • 解析过程：本地缓存 → 本地DNS → 根DNS → 顶级DNS → 权威DNS
  • 记录类型：A, AAAA, CNAME, MX, NS, TXT

4.3 FTP

  • 文件传输协议
  • 控制连接（21）+ 数据连接（20）
  • 主动模式 vs 被动模式

4.4 SMTP/POP3/IMAP

  • SMTP：发送邮件（25端口）
  • POP3：接收邮件（110端口）
  • IMAP：接收邮件（143端口，更现代）

五、网络安全基础

5.1 加密技术

  • 对称加密：AES, DES（速度快，密钥分发难）
  • 非对称加密：RSA（速度慢，密钥易分发）
  • 哈希函数：MD5, SHA（不可逆）

5.2 常见攻击

  • DDoS：分布式拒绝服务
  • SQL注入
  • XSS跨站脚本
  • 中间人攻击

六、核心计算题

6.1 子网划分计算

公式：
- 子网数 = 2^n（n=借位数）
- 每子网主机数 = 2^m - 2（m=剩余主机位数）
- 网络地址 = IP & 子网掩码
- 广播地址 = 网络地址 | (~子网掩码)
- 可用IP范围：网络地址+1 ~ 广播地址-1

6.2 带宽计算

吞吐量 ≤ 带宽
实际吞吐量 = 带宽 × 效率

6.3 校验码

  • 奇偶校验：1位校验
  • CRC：多项式除法
  • 海明码：纠错码
