阶段 1 阶段性测验：操作系统 + 计算机网络 + 数据库（共 45 道选择题）

测验范围：第一阶段全部内容——操作系统（Day 1–3）15 题 + 计算机网络（Day 4–6）15 题 + 数据库（Day 7–8）15 题。 考试规则：计时 60 分钟，独立闭卷完成，每题 1 分，满分 45 分。 合格参照：科目一 75 题合格线为 45 分（60%），故本卷 27/45 为合格线，34/45 以上（75%）为冲刺阶段的目标（对应科目一 55+ 分）。 做题纪律（分科切换节奏）： - OS 题：计算题必须打草稿（地址转换/寻道/信号量），口算几乎必错； - 网络题：概念题居多，凭记忆直接选，每题不超过 40 秒，把时间留给计算题； - 数据库题：SQL 结果题在草稿纸上逐行推导，范式题按 5 步流程走，禁止"看一眼就选"。

完成后：对答案 → 按题号把对错填入下方「答题卡」→ 再把各科正确率填入文末「分科正确率统计表」→ 单科正确率 < 60%（< 9/15）的知识点，在 docs/practice/knowledge-checklist.md 中标记"二轮重点"。

6 D 死锁四必要条件（day01 §6.1）
7 B 银行家算法 = 死锁避免（day01 §6.2）
8 A 信号量 P/V 运算（day01 §5.2）
9 A 页式地址转换：物理地址 = 块号 × 页大小 + 偏移（day02 §3.4）
10 C 二级页表访存次数与 TLB（day02 §3.4–3.5）
11 B Belady 异常只出现在 FIFO（day02 §7.3）
12 A 缺页中断属于内部中断（day02 §6.1）
13 A 磁盘调度只优化寻道时间（day03 §3.1）
14 A SSTF 寻道距离计算（day03 §3.2）
15 A 一级索引可管理文件大小（day03 §6.1）

1. A：PCB 是进程存在的唯一标志，进程与 PCB 一一对应。B 错——PCB 中的现场信息、状态、队列指针等在进程运行期间不断变化；C 错——PCB 保存的是进程的描述信息、控制信息和资源信息，程序代码本身在代码段；D 错——PCB 是进程的私有结构，不能共享。

2. B：阻塞态不能直接到执行态，必须先回就绪态排队，由调度程序选中后才能执行。这是五状态模型中最常考的非法转换判断。

3. C：进程是资源分配的基本单位，线程是处理机调度的基本单位（这是固定考点，见 day01 §3.3）。A、B、D 均正确。

4. A：SJF 按运行时间从短到长调度，顺序为 2 → 4 → 6 → 8。周转时间 = 完成时间 − 到达时间（同时到达，到达均为 0）：2、6、12、20。平均周转 = (2+6+12+20) ÷ 4 = 10。必须画甘特图列时间轴，口算易排错顺序。

5. B：时间片过小 → 单位时间内上下文切换次数过多，系统效率下降；A（长作业饥饿）是 SJF 的问题；D（退化为 FCFS）是时间片过大的结果。

6. D：死锁四个必要条件 = 互斥、请求和保持（占有并等待）、不剥夺（不可抢占）、循环等待。时间片轮转是调度算法，与死锁条件无关。

7. B：银行家算法在每次资源分配前检查系统是否处于安全状态，属于死锁避免（不是预防——预防要破坏必要条件；也不是检测——检测是事后发现）。

8. A：3 − 1（P）= 2；2 − 1（P）= 1；1 + 1（V）= 2；2 − 1（P）= 1；1 + 1（V）= 2。

9. A：页大小 4KB = 4096。页号 P = 8452 ÷ 4096 = 2（商），页内偏移 W = 8452 mod 4096 = 260。物理地址 = 块号 × 页大小 + W = 5 × 4096 + 260 = 20480 + 260 = 20740。（注意：页式是"乘页大小"，段式才是"加段基址"。）

10. C：二级页表，TLB 未命中时需：① 访问外层页表（1 次）→ ② 访问内层页表（1 次）→ ③ 取数据（1 次）= 3 次。若 TLB 命中则只需 1 次（快表查找是硬件操作，不计入访存）。

11. B：Belady 异常——增加分配的物理块数反而使缺页次数增加——只出现在 FIFO。OPT、LRU、Clock 都不会出现。这是 FIFO 的标志性缺陷。

12. A：缺页中断属于内部中断（程序性中断），在指令执行期间产生，执行完后返回被中断的指令重新执行（这一点与一般的内部中断"返回下一条指令"不同）。外部中断指时钟、I/O 完成等硬件中断。

13. A：磁盘调度算法（FCFS/SSTF/SCAN/C-SCAN 等）只优化寻道时间，因为机械移动中寻道最耗时；旋转延迟与传输时间由硬件决定，调度算法一般不干预。

14. A：SSTF 每次选择离当前磁头最近的请求： 100 → 90（10）→ 58（32）→ 55（3）→ 39（16）→ 38（1）→ 18（20）→ 150（132）→ 160（10）→ 184（24）。 总距离 = 10+32+3+16+1+20+132+10+24 = 248。 必须逐段列出移动距离，并注意 SSTF 会"折返跑"、可能造成远端请求饥饿。

15. A：一级索引的索引项数 = 块大小 ÷ 块号字节数 = 4KB ÷ 4B = 1024 项；每项指向一个 4KB 数据块 → 最大 = 1024 × 4KB = 4096KB = 4 MB。（对照记忆：一级 4MB / 二级 4GB / 三级 4TB。）

第二部分：计算机网络（16–30）

17 A ARP 属网际层（网络层），IP↔MAC（day04 §2.3、§6.3）
18 C 必背端口号（day04 §七）

16. B：表示层负责数据格式转换（如 ASCII↔EBCDIC）、数据加密与数据压缩。应用层提供用户接口，会话层管理会话同步，传输层提供端到端可靠通信。

17. A：ARP（地址解析协议）工作在网络层（网际层）——它为 IP 服务，把 IP 地址解析为 MAC 地址。注意：ARP 报文不用 IP 封装（直接装在以太网帧里），所以常被误认为属于数据链路层，软考按"网络层"作答。UDP 是传输层，HTTP/SMTP 是应用层。

18. C：SMTP = 25（发邮件）。A 错——DNS = 53，110 是 POP3（收邮件）；B 错——FTP 控制连接 = 21，数据连接 = 20；D 错——HTTP = 80，8080 只是常见的非官方备用端口。

19. A：封装是自上而下逐层加头：应用层报文 → 传输层加 TCP 首部成为报文段 → 网络层加 IP 首部成为 IP 数据报 → 数据链路层加帧头帧尾成为帧 → 物理层转比特流。B 错（传输层不加 IP 头）、D 错（TCP 头在 IP 头之内，顺序不能颠倒）。

20. B：交换机工作在数据链路层（基于 MAC 地址转发）。集线器是物理层（广播式中继），路由器是网络层（基于 IP 转发），网关工作在传输层及以上（协议转换）。

21. B：三次握手中，服务器在 LISTEN 状态收到客户端 SYN 后，回送 SYN+ACK，自己进入 SYN-RCVD；收到客户端的 ACK 后才进入 ESTABLISHED。客户端发 SYN 后进入 SYN-SENT。

22. A：TIME-WAIT 等待 2MSL 的两个目的：① 保证最后的 ACK 能到达被动关闭方（若丢失，对方会重发 FIN，本端可再次重传 ACK）；② 让本次连接的所有报文段都从网络中消失，防止它们干扰同一对套接字的新连接。与拥塞窗口、本端数据发送无关。

23. B：TCP = 面向连接、可靠、首部固定 20 字节、点对点；UDP = 无连接、不可靠、首部固定 8 字节、支持广播/多播、开销小速度快。A 的数字写反了；C 说反了（UDP 才支持广播）；D 错——"不可靠"是 UDP 的定义属性。

24. B：3 个重复 ACK（快重传）：ssthresh = cwnd ÷ 2，cwnd = ssthresh（减半但不回 1），进入快恢复。超时才是 ssthresh = cwnd ÷ 2、cwnd = 1（回 1 重新慢开始）。口诀："超时回 1，重复 ACK 减半"。

25. A：/26 → 掩码 255.255.255.192 → 块大小 = 256 − 192 = 64；第 4 段 170 落在 128–191 这个块内（170 ÷ 64 = 2 余 42 → 块起始 128）→ 网络地址 = 192.168.10.128。广播地址 = 128 + 64 − 1 = 192.168.10.191。

26. A：掩码 255.255.255.192 = /26 → 主机位 h = 32 − 26 = 6 → 可用主机数 = 2⁶ − 2 = 62（必须减 2：网络地址与广播地址不可分配）。

27. A：4 个连续的 /24 且起始地址对齐 → 聚合 2² = 4 个网络，前缀减少 2 位 → 172.16.0.0/22。聚合条件：被聚合的网络必须连续且起始地址对齐（第三段 0、1、2、3 的共同前缀是 22 位）。

28. A：DES 的分组长度为 64 位，有效密钥长度为 56 位（64 位输入中有 8 位是奇偶校验位，不参与加密运算）。"56 和 64"是最容易记反的一对；DES 属对称加密（3DES 有效密钥 168 位；AES 分组固定 128 位、密钥 128/192/256 → 轮数 10/12/14）。

29. A：数字签名 = 发送方用自己的私钥对报文摘要加密（或对摘要做签名运算），附着在报文后发送，可提供身份认证、抗否认（不可抵赖）、完整性保护。B/C 错——数字签名不提供机密性（签名后的报文仍是明文，要保密必须再加密或用数字信封）；D 错——签名依赖非对称加密（私钥签名、公钥验签）。

30. C：IDS 旁路（镜像）部署，只检测并告警，不改变业务流量；IPS 串联部署，发现攻击可以直接丢弃/阻断数据包。两者是"告警 vs 阻断"的关系。

31. B：目（Degree）= 关系的列数（属性个数）；基数（Cardinality）= 关系的行数（元组个数）。这是最容易被反过来问的一对术语。

32. A：主码非空且唯一 = 实体完整性（对应 PRIMARY KEY）。参照完整性约束的是外码（要么为空、要么必须引用已存在的主码值）；用户定义完整性是业务约束（CHECK / NOT NULL / UNIQUE）。

33. A：C2（数据结构）共有 4 条记录：1001→85、1002→NULL、1004→70、1006→88。 - COUNT(*) = 4（数行，NULL 行也算 1 行）； - COUNT(Grade) = 3（数非空成绩值，NULL 跳过）； - AVG(Grade) = (85+70+88) ÷ 3 = 243 ÷ 3 = 81.0（分母是 3 不是 4！）。 这三个数字是数据库第一大考点，必须脱口而出。

34. A：σ 是选择（选行）操作——只横向切割、过滤行，列数永远不变（仍是 S 的 4 列）。S 中 Sdept='计算机系' 的有 1001、1002、1007 共 3 行 → 结果 3 行 4 列。（若是 π_{Sdept}(S) 才会变成 1 列、且去重为 3 行。）

35. A：左外连接保留左表 S 的全部 7 行：其中 6 名学生在 SC 中有匹配行共 14 行；1007 周敏没有选课，左外连接为她补一行（SC 各列为 NULL）→ 总行数 = 14 + 1 = 15。若用内连接则为 14；若写 FROM S, SC（无条件）则是 7 × 14 = 98（笛卡尔积）。

36. B："选了 C1 但没选 C2" = 在 C1 的学号集合中、去掉也在 C2 集合中的学号 = 差运算，SQL 关键字 EXCEPT。A（INTERSECT）是"同时选了 C1 和 C2"；C/D（UNION / UNION ALL）是"选了 C1 或 C2"。本例结果为 1003、1005。

37. C：WHERE AVG(Age) > 20 语法错误——WHERE 在 GROUP BY 之前执行，那时还没有分组、谈不上聚合，聚合函数只能出现在 SELECT、HAVING、ORDER BY 中。A 是 HAVING 的正确用法；B、D 均合法。

38. A：除运算 R ÷ S 的语义是"结果中的每个 t，与 S 中每一个元组的组合都存在于 R 中"——即"包含全部"。π_{Sno,Cno}(SC) ÷ π_{Cno}(C) = 选修了全部课程的学生（本数据下只有 1001 张明）。SQL 中用 NOT EXISTS 双重否定实现同样的语义。

39. C：GRANT（授权）/ REVOKE（回收）属于 DCL（数据控制语言）。判据：CREATE/DROP/ALTER = DDL；SELECT/INSERT/UPDATE/DELETE = DML；GRANT/REVOKE（以及 COMMIT/ROLLBACK）= DCL。软考按三分法作答。

40. A：笛卡尔积 R × S 的元组数 = |R| × |S| = 20 × 5 = 100。注意：写 FROM R, S 而忘了连接条件，得到的就是笛卡尔积——这是性能与正确性的双重灾难。

41. C：Sno→Sdept 且 Sdept→Mname，且 Sdept↛Sno（一个系有多个学生），三个要素齐备 → Mname 传递依赖于 Sno。候选码 Sno 是单属性 → 无部分依赖，故该关系最高满足 2NF（见第 43 题同类题）。

42. A：属性分类：A 只在左部出现（L 类）→ 必在候选码中；B、C、D 都只在右部出现（R 类）→ 一定不是候选码成员。A 的闭包 A⁺ = {A} → B → C → D = U ✅ → 候选码 = A。其他选项都不是最小超码（如 ABCD 可由 A 推出全部，是超码但非候选码）。

43. B：按 5 步流程：① 候选码 = Sno（单属性）；② 属性原子 → 1NF；③ 单属性码不可能有部分依赖 → 满足 2NF 的这一半；④ Sdept→Sloc 且 Sdept↛Sno → Sloc 传递依赖于 Sno → 最高为 2NF；⑤ 不再判断（已被第 4 步拦截）。修复：拆出 (Sdept, Sloc)，Sdept 作外码。

44. B：求候选码：AB⁺ = {A,B} → C = U ✅；AC⁺ = {A,C} → B = U ✅ → 候选码为 AB 与 AC，A、B、C 全是主属性（没有非主属性）→ 第 3、4 步自动通过 → 最高 3NF。但依赖 C→B 的左部 C 不含任何候选码 → 不满足 BCNF。这就是"3NF ⊄ BCNF"的标准反例（3NF 的豁免条款"Y 是主属性"在此生效，BCNF 取消了该豁免）。

45. A：M:N 联系必须新建一个关系，属性 = 两端实体的主码 + 联系本身的全部属性，主码 = 两端主码的组合。B 是 1:N 的做法（且方向要说"1 端并入 N 端"）；C 的主码不能任选；D 无法表达多对多关系（一行只能存一个对方实体）。
