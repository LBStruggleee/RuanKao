1. D｜【计算机基础】Cache 地址映射 Cache 与主存的地址映射由硬件（Cache 存储管理部件）自动完成，对程序员和操作系统都透明。操作系统、存储管理软件、程序员均不参与该映射过程。

2. A｜【计算机基础】CPU 组成 程序计数器 PC 属于控制器。控制器包含 IR（指令寄存器）、ID（指令译码器）、PC、时序与控制电路等；运算器包含 ALU、累加器、PSW 等。

3. B｜【计算机基础】浮点数运算 浮点数加减运算步骤：对阶 → 尾数运算 → 规格化。对阶规则是"小阶向大阶看齐"：小阶的尾数右移，每右移一位阶码加 1，直到两阶码相等。故"阶码小的向阶码大的对齐"正确。

4. C｜【计算机基础】平均 CPI 平均 CPI = Σ（指令比例 × 该类指令 CPI）= 4×35% + 2×45% + 6×20% = 1.4 + 0.9 + 1.2 = 3.5。

5. B｜【计算机基础】MIPS MIPS = 主频 ÷ 平均 CPI = 2.8 GHz ÷ 3.5 = 0.8 GHz = 800 MIPS（1G = 10⁹，1M = 10⁶）。用第 4 题算出的 3.5，不能自己另取一个 CPI。

6. D｜【计算机基础】中断 中断向量是中断服务程序的入口地址（或存放一条跳转到中断服务程序入口的跳转指令）。函数返回地址在栈中，I/O 接口地址是设备地址，主程序入口地址不是中断向量。

7. C｜【网络·信息安全】认证与加密 加密确保保密性，阻止被动攻击（截获、窃听）；认证确保发送者/接收者真实性与报文完整性，阻止主动攻击（冒充、篡改、重放）。认证不能阻止被动攻击，故 C 错。A、B、D 表述均正确。

8. A｜【网络·信息安全】访问控制 访问控制的三项任务：授权（决定哪些主体可访问哪些客体）、确定存取权限（读/写/执行等组合）、实施存取权限。审计是独立于访问控制的安全功能（记录并审查主体对客体的访问），不属于访问控制的任务。

9. C｜【网络】路由协议 BGP（边界网关协议）运行于 TCP 之上，是自治系统之间的外部网关协议（EGP）；RIP、OSPF 均为内部网关协议（IGP）；UDP 是传输层协议，不是路由协议。

10. A｜【网络·信息安全】安全属性 "未经授权不能改变/修改"= 完整性。保密性是"不被非授权者获取（偷看）"；可用性是"合法者能正常访问"；不可抵赖性是"发送方身份可确认、不可抵赖"。

11. C｜【网络】网络命令 netstat 显示网络连接、路由表、接口信息，以及端口与对应应用程序的对应关系。ipconfig 查 IP/MAC/网关配置；traceroute（Windows 下为 tracert）查路径；nslookup 查 DNS 记录。

12. A｜【知识产权】专利申请 专利遵循先申请原则：同样的发明创造，专利权授予先申请的人。甲先于乙一日提出，甲获得该项专利申请权。同一日分别申请的，才需要协商确定申请人。

13. B｜【知识产权】软件著作权归属 小王在甲公司实习期间、为该公司软件项目开发并撰写文档，属于职务作品：针对本职工作中明确规定的开发目标所开发的软件（且使用单位物质技术条件、由单位承担责任），其软件著作权归单位（甲公司）所有，作者仅享有署名权。故 B 正确。

14. B｜【知识产权】著作权保护期 作者的署名权、修改权、保护作品完整权不受时间限制（永久保护）。发表权、复制权、发行权、出租权、信息网络传播权等均有保护期（公民作品：作者终身及死亡后 50 年；法人作品：首次发表后 50 年）。故"修改权"正确。

15. D｜【软件工程】结构化分析 数据流图（DFD）中的元素（数据流、数据存储、加工、外部实体）在数据字典（DD） 中进行定义和说明。数据字典是 DFD 的必要补充。

16. B｜【软件工程】模块设计原则 模块规模要适中：过大则分解不充分，过小则接口增多、调用频繁，反而降低独立性——"越小越好"是错的。提高模块独立性（A）、模块作用域在其控制域之内（C）、降低模块接口复杂性（D）都是良好的启发式原则。

17. D｜【软件工程】AOE 网与关键路径 关键路径是从源点到汇点的最长路径，其长度即最短工期。本图最长路径长度为 22 天。（【存疑：图形复原】官方解析给出的关键路径为 ABFJL 与 ADGIJL，长度均为 22。）

18. B｜【软件工程】关键路径条数 长度等于总工期的路径有 ABFJL 与 ADGIJL 两条，故关键路径共 2 条。算最早时间从左向右取大，算最晚时间从右向左相减取小，"最早 = 最晚"的顶点必在关键路径上。

19. D｜【软件工程】COCOMO II 成本估算 COCOMO II 的三种规模估算选择：应用组装模型用对象点（应用程序点）；早期设计阶段模型用功能点（可换算为代码行）；体系结构阶段模型把工作量表示为源代码的行数。

20. C｜【数据结构】表达式树与后缀式 后缀式（逆波兰式）= 对语法树做后序遍历（左子树 → 右子树 → 根）。该树后序遍历序列为 a b c - d * +，即 abc-d*+。（【存疑：图形复原】语法树结构见试卷文件，根为 +，左子树为 a，右子树为 *，* 的左右子树为 -(b,c) 与 d。）

21. A｜【软件工程·程序设计语言】编译过程 C/C++ 源程序到可执行程序：预处理 → 编译 → 汇编 → 链接。编译型语言常简述为"预处理→编译→链接"，本题四个选项中 A 最合适。

22. C｜【软件工程·程序设计语言】栈与递归 嵌套/递归调用需要"后进先出"地保存返回地址与现场，系统用栈实现；返回时按入栈逆序弹出。队列是 FIFO，不能保证正确返回。

23. C｜【OS】进程资源图与死锁 图①可化简：P1 无残余资源需求，先化简 P1 并释放其占有的 1 个 R1 + 1 个 R2；释放后 P2（需 2 个 R1）、P3（需 1 个 R2）都能依次得到满足，故图①可完全化简。 图②不可化简：R1、R2 均无剩余，P1（需 R2）、P2（需 R1）、P3（需 R2）全部阻塞，没有任何进程能运行释放资源，是死锁状态，不可化简。（【存疑：图形复原】各进程已分配/仍需资源数见试卷文件第 23 题说明。）

24. D｜【OS】页式地址转换 页面大小 4K = 2¹²，故逻辑地址低 12 位为页内偏移，高位为页号。3C20H 的低 12 位 = C20H（偏移），页号 = 3。查页面变换表：页号 3 → 物理块号 6。物理地址 = 块号拼接偏移 = 6C20H。

25. B｜【OS】索引文件 i_addr[0]~i_addr[4] 为直接索引，对应逻辑块 0~4；i_addr[5]、i_addr[6] 为一级间接索引，对应逻辑块从 5 开始。故逻辑块号 4 用直接地址访问，逻辑块号 5 用一级间接地址访问。

26. D｜【OS】索引文件最大长度 1KB 索引块 / 4B 地址项 = 256 个地址项/索引块。 直接：5 × 1KB = 5KB； 一级间接（2 项）：2 × 256 × 1KB = 512KB； 二级间接（1 项）：256 × 256 × 1KB = 65536KB。 总计 = 5 + 512 + 65536 = 66053 KB。

27. D｜【OS】PV 操作与信号量 信号量初值 = 可用资源数 = 5（这也是最大值）。n 个进程申请时，最多有 (n−5) 个进程在等待（n≥5 时必有人等待），此时信号量取到最小值 −(n−5)。故取值范围 −(n−5) 〜 5。

28. B｜【OS】线程 线程私有：线程 ID、寄存器组、堆栈（含栈指针）、错误返回码、信号屏蔽码。线程共享：进程代码段、全局数据（公有数据）、打开的文件描述符、信号处理器、当前目录、用户/组 ID 等。栈指针不能共享，故 B 错。

29. A｜【软件工程】过程模型 喷泉模型是一种以用户需求为动力、以对象为驱动的模型，用于描述面向对象的软件开发过程。

30. D｜【软件工程】喷泉模型特点 喷泉模型的特点是迭代与无间隙：分析、设计、实现等活动之间没有明显的边界，可交叉、可迭代、支持软件重用、以用户需求为动力。"开发活动之间存在明显的界限"恰恰是它不包含的特点（那是瀑布模型的特点）。

31. C｜【软件工程】内聚性 通信内聚：模块内的所有处理元素都使用同一个输入数据、产生同一个输出数据，或在同一个数据结构上操作。逻辑内聚是完成逻辑上相关的一组任务；过程内聚是按特定次序执行；功能内聚是完成单一功能。

32. B｜【软件工程】软件质量属性 吞吐量：在给定时间内系统所能处理的任务/请求的数量（每分钟处理多少个请求）。响应时间是"系统对请求作出响应的时间"；负载是并发压力；容量是存储/处理能力的上限。

33. D｜【软件工程】程序效率 设计更好的算法、采用不同的数据结构、采用不同的程序设计语言都可能改变时间/空间复杂度从而提高效率；仅仅把代码改写得更紧凑（少占几行）不改变算法，不能提高执行效率。

34. A｜【计算机基础】可靠性与可用性 可靠性 = MTTF/(1+MTTF)（给定时间间隔内无失效运行的概率）； 可用性 = MTBF/(1+MTBF)（某时刻能正确运行的概率）； 可维护性 = 1/(1+MTTR)。

A｜【软件工程】白盒测试·语句覆盖 语句覆盖要求所选用例覆盖程序中每一条可执行语句。该流程图只有两条可执行赋值语句：判定 1 为真时执行的 X=X/A 与判定 2 为真时执行的 X=X+1。四用例逐一代入（【存疑：图形复原】按原图结构复原，与四个用例均自洽）： - ①（A=2, B=0, X=4）：两判定均为真 → 执行 X=4/2=2、X=2+1=3，两条语句都执行（路径 abd）； - ②（A=1, B=1, X=1）：两判定均为假，两条语句都不执行（路径 ace）； - ③（A=2, B=1, X=1）：判定 1 假、判定 2 真 → 仅执行 X=1+1=2（路径 acd）； - ④（A=4, B=0, X=2）：判定 1 真、判定 2 假 → 仅执行 X=2/4=0.5（路径 abe）。 四者之中只有 ① 能凭一例同时执行两条语句（例如改用 ② 则一条都执行不到），故单独采用 ① 即可实现语句覆盖。

36. D｜【软件工程】白盒测试·路径覆盖 路径覆盖要求覆盖程序中所有可执行路径。两个判定两两组合共 4 条互不相同的路径：abd（①）、abe（④）、acd（③）、ace（②），四个用例各走一条不同路径，要覆盖全部 4 条必须 ①②③④ 全部选用，缺一不可。路径覆盖蕴含语句覆盖、判定覆盖与条件覆盖，是这几种覆盖中最强的一种。

37. D｜【软件工程·面向对象】this 关键字 this 指向当前对象，this.属性 表示对象成员变量，可与同名的局部变量/形参区分（如构造函数 this.x = x）。private/protected/public 是访问控制修饰符。

38. D｜【软件工程·面向对象】泛化（一般—特殊）关系 "一般—特殊"即泛化（继承）关系：子类是父类的特殊化。"确诊病人"是"发热病人"的一种特殊情形（确诊者属于发热病人的子集），二者是一般—特殊关系。A（确诊/治愈）是同一对象的不同状态；B（确诊/疑似）是并列分类；C（医生/病人）是无关角色。

39. D｜【软件工程·面向对象设计原则】 共同封闭原则（CCP）：包中的所有类对于同一种性质的变化共同封闭——一个变化若影响一个包，则影响该包中所有类，而不影响其他包。共同重用（CRP）：重用包中一个类就要重用包中所有类；开放—封闭（OCP）：对扩展开放、对修改封闭；接口分离（ISP）：使用多个专门接口而非单一总接口。

40. C｜【软件工程·面向对象】多态分类 过载（重载）多态：同一个名字（操作符、函数名）在不同上下文中有不同的类型/含义。参数多态是最纯的多态（泛型/模板）；包含多态是子类型化（同一操作可用于类型及其子类型）；强制多态是编译器隐式类型转换。

44. A｜【软件工程·设计模式】生成器模式 题干直接给出模式定义："将一个复杂对象的构建与它的表示分离，使得同样的构建过程可以创建不同的表示"，即生成器（Builder）模式。抽象工厂强调创建一系列相关产品；原型通过克隆创建对象；工厂方法由子类决定创建哪个对象。

47. D｜【软件工程·设计模式】Builder 适用场景 Builder 适用于：① 创建复杂对象的算法应独立于该对象的组成部分及装配方式；② 构造过程必须允许被构造的对象有不同的表示。B 是工厂方法的适用场景；C 是抽象工厂的适用场景；A 表述接近但官方答案为 D。

48. A｜【软件工程·程序设计语言】传值与传引用 foo(5)：args = 5，x = 6。调用 hoo(args, x)：hoo 的形参 x 按值 = 5（局部副本），形参 a 按引用 绑定到 foo 中的 x。 hoo 内执行：x = x - 1 → 局部 x = 4；a = a * x → a = 6 × 4 = 24，因 a 是引用，foo 中的 x 被改为 24。 返回后 print(x) 输出 24。（注意：用的是减 1 之后的 x，容易误算成 6×5=30。）

49. A｜【软件工程·程序设计语言】上下文无关文法 文法中没有终结符 (、)、/，且 id 是单个字母（不能出现数字 2），故 B（含括号）、D（含 /）、C（含 2）都不能由该文法推导。 a + −b − c 的推导：E ⇒ E−T ⇒ E+T−T ⇒ T+T−T ⇒ a + (−b) − c，其中 −b 由 F → −F → −id 得到。故选 A。

50. B｜【软件工程·程序设计语言】有限自动机 该自动机识别"含有子串 11"的串：读到连续两个 1 即进入终态 s2，之后无论 0、1 都停留在终态。 1100：s0 →1→ s1 →1→ s2（接受）✓； 1001、1010、0101 均不含子串 11，分别停在 s1、s0、s1，未到终态 ✗。（【存疑：图形复原】状态转换图见试卷文件第 50 题说明。）

51. C｜【数据库】E-R 图冲突 同一实体（职工/教师）在不同分 E-R 图中被抽象为实体但属性不同，属于结构冲突。属性冲突指属性的类型/取值范围/单位不一致；命名冲突指同名异义或异名同义；不存在"实体冲突"这一分类。

52. B｜【数据库】E-R 图合并 解决结构冲突的做法是把教师实体并入职工实体：在职工实体中加入职称属性，删除教师实体（过程中还需统一"职工号/教师号、姓名"等属性名）。A 不解决冲突；C 直接删除教师实体丢失了职称属性；D 全部并入会重复记录姓名属性，不如 B 合适。

53. C｜【数据库】函数依赖与候选键 A → BC 可分解为 A → B、A → C；又 B → D，故存在传递依赖 A → D（A → B → D，B 不决定 A）。 候选键：A 的属性闭包 A⁺= {A, B, C, D} = U，且 A 是单属性不可再分，故候选关键字为 A（AC 反而非最小候选键）。

54. B｜【数据库】自然连接 R(A,B,C) 与 S(A,B,D) 在同名属性 A、B 上做自然连接，结果为 4 个属性 (A,B,C,D)，且要求 R 与 S 的 A、B 都相等： R(2,1,4) 与 S(2,1,8) 匹配 → (2,1,4,8)；R(3,4,4) 与 S(3,4,4) 匹配 → (3,4,4,4)。 R 的 (1,2,3)、(4,6,7) 与 S 的 (1,9,1)、(4,8,3) 同名属性不等，不匹配。结果集 = {(2,1,4,8), (3,4,4,4)}。

55. D｜【数据库】外连接 - 自然连接：2 条（匹配的两对）。 - 左外连接：保留 R 全部 4 行，2 行匹配 + 2 行右侧补 NULL → 4 条。 - 右外连接：保留 S 全部 4 行，2 行匹配 + 2 行左侧补 NULL → 4 条。 - 完全外连接：2 条匹配 + 2 条仅左 + 2 条仅右 → 6 条。 故 4, 4, 6。

56. C｜【数据库】分布式数据库 "某场地故障时系统可使用其他场地上的副本而不至于瘫痪"描述的是可用性（同时体现可靠性）。共享性强调所有场地可共享数据；自治性强调各场地能独立处理局部应用；分布性强调数据分布在不同场地。

57. D｜【数据结构】哈夫曼树 权值相同的叶子可能位于不同深度（形态不唯一），路径长度不一定相同，D 错。 其余均正确：哈夫曼树权值越大的叶子离根越近；只有度为 0 和 2 的结点（无度为 1 的结点）；n 个叶子的哈夫曼树共有 2n−1 个结点，必为奇数。

58. A｜【数据结构】存储结构 顺序存储用一组地址连续的存储单元依次存放元素，用元素在存储空间中的相对位置（物理相邻）表示逻辑关系，可随机存取。链表用指针表示逻辑关系；索引存储建索引表；哈希存储用哈希函数。

59. C｜【数据结构】二分查找 二分查找（折半查找）要求：顺序存储（支持随机存取，链表不行）且元素有序排列。

60. D｜【数据结构】图的深度优先遍历 从 v1 深度优先遍历，访问 v2 后，下一个被访问的必须是 v2 的某个出邻接点（按上图复原的边集为 v4）。序列 ①（v1 v2 v3 v4 v5）中 v3 不是 v2 的出邻接点，故 ① 不可能。②③④ 的每一步都沿有向边推进，均可能。（【存疑：图形复原】有向图边集见试卷文件第 60-61 题说明。）

61. B｜【数据结构】图的广度优先遍历 广度优先必须先访问完 v1 的所有出邻接点（v2、v3），才能访问下一层。因此第二、三个顶点只能是 v2、v3（两种顺序均可），之后才是 v4、v5。 ① v1 v2 v3 v4 v5 ✓；③ v1 v3 v2 v4 v5 ✓；②④ 在访问 v4 前未访问完 v1 的邻接点，不可能。

C｜【数据结构】快速排序划分 以最后一个元素 4 为基准（非递减），用"基准元素与另一端待排元素逐一比较并交换"的方法： - 4 与 2 比，2 ≤ 4，不动； - 4 与 8 比，8 > 4，交换 → (2, 4, 7, 1, 3, 5, 6, 8)； - 4 与 6、5 比，不交换； - 4 与 3 比，3 < 4，交换 → (2, 3, 7, 1, 4, 5, 6, 8)； - 4 与 7 比，7 > 4，交换 → (2, 3, 4, 1, 7, 5, 6, 8)； - 4 与 1 比，1 < 4，交换 → (2, 3, 1, 4, 7, 5, 6, 8)。 基准 4 到位（其左侧均 ≤ 4、右侧均 > 4），故选 C。

63. C｜【数据结构】快速排序时间复杂度 一趟划分需要从头到尾扫描并比较整个序列的 n 个元素，计算时间为 O(n)（与划分的深度无关，那才是 O(lgn)~O(n) 的部分）。

64. B｜【数据结构】图的边数 简单无向连通图：最少 n−1 条边（即生成树/树）；最多为无向完全图的边数 n(n−1)/2 条。

65. D｜【数据结构】渐进分析 增长率从低到高：lgn < n^(2/3) < 1000n < n⁴ < 2ⁿ < n!。 关键比较：lgn 慢于任何正幂次；n^(2/3) 是亚线性幂，慢于 n（故 1000n 在 n^(2/3) 之后）；n⁴ 与 2ⁿ 在 n > 16 后 2ⁿ 更大；n! 增长最快。
