1. B｜【计算机基础】CPU 组成与指令执行 CPU 执行指令时会自动修改程序计数器（PC）的内容，使其保存的总是将要执行的下一条指令的地址（顺序执行时 PC 自动 +1，跳转时由跳转指令改写）。选 B。 排除：指令寄存器（IR）存放正在执行的指令；指令译码器（ID）分析指令的操作码；地址寄存器（AR）保存当前 CPU 访问的内存单元/I/O 端口地址。

知识点：PC = 下一条指令地址；IR = 当前指令；MAR = 内存地址；MBR/MDR = 内存数据。

2. A｜【计算机基础】层次化存储体系 BIOS 是一组固化在主板上一个 ROM 芯片里的程序（基本输入输出程序、开机自检、系统自启动），从 CMOS 中读写系统设置。选 A。 排除：CPU 寄存器在芯片内部；主板 RAM 断电即失，无法保存 BIOS；虚拟存储器是硬盘上的交换区。

知识点：BIOS = ROM 固化；CMOS = 可读写、存设置、需电池供电。

3. D｜【计算机基础】补码表示范围 n 位补码（含 1 位符号位）的表示范围为 −2ⁿ⁻¹ ～ +2ⁿ⁻¹ − 1。可以直接表示的最小值为 −2ⁿ⁻¹（其补码是人为定义的，如 n=8 时 1000 0000 表示 −128）。选 D。 排除：2ⁿ 与 −2ⁿ 超出 n 位表示范围；2ⁿ⁻¹（正数侧）补码无法直接表示——补码正数侧最大只能到 2ⁿ⁻¹ − 1（如 8 位最大 +127）。

知识点：补码范围关于 0 不对称，负数侧多一个 −2ⁿ⁻¹。这是补码与原码的关键区别。

4. C｜【计算机基础】系统可靠性（串并联） （【存疑：图形复原】框图结构见 2018H2-mock-questions.md 第 4 题附注：3 部件并联子系统 与 2 部件并联子系统 串联。） 3 个部件并联的可靠度 = 1 − (1 − R)³；2 个部件并联的可靠度 = 1 − (1 − R)²。 两子系统串联，系统可靠度 = [1 − (1 − R)³] × [1 − (1 − R)²]。选 C。 排除：A（(3R+2R)/2 = 2.5R）、B（R/3+R/2）把并联当串联直接相加；D 只做一次"1 −"缺少嵌套结构。

知识点：并联 R = 1 − (1−R₁)(1−R₂)…(1−Rₙ)；串联 R = R₁×R₂×…×Rₙ。

5. C｜【计算机基础】奇偶校验 一位奇校验使校验码中"1"的个数为奇数。传输中若奇数个数据位出错（1↔0 翻转奇数次），"1"的个数奇偶性改变，可以检测出错误；但奇偶校验只能查错、不能纠错。选 C。 排除：A"所有奇数位出错"表述有误（应为"奇数个数据位出错"）；B、D 说能纠正，错。

知识点：偶数个位出错时奇偶性不变 → 检测不出。这是奇偶校验的根本局限。

6. A｜【计算机基础】指令流水线 流水线在某一时刻让多个部件同时处理多条指令，提高的是吞吐率和部件利用率；但对单条指令而言，其执行时间（取指+分析+执行各段时间之和）并不缩短——单条指令仍需完整走完所有段。故"流水线方式可提高单条指令的执行速度"不正确，选 A。 B（同时执行多条指令）、C（提高部件利用率）、D（提高吞吐率）都是流水线的正确叙述。

知识点：流水线提高的是吞吐率（单位时间完成指令数），不是单条指令的执行时间。

7. B｜【网络·信息安全】对称加密 DES 是典型的对称（共享）密钥加密算法，加密与解密使用同一密钥。选 B。 排除：公开密钥加密（非对称）= RSA、ECC、ElGamal、DSA、Diffie-Hellman；数字签名与认证是密码学应用而非 DES 的归类。

知识点：对称 = DES、3DES、AES、IDEA、RC4/RC5；非对称 = RSA、ECC、DSA 等。

8. D｜【网络·信息安全】计算机病毒特征 计算机病毒具有传染性、隐蔽性、潜伏性、触发性、破坏性等特征。自毁性不属于病毒的特征。选 D。

知识点：病毒五特征口诀 = 传（传染）隐（隐蔽）潜（潜伏）触（触发）破（破坏）。

9. B / 10. B｜【网络·信息安全】信息摘要 （9）MD5 是摘要（散列）算法，把任意长度输入压缩为定长输出。选 B。 （10）MD5 输出由 4 个 32 位分组级联而成 = 128 位散列值。选 B。 排除：路由选择算法（A）是网络层的；共享/公开密钥（C、D）是加密算法分类。长度 56 位（A）是 DES 密钥长度；140（C）无对应算法；160 位（D）是 SHA-1 输出长度。

知识点：MD5 = 128 位；SHA-1 = 160 位；SHA-256 = 256 位。摘要算法不可逆、抗碰撞。

11. B｜【网络】Web 邮件 使用 Web 方式收发电子邮件必须设置账号密码登录（Web 邮件通过浏览器以 HTTP/HTTPS 访问，仍需身份认证）。故"可以不设置账号密码登录"错误，选 B。 A（Web 方式由邮件服务器代为 SMTP 收发，客户端无须单独设置 SMTP）、C（可插入多个附件）、D（未发送邮件保存到草稿箱）都是正确描述。

知识点：Web 邮件 = 浏览器 + HTTP/HTTPS + 服务器代劳 SMTP/POP3；客户端邮件 = 本地配置 SMTP/POP3/IMAP。

12. C｜【知识产权】保护期限 商标权可以通过续展（续注）延长拥有期限（每次续展 10 年，次数不限），故可能无限期拥有。选 C。 排除：著作权（A）保护期为作者终生及死后 50 年；专利权（B）发明专利 20 年、实用新型/外观设计较短；集成电路布图设计权（D）保护期 10 年。三者均有固定期限。

知识点：商标可无限续展；著作权、专利权不可续展。

13. B｜【知识产权】软件著作权法律体系 构成我国保护计算机软件著作权的两个基本法律文件是《中华人民共和国著作权法》和《计算机软件保护条例》。选 B。 排除：《软件法》（A、C）不存在；我国没有《中华人民共和国版权法》（D），"版权法"是著作权法的别称而非独立法律。

知识点：《著作权法》+《计算机软件保护条例》= 软件著作权保护"两支柱"；《条例》是《著作权法》的特别法。

14. D｜【知识产权】侵权判断 题干已明确第一个公司是软件著作权人，程序员仅受委托开发。程序员将该软件"略作修改"后提交给第二家公司，未经著作权人许可，构成对原公司的侵权。选 D。 排除：开发者没有"特权"（A）；这不是"正常使用著作权"（B）；也不"不构成侵权"（C）。

知识点：委托开发软件的著作权归属由合同约定、无约定归受托人；但本案著作权已归第一个公司，程序员再处分即侵权。

15. D｜【软件工程】结构化分析（SA） 结构化方法的分析结果由以下几部分组成：一套分层的数据流图、一本数据字典、一组小说明（加工逻辑说明）、补充材料。结构图是结构化设计（SD）阶段的工具，不属于结构化分析的输出。选 D。

知识点：SA 输出 = DFD + DD + 加工逻辑（小说明）+ 补充材料；SD 输出 = 结构图（模块结构图）。

16. A｜【软件工程】数据流图（DFD） DFD 的基本元素 = 数据流、加工、数据存储、外部实体。外部实体是存在于系统之外的对象（人、物、外部系统、组织机构），用来帮助理解系统数据的来源与去向。信用卡管理系统是机票预订系统之外的外部系统，属于外部实体。选 A。

知识点：判别外部实体 = "系统之外、不随系统设计改变"。信用卡接口是系统与外部系统的数据边界。

17. D / 18. C｜【软件工程·项目管理】关键路径与松弛时间 （【存疑：图形复原】活动图结构见 2018H2-mock-questions.md 第 17-18 题附注。） 完成项目的最少时间 = 关键路径（最长路径）长度。经多源核对：关键路径为 A→D→F→H→J，长度 46 天，没有比它更长的路径。故（17）选 D（46）。 活动 FG 的松弛时间 = 总工期 − 包含 FG 的最长路径长度。包含 FG 的最长路径为 A→D→F→G→J = 18 + 3 + 7 = 28 天，故 FG 松弛时间 = 46 − 28 = 18 天，（18）选 C（18）。

知识点：松弛时间 = 最晚开始 − 最早开始 = 总工期 − 含该活动的最长路径。关键路径上活动的松弛时间为 0。 关联已交付卷：2019H1 第 17-18 题（沟通路径/关键路径 55 天）、2019H2 第 17-18 题（关键路径 22 天/总时差 2 天）为同类考点。

19. B｜【软件工程·项目管理】风险概念 风险具有不确定性（可能发生也可能不发生）和损失（发生则产生恶性后果）两个特性。"客户不清楚需求 → 开发小组开发原型帮助其确定需求"是一种应对手段/解决措施，不是风险本身。选 B。 A（子系统推迟交付）、C（未正确理解需求）、D（核心成员离职）都是典型风险。

知识点：风险 = 不确定性 × 损失。区分"风险"与"风险的应对措施"是本题关键。 关联已交付卷：2019H1 第 19 题（"团队可以进行良好沟通"不是风险）为同类"选不是风险的一项"。

20. B｜【程序设计语言】短路求值 表达式 "a or ((c < d) and b)" 最后计算的是 or（或）。或运算只要有一个操作数为真结果即为真，因此当 a 为 true 时，无需计算 or 右侧的 ((c<d) and b) 即可确定整个表达式为真，可短路。选 B。 排除：b、c、d 的取值都在 or 的右侧子表达式中，必须先算出 a 为假才有意义，不能立即短路。

知识点：or 短路看左操作数为真；and 短路看左操作数为假。

21. C｜【程序设计语言】二叉表达式树 （【存疑：图形复原】树结构见 2018H2-mock-questions.md 第 21 题附注。） 由树的结构：根为"−"（最后计算），其左子树为""（其次计算），""的一个操作数为"+"（最先计算，操作数 20、30），另一个为 10，根的另一个操作数为 40。 还原表达式 = 10 * (20 + 30) − 40。选 C。 排除：A（1020+30−40）把""的右操作数当成 20+30−40 整体；B（10(20+30−40)）把"−"并入括号内；D（1020+(30−40)）运算符优先级与树不符。

知识点：表达式树的后序遍历 = 后缀式；树的层次反映运算符优先级，越靠根越后计算。

22. C｜【程序设计语言】数据类型转换 整型与浮点型变量相加时，系统先将整型变量转换为浮点型，再进行浮点运算。选 C。 排除：A（浮点→整型）方向相反且可能丢失精度；B、D 是同类型运算，不需要转换。

知识点：隐式类型转换按"低精度→高精度"自动提升：int → float/double。

23. D｜【操作系统】死锁资源数计算 互斥资源 R 共 8 个，3 个进程竞争，每个进程申请 i 个。可能发生死锁的最小 i： - i ≤ 3 时不会死锁：如 i=3，最坏分配 3、3、2，持有 3 个的进程可完成并释放资源，系统不死锁。 - i=4 时，3 个进程各持有 2 个后剩余 2 个，任一进程再申请 1 个都无法满足且不释放 → 死锁。 故最小 i = 4。选 D。

知识点：n 个进程各需 i 个资源、共 m 个资源，可能死锁的最小 i 满足 n(i−1) + 1 > m，即 i > (m−1)/n + 1。本题 3(i−1)+1 > 8 → i > 10/3 → i ≥ 4。

24. D / 25. B / 26. C｜【操作系统】前趋图与 PV 操作 （【存疑：图形复原】前趋图与程序结构见 2018H2-mock-questions.md 第 24-26 题附注。） 前趋边与信号量一一对应（S1～S6 初值均为 0）：S1:P1→P2，S2:P1→P3，S3:P2→P3，S4:P2→P4，S5:P3→P5，S6:P4→P5。 配对原则：每条前趋边 Pi→Pj 对应"Pi 结束时 V(对应信号量)，Pj 开头 P(对应信号量)"。 - ①（P1 结束，通知后继 P3）：已有 V(S1)，补 V(S2)；②（P2 开头，等前趋 P1）：P(S1) →（24）选 D - ③（P3 开头，等前趋 P2）：已有 P(S2)，补 P(S3)；④（P3 结束，通知后继 P5）：V(S5) →（25）选 B - ⑤（P4 结束，通知后继 P5）：V(S6)；⑥（P5 开头，等前趋 P3、P4）：P(S5)P(S6) →（26）选 C 排除：(24) A/B 的 ② 方向反或 ① 错；(25) C/D 的 ③ 误为 V 操作（P3 有 2 个前趋，必须有 2 个 P）；(26) A/D 的 ⑤ 误为 P 操作（P4 有后继，必须是 V）。

Q33（耦合类型）—— 答案 B（标记耦合）vs A（数据耦合）

题干：采购子系统传递"采购金额、收款方、采购日期等多项信息"给另一模块。

裁决：取 B（标记耦合）。理由： 1. 来源分布：A（希赛系主来源）、B（CSDN 全文版）、D（在线做题系统）均给 B；仅来源 C（王林版）给 A，2:1。 2. 定义裁决（更可靠）：耦合由弱到强 = 非直接 → 数据 → 标记 → 控制 → 外部 → 公共 → 内容。 - 数据耦合：模块间传递的是简单的数据参数（单个变量/标量）。 - 标记耦合：模块间传递的是记录/数据结构（某一数据结构的子结构，一次传递多个相关数据项）。 本题"采购金额、收款方、采购日期"是多项相关数据封装为一个记录传递，符合标记耦合定义，而非把三个独立简单变量分别传递。 3. 应试策略：若考试中遇到同类题，按"传数据结构/记录 = 标记耦合；传简单变量 = 数据耦合"判别，与本题库答案一致。

Q43（UML 供/需接口）—— 答案 C（供接口和需接口）vs D

题干：图中①为小球+实线（lollipop）、②为半圆开口+实线（socket）。

裁决：取 C（供接口和需接口）。理由： 1. 来源分布：A、C 给 C；B 给 D，2:1。 2. UML 常规定义裁决： - 小球 + 实线（lollipop，棒棒糖） = 供接口（provided interface）：构件对外提供、可被其他构件调用的接口。 - 半圆开口 + 实线（socket，插座） = 需接口（required interface）：构件需要调用外部提供的接口。 图中①为供接口、②为需接口 → 供接口和需接口（先"供"后"需"，与图示顺序一致）= C。 3. ⚠️ 教材勘误提醒：《软件设计师教程（第 5 版）》P375 的构件图示例把供/需接口的图标画反了。若以该书插图为记忆来源，容易误选 D。考试以 UML 官方定义（lollipop=供、socket=需）为准。

Q56（关系代数等价）—— 题目与选项本身有瑕疵

题干：π1,4(σ2=5(R⋈S)) 与哪个表达式等价（R(A,B,C,D)、S(C,D,E)）。

结论：四个选项无一严格正确，按"最接近"取 D。完整推导： 1. R⋈S 的属性顺序（去重同名属性 C、D 后）= A, B, C, D, E，故序号：1=A, 2=B, 3=C, 4=D, 5=E。 2. σ2=5 = 选择 B = E（注意 2、5 是列序号，不是数值常量）；π1,4 = 投影 A 和 D。 3. 因此原式 = "取 R.B = S.E 的元组，投影 R.A、R.D"，即 πR.A, R.D(σR.B=S.E(R⋈S))。 4. 选项用的是 R×S（笛卡儿积）。自然连接 = 笛卡儿积 ∧ 同名属性取值相等，故严格等价式应为： πR.A, R.D(σR.B=S.E ∧ R.C=S.C ∧ R.D=S.D(R×S)) 四个选项全都缺少 R.C=S.C ∧ R.D=S.D 这一自然连接必备条件，因此无一严格正确。 5. 相较之下，只有 D 的选择条件（R.B=S.E）与投影（R.A、R.D）与原式完全对应（A 的条件 C=D 与投影 A,D 都错；B 的条件 R.B=S.C 错；C 的条件 R.C=S.D 错），故取 D。 6. 应试策略：真题中此类"改写"题若选项均不严格，选条件与投影与原式逐一对应的那一项。本题答案不影响对"自然连接需补同名属性相等条件"这一核心知识点的掌握。

Q65（贪心算法结论）—— 公开答案 C，但 A 在数学上成立

题干：本题消防栓算法的求解特点（四选一）。

裁决：按公开答案键取 C（对有些实例，可能得不到最优解），但标注争议。理由： 1. 题库解析的口径："肯定可以求得问题的一个最优解"是动态规划的特点（不是所有贪心都成立），"可以求得问题的所有最优解"不是任何算法的普遍性质，故排除 A、B；在 C 与 D 之间，C 的说法"更恰当"。 2. 数学层面的反证：本题策略（"从左端第一栋未被覆盖的房子起，在其右侧 m 米处放置"）等价于区间选点/区间覆盖问题的经典贪心，已证明该策略总能取得最优解——即"覆盖所有房子的最少消防栓数"正是该贪心的结果。因此 A（肯定可以求得问题的一个最优解）在数学上正确。 3. 分歧根源：命题人按"贪心法的一般性质 = 不保证全局最优"出题，而本题恰好是该一般结论的例外（可证明最优的贪心）。题目把"该算法"的结论一般化，导致了争议。 4. 应试策略（最重要）：考试时按公开答案 C 作答——上午题为客观题，以命题人/官方答案为准；但心里要清楚：贪心是否最优取决于具体问题，"区间选点/区间覆盖"这类问题是贪心可证最优的典型（与 0-1 背包贪心不最优形成对照，见 2019H2 第 63 题、2022H1 第 40 题）。
