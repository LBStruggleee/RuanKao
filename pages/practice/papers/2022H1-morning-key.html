二、逐题解析（含知识点归属）

格式：答案 | 【科目】知识点 | 解析。第 35–75 题题号未经原卷印证，解析按知识点本身给出。

1. B｜【计算机基础】冯·诺依曼体系结构 冯·诺依曼机的核心是存储程序：程序指令与数据均以二进制存于主存（A 对），程序功能由 CPU 执行指令实现（C 对），执行由指令自动控制（D 对）。"数据则存储在高速缓存中"错误——数据同样存于主存，高速缓存只是主存与 CPU 之间的高速缓冲层次，故选 B。

2. A｜【计算机基础】SRAM 与 DRAM SRAM 依靠触发器存数，集成度低、功耗（静态功耗）大、不需动态刷新、速度快，用作 Cache；DRAM 依靠电容存数，集成度高、需定期刷新、功耗（ refresh 电流）也较大，用作主存。逐项比对：A 中"集成率低【集成度低】、功率大、不需要动态刷新"同时满足 SRAM 的三个特征，正确；B、C、D 都把"需要/不需要刷新"说反了（SRAM 不需刷新、DRAM 需刷新）。

3. C｜【计算机基础】多级中断与现场保存 多级中断的关键是中断嵌套：高优先级中断会打断低优先级中断，被中断的现场（PC、PSW、通用寄存器等）必须先保存、后恢复，且符合"后进先出"。堆栈天然提供 LIFO 的压栈/出栈操作，是保存与恢复程序现场最有效的数据结构；通用寄存器、累加器数量有限且无 LIFO 语义；程序计数器只保存一条返回地址，无法保存全部现场。

4. B｜【计算机基础】RISC 与 CISC RISC 的特征是指令简单、种类与寻址方式少、长度固定、大多指令单周期完成、硬布线（组合逻辑）控制、大量通用寄存器、适合流水线；CISC 指令复杂、格式可变、普遍采用微程序（微码）控制。故 B 把两者的控制器类型说反了（应为"RISC 普遍采用硬布线控制器，CISC 普遍采用微程序控制器"），选 B。A、C、D 均为正确叙述。

5. A｜【计算机基础】系统可靠性（串联+并联） （【存疑：图形复原】框图见原卷 PDF 第 3 页，结构为两端各一个可靠度 R 的部件串联、中间为两个 R 部件并联。） 系统 = R（串联）× [1−(1−R)²]（并联）× R（串联），代入 R=0.95： 并联部分 1−(1−0.95)² = 1−0.0025 = 0.9975；系统 = 0.95 × 0.9975 × 0.95 = 0.90019375 ≈ 0.90，选 A。 （B 缺了并联的"1−"取反；C 用 2×(1−R) 无可靠性依据；D 把全部 4 个部件当串联 R⁴ 又乘 (1−R)，均错。）

6. D｜【计算机基础】同步传输与异步传输 计算机内部各部件间（CPU↔主存、CPU↔总线、CPU↔I/O 接口）普遍采用同步传输（统一时钟、成块传送）。I/O 接口与打印设备之间速度差异大、无统一时钟，采用异步传输（应答/握手方式逐字节传送），选 D。

7. B｜【网络·信息安全】安全文件传输协议 SFTP（SSH File Transfer Protocol）基于 SSH 加密通道（端口 22）传输文件，提供加密与身份认证。FTP（20/21）明文传输；TFTP（69）基于 UDP、无安全机制；ICMP 是网络控制报文协议（ping），不传文件。

8. D｜【网络·信息安全】恶意代码与攻击手段 计算机病毒是能自我复制、感染文件的恶意程序：永恒之蓝（利用 MS17-010 的蠕虫型）、蠕虫、特洛伊木马均为恶意代码。DDoS（分布式拒绝服务）是一种网络攻击行为（发起海量请求使目标瘫痪），不是能感染、复制的程序，故"不属于计算机病毒"选 D。

9. C｜【网络·信息安全】杀毒软件的能力边界 杀毒软件通过特征库/行为匹配检测并清除病毒、蠕虫、木马等恶意代码（A、B 对），服务器同样需要（D 对）。但网站信息被篡改是攻击者入侵 Web 服务器后修改页面，属于入侵/访问控制失效范畴，杀毒软件不能有效防止（需 WAF、加固、审计等），故 C 的描述错误，选 C。

10. A｜【网络·信息安全】防火墙访问控制 在出口防火墙上配置 ACL（访问控制列表），按源/目的地址、端口、协议允许或拒绝报文通过，可阻止外部未授权用户访问内网。SNAT 用于内网地址转换上网（解决地址短缺）；入侵检测只"发现并告警"，默认不阻断；防病毒过滤的是恶意代码而非访问权限。

11. C｜【网络·信息安全】SQL 注入防御 SQL 注入的根源是用户输入被拼接进 SQL 语句。有效手段：关键字过滤/参数化查询（A）、WAF（B，识别注入特征并拦截）、定期扫描修复漏洞（D，减少可被注入的缺陷）。入侵检测系统（IDS）以监听、告警为主，默认不在线阻断业务流量，难以有效防御应用层注入，选 C。（若为 IPS 则有阻断能力，但选项明确是 IDS。）

12. B｜【知识产权】专利申请权归属 专利法对相同内容的发明创造实行先申请原则：两个以上申请人就同样的发明创造申请专利的，专利权授予最先申请的人（甲、乙、丙分别申请，则先申请者获得）。"先发明者"是美国的先发明制；"先试用者"是商标法的规则；均不适用于专利。

13. C｜【知识产权】保护期可延长 商标权保护期 10 年，但可以无限次续展（每次续展 10 年），即"保护期可以延长"。著作权（作者终生+50 年，不可延长）、专利权（发明 20 年/实用新型 10 年/外观 15 年，不可延长）、商业秘密权（无固定期限，靠保密维持）均不能延长保护期。

14. B｜【软件工程】软件测试方法 输入取边界值 3500 及其两侧相邻值 3499（边界内）、3501（边界外），正是边界值分析的典型用例选取方式（等价类边界 ±1）。判定覆盖/路径覆盖针对逻辑分支；因果图针对输入条件组合关系，均与"取临界值两侧"的描述不符。

15. C｜【软件工程】软件维护 软件维护是软件生命周期中持续时间最长、工作量与成本往往超过开发的阶段（行业经验：维护成本可达总成本的 60%–80%），且维护的是整个软件系统（代码+文档+数据），不只是代码。故 A、B、D 均错，选 C。

16. D｜【软件工程·面向对象】静态绑定与动态绑定 动态绑定（Dynamic Binding）：在运行时才把函数/过程调用与响应调用所需执行的代码（方法体）相结合，是多态的实现基础。静态绑定在编译期完成绑定（重载方法多用静态绑定）。强/弱类型是类型检查的严格程度，与"调用与代码结合"无关。

17. B｜【软件工程·面向对象设计】包的依赖原则 包的依赖关系图中不允许出现环（循环依赖会导致包间强耦合、无法独立复用与测试），这是无环依赖原则（ADP，Acyclic Dependencies Principle）。单一责任（SRP）针对类的设计；依赖倒置（DIP）强调依赖抽象；里氏替换（LSP）针对父子类型替换。

18. C｜【软件工程·面向对象分析】OOA 的活动 面向对象分析（OOA）一般按认定对象 → 组织对象 → 描述对象间相互作用 → 确定对象的操作的顺序进行，第一项活动是"认定对象"（从问题域中识别出对象/类），选 C。

19. D｜【软件工程·面向对象】OOA/OOD/OOP 的分工 面向对象程序设计语言（如 Java、C++、Python）服务于面向对象实现（OOP）阶段——用语言把设计映射为可执行代码。用例设计、分析、需求分析分别对应更早的设计/分析活动，不是"程序设计语言为之服务"的目标。

20. B｜【程序设计语言】Python 包管理 pip 安装第三方模块的标准命令是 pip install numpy（pip + 子命令 install + 包名）。pip numpy 缺 install 子命令；install numpy 缺 pip；import num（原文如此，应为 import numpy）是导入已安装模块的语句而非安装命令。

21. A｜【程序设计语言】Python 序列运算 在 Python 中，列表 × 整数 n 表示把列表元素重复 n 次（序列的重复运算），故 X = [1, 2]，X * 2 = [1, 2, 1, 2]，选 A。[2, 4] 是把乘法当作逐元素数值运算（需 NumPy 数组才支持）；[1, 1, 2, 2] 是误按"每个元素重复"理解。

22. A｜【程序设计语言】Python 数据类型 tuple（元组）：不可变（创建后不能修改元素）、有序（支持索引/切片）、元素可重复，三项全中。dict（字典）是可变的键值映射（有序但可变）；list（列表）可变；set（集合）无序且元素唯一。

23. B｜【数据库】视图与数据字典 视图是虚表，数据库中并不存放视图的数据（不存查询结果 C），只存放视图的定义（创建视图的 SELECT 语句）于数据字典/系统目录中。查询时由 DBMS 依据视图定义重写为对基本表的查询。"所引用的基本表"是定义中的组成部分，不是数据字典保存的对象整体。

24. C｜【数据库】自然连接的属性列数 （本人独立重算）R(A,B,C,D)、S(A,D,E,F)，公共属性为 A、D。自然连接 R⋈S 在公共属性上做等值连接并合并同名属性，结果属性 = {A, B, C, D} ∪ {A, D, E, F} = {A, B, C, D, E, F}，共 6 列，选 C。

⚠️ 分歧题：51CTO 给 4（误把结果当成"公共属性 2 列 + 非公共 2 列"）。博客园第三来源与 CSDN 均为 C=6，且按定义重算确定 6 列，取 C。

B｜【数据库】自然连接转笛卡尔积+选择+投影 （本人独立重算）设 R×S 的列序为 R.A=1, R.B=2, R.C=3, R.D=4, S.A=5, S.D=6, S.E=7, S.F=8。自然连接 = 在公共属性上等值并去重列： R⋈S ≡ π(1,2,3,4,7,8)(σ(1=5 ∧ 4=6)(R×S))（保留 R 的 4 列 + S 的 E、F 两列）。 再叠加选择 R.B > S.F，即比较第 2 列与第 8 列： σ(R.B>S.F)(R⋈S) ≡ π(1,2,3,4,7,8)(σ(1=5 ∧ 2>8 ∧ 4=6)(R×S))，选 B。 （A 缺连接条件与投影；C、D 把数值比较 2>8 误写成字符串比较 '2'>'8'——字符串逐位比较 '2'>'8' 为假，与题意不符。）

26. C｜【数据结构】散列表（哈希表） 线性探测法（开放地址法）在冲突时顺序向后探查，会造成大量关键字在一段连续地址上"堆积"——即聚集（clustering/主聚集）问题，C 正确。A 错：查找时比较的不只是关键字本身与其同义词，还可能包括因冲突被顺延到同一线性探查序列上的非同义词（这正是 2021 年卷 2 第 60 题构造反例证明的结论）；B 错：装填因子 α<1 只减少冲突、不能避免冲突；D 错：链地址法平均查找长度取决于 α，并非恒为 1。

27. B｜【数据结构】折半查找判定树 长度 n 的有序顺序表做折半查找，其判定树由每次比较中点生成：任一结点的左右子树高度差不超过 1，整棵树形态与平衡二叉树（AVL）一致（仅可能最下层右侧不满，是理想平衡的特例），选 B。它不是哈夫曼树（不按权值构造）、不是完全二叉树（n 不为 2^k−1 时最下层右侧空缺）、不是最小生成树（不是图的结构）。

28. C｜【数据结构】树的度与叶子结点数 （本人独立重算）设 nᵢ 为度为 i 的结点数。树的分支（边）数 = 各结点度数之和 = 4n₄+3n₃+2n₂+n₁；又分支数 = 总结点数 − 1 = (n₄+n₃+n₂+n₁+n₀) − 1。两者相等： 4n₄+3n₃+2n₂+n₁ = n₄+n₃+n₂+n₁+n₀ − 1 → n₀ = 3n₄ + 2n₃ + n₂ + 1。 代入 n₄=7, n₃=5, n₂=8：n₀ = 21 + 10 + 8 + 1 = 40，选 C。

29. A｜【数据结构】排序的稳定性 冒泡排序是稳定排序（相等元素不发生跨位交换）。快速排序（交换基准两侧元素）、堆排序（堆顶下沉会打乱相等元素）、简单选择排序（跨越式交换）均不稳定。（口诀："快选堆"不稳定。）

30. D｜【数据结构】图的邻接表 无向图的每条边 (u,v) 在邻接表中产生两个边表结点（u 的表与 v 的表各一个），故边表结点总数必为偶数。现总数为奇数，说明图必为有向图（每条有向边只产生一个表结点，总数才可能奇/偶不定），选 D。顶点数的奇偶与边表结点数的奇偶无确定关系，故 A、B 不能判定。

31. B｜【网络】OSI 参考模型 数据链路层在物理线路上提供可靠的数据传输（成帧、差错控制、流量控制），把不可靠的物理链路对网络层呈现为一条无差错的线路。物理层只透明传输比特流（不保证可靠）；网络层提供源到目的的寻址与路由；传输层提供端到端（主机到主机）的可靠或不可靠服务。

C｜【程序设计语言】文法推导（【存疑：题目来源为网络回忆版】） 文法 S → A0 | B1，A → S1 | 1，B → S0 | 0。观察：从 S 出走 A 分支末尾加 0、走 B 分支末尾加 1；而 A、B 又分别以 S 开头（A→S1、B→S0）形成递归，每层递归在串尾补一个与"进入分支"相反的符号，使 0 与 1 配对出现。实际推导：S ⇒ A0 ⇒ 10（0、1 各一）；S ⇒ B1 ⇒ 01；S ⇒ A0 ⇒ S10 ⇒ B110 ⇒ 0110…；S ⇒ A0 ⇒ S10 ⇒ A110 ⇒ 1110…（个数不等者也可推出，但并非所有不等者都可推出）。选项中最贴切的是"某些 0 和 1 个数相等的字符串"（如 10、01、1010、0101 等），选 C。A、B 过窄（只能生成全部 0 串或全部 1 串，与"同时含 0、1"矛盾）；D 过宽（"所有"个数不同的串，如 "000" 无法推出）。

A｜【数据结构与算法】0/1 背包与部分背包（【存疑：题目来源为网络回忆版】） （本人独立重算，物品表见试卷文件） - 部分背包（可分割，用贪心）：按单位价值优先，物品 1（w5,v50）→ 物品 2（w25,v200）→ 物品 3（w30,v180），累计重量 60、价值 430；余 40，切物品 4 的 40/45：225×(40/45)=200。总价值 430+200=630。 - 0/1 背包（不可分割，须枚举最优组合）：组合 {2,3,4} 重量 25+30+45=100（恰满），价值 200+180+225=605；其余组合：{1,2,3,5} 重 110 超限、{1,4,5}=475、{1,2,3}+剩余装不下 4/5=430… 均不超 605。故 0/1 最优 = 605。 答案 605 和 630，选 A。

71. B｜【英语】上下文：系统生命周期（⚠️ 本段为 2020 下半年英语真题，被整理版误收） "无论系统或应用设计、构造与测试得多好，错误都在所难免。一旦系统被实现（implemented），它就进入运行与支持阶段。" designed/analyzed/investigated 都处于实现之前的阶段，与"进入运行与支持"衔接不上。

72. A｜【英语】上下文：支持的前提 "在信息系统被支持（supported）之前，它必须先投入运行。" 与后文反复出现的 "systems support" 直接呼应。tested（测试）、constructed（建设）发生在运行之前。

73. C｜【英语】上下文：系统运行 系统运行是信息系统业务流程与应用程序的日常、周、月、年复一年的执行（execution）。construction（建设）、implementation（实现）属于更早阶段；maintenance（维护）属于"支持"而非"运行"。

74. D｜【英语】固定搭配 "与系统分析、设计、实现不同，系统支持不能被合理地分解（decomposed）为支持项目必须执行的实际阶段。" decompose into = 分解为，是标准搭配。broke（打破，且时态形式错）、formed（形成）、composed（组成，表"由…组成"用 be composed of）都不合语境。

75. A｜【英语】固定搭配 "每项活动都是由已实现系统中遇到的特定问题、事件或机会所触发（triggered）的支持项目。" be triggered by = 由……触发，是标准被动搭配。leaded 形式错误（lead 的过去分词为 led）；caused（引起）、produced（产生）虽语义相近，但不及 triggered 贴合"问题/事件/机会"引发支持项目的语境。
