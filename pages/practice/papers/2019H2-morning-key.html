二、逐题解析（含知识点归属）

格式：答案 | 【科目】知识点 | 解析

1. B｜【计算机基础】Cache 高速缓存 在 CPU 内外设置多级高速缓存（L1/L2/L3），主要目的是解决 CPU 与主存之间速度不匹配的问题，提高 CPU 访问主存数据或指令的效率。选 B。 排除：Cache 容量远小于主存，不扩大主存容量（A 错）；也不扩大"存储系统的存量"（C 错，存量是外存/硬盘的职责）；Cache 与外存无关（D 错，CPU 不会直接访问外存）。

知识点：存储层次结构（寄存器→Cache→主存→外存），越靠近 CPU 速度越快、容量越小。

2. A｜【计算机基础】系统可靠性（串并联） 部件 2、3 并联构成冗余子系统：可靠度 = 1-(1-0.8)(1-0.8) = 1-0.2×0.2 = 0.96； 与部件 1（0.90）串联：0.90 × 0.96 = 0.864； 设部件 4 可靠度为 R₄，系统可靠度 = 0.864 × R₄ ≥ 0.85，得 R₄ ≥ 0.85 / 0.864 = 0.85 / [0.9×(1-(1-0.8)²)] ≈ 0.984。选 A。 排除：B 式 = 0.85/(0.9×0.04) ≈ 23.6（>1 不合理）；C 式 = 0.85/(0.9×1.6) ≈ 0.59（并联当串联相加，错）；D 式 = 0.85/(0.9×2×0.2) ≈ 2.36（>1 不合理）。

知识点：并联 R = 1-(1-R₁)(1-R₂)；串联 R = R₁×R₂×…×Rₙ。

3. C｜【计算机基础】中断处理 中断处理时保存现场的目的是：中断服务程序执行完后，能正确返回到被中断的程序继续执行（恢复断点与寄存器状态）。选 C。 排除：A/B/D 都可能是保存现场的"副作用"，但不是根本目的。

知识点：中断过程 = 保存现场→执行中断服务程序→恢复现场→返回断点。

4. D｜【计算机基础】主存编址计算 存储单元数 = CFFFFH - A0000H + 1 = 30000H = 3×16⁴ = 196608 个单元；按字节编址 → 196608 B = 196608/1024 = 192 KB。选 D。

知识点：编址范围"从 A 到 B"的单元数 = B - A + 1；1 KB = 1024 B。注意"从…到…"要 +1。

5. B｜【计算机基础】存储芯片扩展 芯片数 = 总容量 / 单片容量 = 192 KB / (64 K × 8 bit) = 192K×8bit / 64K×8bit = 3 片（字扩展，位数已满足 8 bit，无需位扩展）。选 B。

知识点：字扩展（增加容量）片数 = 总单元数/单片单元数；位扩展（增加字长）片数 = 字长/单片位宽。

6. B｜【计算机基础】流水线执行时间 流水线建立时间 = t取指+t分析+t执行 = 5+2+3 = 10 Δt；流水线周期 = max(5, 2, 3) = 5 Δt； 执行 500 条指令总时间 = 建立时间 + (n-1)×周期 = 10 + (500-1)×5 = 10 + 2495 = 2505 Δt。选 B。 排除：A 2500 = 500×5（漏了建立时间的 5 Δt 差值）；C 2510、D 2515（周期取错或建立时间取错）。

知识点：流水线执行时间 = 第一条指令的完整时间 + (n-1) × 最长段（瓶颈段）时间。

7. C｜【网络·信息安全】安全协议 MIME（多用途互联网邮件扩展）只规定邮件内容格式（非 ASCII 文本、附件、多部分消息体），与安全无关，选 C。 有关项：SSL 为通信提供加密（A）；HTTPS = HTTP+SSL（B）；PGP 是基于公钥的邮件加密与签名软件（D）。安全邮件协议是 S/MIME。

知识点：MIME 管格式，S/MIME、PGP、SSL/HTTPS 管安全。

8. D｜【网络·信息安全】对称/非对称加密算法 DES 是典型的对称（共享）密钥加密算法，不属于公开密钥加密算法，选 D。 ECC（椭圆曲线密码）、DSA（数字签名算法，基于公钥体制）、RSA 都是公开密钥（非对称）加密算法。

知识点：非对称 = RSA、ECC、ElGamal、DSA、Diffie-Hellman；对称 = DES、3DES、AES、IDEA、RC4/RC5。

9. B｜【网络·信息安全】Kerberos 与重放攻击 Kerberos 系统通过在报文中加入时间戳防止重放攻击（服务器据时间戳判断是否为重放包）。选 B。

知识点：重放攻击的对策 = 时间戳、随机数（nonce）、序列号。Kerberos 用时间戳。

10. A / 11. B｜【网络·信息安全】数字证书与 CA 数字证书由 CA 签发，内含网站的公钥并附有 CA 的签名。用户获取证书后，用 CA 的公钥（10，A）验证 CA 的签名（11，B）的真伪，确认证书有效，进而确认网站合法性。 排除：网站的公钥/私钥不能用来验证证书本身（C/D 用于 10、11 均错）；CA 的私钥从不公开。

知识点：CA 公钥验证 CA 签名 → 信任链。HTTPS 握手中服务器发证书，客户端用 CA 公钥验签。

12. B｜【知识产权】委托开发软件的归属 委托开发：若委托人与受托人（开发者）对归属有特别约定，从其约定；无约定的，著作权由受托人（李某）享有。选 B。 排除：A、D 太绝对，忽略了"有约定从约定"；C 混淆了"委托开发"与"职务作品"（是否单位分派）两种不同情形。

知识点：《计算机软件保护条例》第 11 条：委托开发的软件，其著作权的归属与行使由委托人与受托人签订书面合同约定；无书面合同或者合同未作明确约定的，其著作权由受托人享有。

13. C｜【知识产权】职务作品软件 李工是公司软件设计师，软件是任职期间针对本职工作中明确指定的开发目标所开发（且按公司规定申请著作权），属于职务作品，著作权由公司享有。选 C。 排除：A/B/D。署名权由开发者（李工）享有，但著作权的其他权利（发表权、复制权、许可权等财产权利）归单位。

知识点：职务软件三情形 = 本职指定目标 / 本职活动预见或自然结果 / 主要用单位物质技术条件且单位承担责任。满足任一条，著作权归单位（署名权除外）。

14. D｜【软件工程】数据流图（DFD） DFD 四要素：外部实体、数据流、加工（处理）、数据存储。外部实体是存在于系统之外的人员、组织或其他系统。考生、考试中心、阅卷老师都是系统外的人/机构（A/B/C 均为外部实体）；试题是系统加工后产生的数据流，不是外部实体。选 D。

知识点：判别外部实体 = "系统之外、不随系统设计改变"。数据流、加工、数据存储都在系统之内。

15. A｜【软件工程】模块设计原则 模块的规模应适中，不是越小越好——模块过小会导致模块数量爆炸、模块间接口与调用开销大于收益。选 A（叙述不正确）。 B（信息隐藏）、C（高内聚低耦合）、D（过程抽象与数据抽象）都是正确的软件设计原则。

知识点：模块规模"适中"、模块"独立性"（内聚高、耦合低）、信息隐藏、抽象。

16. C｜【软件工程】内聚类型 一个模块内各处理元素密切相关于同一功能、必须顺序执行，且前一元素的输出就是下一元素的输入——这是顺序内聚。选 C。 排除：过程内聚（A）是"多个任务按指定过程执行"，元素间可以无数据传递；时间内聚（B）是"同一时间执行"（如系统初始化）；逻辑内聚（D）是"逻辑上相似的功能通过参数选择"。

知识点：内聚由弱到强 = 偶然→逻辑→时间→过程→通信→顺序→功能。

17. B｜【软件工程·项目管理】关键路径（AOE 网） （【存疑：图形复原】活动图见 2019H2-morning-questions.md 第 17-18 题附注，权值请对照解析书第 155 页原图。） 按原图权值计算，关键路径有两条：ABFJL 和 ADGIJL，总工期 22 天。里程碑 C 不在关键路径上（C 只有 A→C→E→H→J→L 一条路径，长度短于 22），选 B。 B、D、J 都在关键路径上（B 在 ABFJL 上，D、J 在 ADGIJL 上，J 也在 ABFJL 上）。

知识点：关键路径 = 从源点到汇点最长路径；关键路径上的所有事件（里程碑）总时差为 0。一个 AOE 网可有多条等长的关键路径。

18. C｜【软件工程·项目管理】总时差（松弛时间） 活动 BE 的最早开始时间 ES = 第 4 天（其前驱活动 A→B 完成于第 4 天），最晚开始时间 LS = 第 6 天，总时差 = LS - ES = 6 - 4 = 2 天。选 C。 即：BE 最多可以晚 2 天开始而不影响总工期（22 天）。

知识点：活动总时差 = LS - ES = LF - EF，关键活动总时差 = 0。

19. C｜【软件工程·项目管理】风险概念 风险是可能发生的事件（A 对）；风险发生时其本质、范围和时间影响后果（B 对）；风险可以预测、可以控制（D 对），但"可以预测"并不意味着"可以避免其发生"——有些风险（如需求变更、人员流动）可预测但无法完全避免，只能缓解。选 C（叙述不正确）。

知识点：风险 = 不确定性 × 损失。风险管理 = 识别→估计→评价→控制，不是消除。

20. A｜【程序设计语言】编译过程 语法分析阶段的输入是记号流（token stream）——即词法分析的输出。选 A。 排除：字符流（B）是词法分析的输入；源程序（C）是编译器整体输入；分析树（D）是语法分析的输出之一。

知识点：词法分析（字符流→记号流）→ 语法分析（记号流→分析树/语法树）→ 语义分析 → 中间代码 → 优化 → 目标代码。

21. B｜【程序设计语言】语法错误检测 括号不配对是典型的语法错误（括号是语法范畴的配对结构），在语法分析阶段检查出来。选 B。 排除：词法分析（A）只识别单词（标识符、常数、界符）；语义分析（C）查类型匹配等静态语义；目标代码生成（D）在最后。

知识点：词法错误（非法字符）、语法错误（括号不配对、缺少分号）、语义错误（类型不匹配）。

22. D｜【程序设计语言】后缀式（逆波兰式） 表达式 (a-b)(c+d)：先算 a-b → ab-，再算 c+d → cd+，最后相乘 → ab-cd+**。选 D。 排除：A abcd-+* = a×(b-(c+d))；B ab-c+d* = ((a-b)+c)×d；C abc-d* = a×(b-c)。

知识点：后缀式构造 = 对表达式语法树做后序遍历；运算符跟在两个操作数之后。

23. C｜【操作系统】前趋图与 PV 操作（三空连环①②） 前趋边：P1→P2、P2→P3、P2→P4、P3→P4、P3→P5、P4→P5。信号量 S1～S6 初值均为 0。 每条边 Pi→Pj 对应"Pi 结束时 V 一个信号量，Pj 开头 P 该信号量"。 P1→P2：P2 开头已有 P(S1)，故 ① = V(S1)（P1 执行完通知 P2）。 P2→P3（P3 开头有 P(S2)）与 P2→P4：故 ② = V(S2)V(S3)（P2 执行完分别通知 P3、P4）。 所以（23）= V(S1) 和 V(S2)V(S3) = 选项 C。 排除：A 把 ② 写成两个 P 操作（方向反了）；B/D 的 ① 写成 P(S1)（P1 无前趋，不需要 P）。

知识点：前趋图中"V 操作在箭头流出端（前趋进程结束后），P 操作在箭头流入端（后继进程开始前）"。

24. A｜【操作系统】前趋图与 PV 操作（空③④） P3→P4（P4 开头已有 P(S4)）与 P3→P5：故 ③ = V(S4)V(S5)（P3 执行完通知 P4、P5）。 P4 需等 P2 和 P3 两个前趋：程序已有一个 P(S4)（等 P3），还缺等 P2 的操作，故 ④ = P(S3)。 所以（24）= V(S4)V(S5) 和 P(S3) = 选项 A。 排除：B 的 ④ 是 V 操作（P4 有 2 个前趋，已给 1 个 P，必须再补 1 个 P）；C/D 的 ③ 是两个 P 操作（P3 只有 1 个前趋 P(S2)，③ 应是 2 个 V）。

知识点：某进程有 n 个前趋，其程序中必须有 n 个 P 操作；有 m 个后继，必须有 m 个 V 操作。P4 有 2 前趋 1 后继 → 2 个 P（已给 1 个 + ④ 补 1 个）+ 1 个 V。

25. D｜【操作系统】前趋图与 PV 操作（空⑤⑥） P4→P5：故 ⑤ = V(S6)（P4 执行完通知 P5）。 P5 有 2 个前趋（P3、P4），程序开头必须 P 两次：⑥ = P(S5)P(S6)（分别等 P3 的 S5、P4 的 S6）。 所以（25）= V(S6) 和 P(S5)P(S6) = 选项 D。 排除：A/C 的 ⑤ 是 P 操作（P4 只有 1 个后继，⑤ 应是 V）；B 的 ⑥ 是两个 V 操作（P5 无后继，不需要 V）。

知识点：信号量配对原则——每个 V 必须有对应的 P，且初值均为 0 时，P 先于 V 不成立则阻塞。

26. C｜【操作系统】I/O 软件层次 I/O 软件采用分层思想，隐藏了 I/O 操作的实现细节，向用户提供逻辑接口（而非物理接口），方便用户使用 I/O 设备。选 C。 排除：A/D 说"开放了细节"（恰恰相反，细节被隐藏）；B 说"提供物理接口"（提供的是逻辑接口，物理细节对用户透明）。

知识点：I/O 软件目标 = 方便性（逻辑接口）、设备独立性、效率、错误处理。

知识点：树的关键恒等式 = 分支数 = n - 1 = Σ(各度数 × 该度数结点数)。

60. A｜【数据结构】图的邻接矩阵 邻接矩阵是 n 阶方阵（n = 顶点数）。题图有 5 个顶点 → 5×5 矩阵。选 A。 排除：7（B/C/D）是干扰项，与顶点数无关。

知识点：邻接矩阵只与顶点数有关，与边数无关；有向图矩阵不一定对称。

61. B｜【数据结构】邻接链表 邻接链表中顶点 v 的表结点个数 = v 的出度（邻接顶点数）。 已知顶点 1 的表结点 = 2（出弧 <1,2>、<1,3>），顶点 5 的表结点 = 0（无出弧）。按原图结构，顶点 2 和顶点 3 的表结点个数都为 2。选 B。

知识点：有向图邻接表 = 出度表；逆邻接表 = 入度表。无向图邻接表表结点数之和 = 2×边数。

62. C｜【数据结构】排序算法时间复杂度 最坏情况下：归并排序 = O(n log n)；插入排序、冒泡排序、快速排序最坏均为 O(n²)（快排在已序/逆序输入下退化为 O(n²)）。选 C。

知识点：快排平均 O(n log n) 但最坏 O(n²)；归并、堆排在任何情况下都是 O(n log n)。这是"最坏最低"与"平均最快"的区别。

63. D｜【算法设计】贪心算法适用性 部分（分数）背包问题具有贪心选择性质和最优子结构，贪心算法保证求得最优解（按单位价值降序，能装就装，装不下就按比例切分）。选 D。 排除：0-1 背包（A，物品不可切分，贪心不保证最优，需动态规划）；矩阵链乘（B，需区间 DP）；最长公共子序列（C，需 DP）。

知识点：贪心成立的两前提 = 最优子结构 + 贪心选择性质。0-1 背包与分数背包的区别就在于"能否切分"。

64. A｜【数据结构】哈夫曼编码 （【存疑：图形复原】频率表见 2019H2-morning-questions.md 第 64-65 题附注：a=40%、b=10%、c=20%、d=16%、e=14%。） 构造哈夫曼树：取两个最小 {b:10, e:14} 合并为 24；再取 {d:16, c:20} 合并为 36；{24, 36} 合并为 60；最后 {a:40, 60} 合并为根 100。 a 的编码长 1 位（0），b、c、d、e 的编码长 3 位。按原图标注：c = 111、a = 0、d = 110、e = 101， "cade" = 111 + 0 + 110 + 101 = 1110110101。选 A。 排除：B/D 以 11 开头（a 编码为 1，与 a 频率最高应为最短编码矛盾）；C 末位为 0（e 应为 101，末位 1）。

知识点：哈夫曼树 = 每次合并两个最小频率的子树；频率越高编码越短。前缀码性质保证无歧义解码。

65. C｜【数据结构】哈夫曼编码压缩比 5 个不同字符，等长编码至少需 3 位，压缩前每字符平均 3 bit。 压缩后平均码长 = [40×1 + (10+20+16+14)×3] / 100 = (40 + 60×3) / 100 = 220/100 = 2.2 bit。 压缩比 = (3 - 2.2) / 3 = 0.8 / 3 ≈ 0.267 ≈ 27%。选 C。 排除：A 20%（2.4 bit 平均长，错）、B 25%（2.25 bit，错）、D 30%（2.1 bit，错）。

知识点：压缩比 = (原平均码长 - 压缩后平均码长) / 原平均码长。哈夫曼编码的带权路径长度（WPL）即压缩后总比特数。

66. D / 67. B｜【网络】TCP/IP 与 OSI 模型对应 TCP/IP 网络中，建立连接进行可靠通信由 TCP 协议完成，属于 传输层（66 选 D）。 OSI/RM 七层模型中，传输层之上还有会话层、表示层、应用层；会话层提供建立、维护和结束会话连接的功能（即"建立连接"对应 OSI 的会话层），67 选 B。

知识点：TCP/IP 四层 = 网络接口层、网际层（IP）、传输层（TCP/UDP）、应用层。OSI 的会话层在 TCP/IP 中被并入应用层。

68. D｜【网络】IPv6 地址空间 IPv4 地址 = 32 位，地址空间 2³²；IPv6 地址 = 128 位，地址空间 2¹²⁸。 2¹²⁸ / 2³² = 2⁹⁶ 倍。选 D。 排除：A 4（2²，误作 128/32 的比值中的"倍"的差）、B 96（把位数差当倍数）、C 128（把位数当倍数）。

知识点：IPv4 = 32 位（4 字节，点分十进制）；IPv6 = 128 位（8 组 16 位，冒号十六进制）。地址空间倍数 = 2^(128-32) = 2⁹⁶。

69. A｜【网络】无线通信技术 蓝牙通信距离最短（约 10 米），用于连接本地外围设备（耳机、鼠标、打印机）。选 A。 排除：窄带微波（B，点对点，几十米到数公里）；CDMA（C，蜂窝移动通信，数百米到数公里）；蜂窝通信（D，基站覆盖，公里级）。

知识点：无线技术距离排序（由近到远）= 蓝牙（10m）< 红外（1m，但属视距通信）< Wi-Fi（100m）< 窄带微波 < 蜂窝/CDMA。

70. A｜【网络】邮件协议 发送带多媒体数据（附件、非 ASCII 内容）的电子邮件，需采用 MIME 协议扩展邮件标准以支持多媒体格式。选 A。 排除：SMTP（B，只传输纯文本邮件，无法处理多媒体）；POP3（C，收取邮件协议）；IMAP4（D，在线收取/管理邮件协议）。B/C/D 都不负责"发送多媒体"。

知识点：SMTP = 发送（ push ）；POP3/IMAP4 = 接收（ pull ）；MIME = 内容格式扩展。安全邮件 = S/MIME、PGP。

71. A｜【计算机英语】微服务架构（集成） "It might also integrate with other applications via either web services or a message broker."——应用还可能通过 Web 服务或消息代理与其他应用集成。选 A。 排除：coordinate（B，协调，不带"with 其他应用"的集成语义）；cooperate（C，合作）；communicate（D，通信，语义偏窄）。

知识点：integrate with = 与…集成。微服务通过 API/消息代理与其他系统集成。

72. B｜【计算机英语】请求与响应 "returning a HTML/JSON/XML response"——处理请求后返回 HTML/JSON/XML 格式的响应。选 B。 排除：request（A，请求，是"被处理的"而非"返回的"）；text（C，太泛）；file（D，文件）。

知识点：HTTP 请求-响应模型：客户端发 request，服务端返回 response。Content-Type 决定 HTML/JSON/XML 格式。

73. A｜【计算机英语】松耦合服务集 "structures the application as a set of loosely coupled, collaborating services"——将应用构造为一组松散耦合的、相互协作的服务集合（对应 Scale Cube 的 Y 轴拆分）。选 A。 排除：loosely cohesion（B，语法错误，cohesion 是名词，不能修饰 services）；highly coupled（C，紧耦合，与微服务理念相反）；highly cohesion（D，语法错误且语义相反）。

知识点：微服务核心特征 = 松耦合（loosely coupled）+ 高内聚（highly cohesive）。耦合度与内聚度是架构质量的两个度量。

74. B｜【计算机英语】独立部署 "Independently deployable — enables a team to deploy their service without having to coordinate with other teams."——可独立部署，团队无需与其他团队协调即可部署自己的服务。选 B。 排除：Dependently（A，依赖部署，相反）；Coordinately（C，需协调，正是本特征要避免的）；Integratedly（D，非标准词）。

知识点：独立部署（independent deployment）是微服务相对单体应用的核心优势，要求服务间接口契约稳定。

75. C｜【计算机英语】服务间通信 "Services communicate using either synchronous protocols such as HTTP/REST or asynchronous protocols such as AMQP."——服务间通过 HTTP/REST 等同步协议或 AMQP 等异步协议进行通信。选 C。 排除：interoperate（A，互操作，指系统能理解彼此接口，语义偏重"兼容性"而非"消息传递"）；coordinate（B，协调）；depend（D，依赖）。

知识点：同步通信 = HTTP/REST、RPC；异步通信 = 消息队列（AMQP、RabbitMQ、Kafka）。异步通信实现服务间解耦与削峰。
