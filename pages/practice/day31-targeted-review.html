3 分钟速记卡（合上文件默写）

关键路径 = 源点到汇点的【最长路径】，其长度 = 【最短工期】（不是边最多的路径！）
正向求 Ve：从左向右，取【大】 max{ Ve(i) + d(i,j) }，源点 Ve = 0
逆向求 Vl：从右向左，取【小】 min{ Vl(j) − d(i,j) }，汇点 Vl = Ve(汇点)
活动总时差（松弛）= LS − ES = Vl(终点) − Ve(起点) − 活动时长
总时差 = 0 的活动 = 【关键活动】；"延期 x 天是否影响工期"⇔ 比较 x 与总时差
一个 AOE 网可有多条【等长】关键路径——找全再选答案
口诀：最早取大、最晚取小；总时差 = LS − ES；时差为 0 是关键活动

3 分钟速记卡（合上文件默写）

页大小 = 2^k ⇒ 逻辑地址【低 k 位 = 页内偏移】，高位 = 页号
页号是【查表的键】，查表得到的【块号】才是结果
物理地址 = 块号 × 2^k + 偏移（即二进制【拼接】，不是相加！）
固定套路口诀：除以页大小得页号、取余得偏移；物理地址 = 块号 × 页大小 + 偏移
段页式 = 段号 + 页号 + 页内偏移：先查【段表】得页表始址，再查【页表】得块号
段式 ≠ 页式：页式乘页大小（块号拼接偏移）、段式加段基址（段基址 + 偏移）
常用换算：4K = 2¹²、8K = 2¹³、16K = 2¹⁴、1K = 2¹⁰

自测小题 2 道（先做，答案在本点末尾折叠区）

自测 2-1：某系统采用页式存储管理，页面大小为 8KB。逻辑地址为 5F3AH，查页表知页号对应的物理块号为 9。求：① 页号与页内偏移各是多少（偏移用十六进制写）？② 物理地址是多少？

自测 2-2：某计算机采用段页式存储管理，逻辑地址共 32 位，其中段号 8 位、页号 12 位，其余为页内偏移。求：① 页内偏移占几位？页大小是多少？② 该系统最多允许多少个段？每个段最多允许有多少页？

【答案】自测 2-1 与 2-2（做完再展开） **自测 2-1 答案**： - ① 8KB = 2¹³，故低 13 位为页内偏移。 5F3AH = 24378；24378 ÷ 8192 = 2 余 7998 ⇒ **页号 = 2**；余数 7998 = **1F3AH**（验算：2 × 2000H = 4000H，5F3AH − 4000H = **1F3AH**）⇒ **页内偏移 = 1F3AH**。 （二进制切位验算：5F3AH = 0101 1111 0011 1010B，低 13 位 = 1 1111 0011 1010B = 1F3AH，高 3 位 = 010B = 2 ✓） - ② 物理地址 = 块号 × 页大小 + 偏移 = 9 × 8192 + 7998 = 73728 + 7998 = **81722 = 13F3AH**。 （验算：9 × 2000H = 12000H，12000H + 1F3AH = **13F3AH** ✓。块号 9 拼到高位，偏移照抄——这就是"拼接不是相加"。） **自测 2-2 答案**： - ① 页内偏移位数 = 32 − 8 − 12 = **12 位** ⇒ 页大小 = 2¹² = 4096 B = **4 KB**。 - ② 段号 8 位 ⇒ 最多 **2⁸ = 256** 个段；页号 12 位 ⇒ 每个段最多允许 **2¹² = 4096** 页（是**上限**，不是"每个段都正好 4096 页"——段内页数随段大小变化）。

  两端都不唯一（一个 X 可对应多个 Y，一个 Y 也可对应多个 X）⇒ m:n
  ⚠️ "至少一位""可服务多位"= 上界不限 = n，别看成 1:1
E-R → 关系模式转换规则：
  1:1 ⇒ 任一端的关系加【对方的主键】作外键
  1:n ⇒ 【n 端】的关系加【1 端的主键】作外键（外键加错端是最常见丢分）
  m:n ⇒ 【新建】一个关系，主键 = 两端主键的【组合】
主键 = 唯一确定一个元组的【最小】属性组；外键 = 引用其它关系主键的属性
候选码 4 步：① 只在左出现⇒必含；只在右出现⇒必排除；两侧都有⇒待定
            ② 对待定属性求闭包 X⁺；③ X⁺ = U ⇒ X 是候选码；④ 候选码的属性都是主属性
Armstrong：伪传递 = X→Y 且 WY→Z ⇒ XW→Z（不是传递律！）
关系模式填空：把需求属性清单与关系模式【逐项对照】，找全所有空缺（常常漏填外键）

自测 4-1：下面是区间型动态规划（矩阵连乘 / 最优三角剖分类）的核心代码骨架，(1)~(4) 各应填什么？

for (r = 2; r <= n; r++)              // (1) ____________________
    for (i = 1; i <= n - r + 1; i++)  // (2) ____________________
    {
        j = i + r - 1;                // (3) ____________________
        for (k = i; k < j; k++)       // (4) ____________________

自测 4-2：三个矩阵连乘，维数分别为 A₁: 10×5、A₂: 5×20、A₃: 20×3（即 p₀=10, p₁=5, p₂=20, p₃=3）。求：① 最少乘法次数；② 最优括号化方案（在哪个位置断开）？要求写出 m[1][2]、m[2][3]、m[1][3] 的计算过程。

【答案】自测 4-1 与 4-2（做完再展开） **自测 4-1 答案**： - (1) **枚举区间规模 r**（从 2 到 n：先算所有长度为 2 的区间，再长度为 3……保证算 m[i][j] 时它依赖的更短区间已算完）； - (2) **枚举左端点 i**（右端点由规模推出，上界 n−r+1 保证 j ≤ n）； - (3) **右端点 j = i + r − 1**； - (4) **枚举切点 k**（在 i 与 j−1 之间，把区间 [i,j] 切成 [i,k] 与 [k+1,j] 两段）。 口诀对照：**外层规模、中层左端、内层切点**。方向记反是本题最常见的错——规模一定在最外层，否则依赖的子问题还没算。 **自测 4-2 答案**： - 边界：m[1][1] = m[2][2] = m[3][3] = 0。 - 长度 2：m[1][2] = p₀p₁p₂ = 10×5×20 = **1000**；m[2][3] = p₁p₂p₃ = 5×20×3 = **300**。 - 长度 3（m[1][3]，在 k=1 或 k=2 断开）： - k=1：m[1][1] + m[2][3] + p₀p₁p₃ = 0 + 300 + 10×5×3 = 300 + 150 = **450**； - k=2：m[1][2] + m[3][3] + p₀p₂p₃ = 1000 + 0 + 10×20×3 = 1000 + 600 = **1600**。 - 取最小 ⇒ **m[1][3] = 450**，断开点 **k = 1**。 - 结论：① **最少乘法次数 = 450 次**；② 最优方案 **(A₁(A₂A₃))**——先算 A₂A₃（5×20×3=300 次，得 5×3 矩阵），再算 A₁×该结果（10×5×3=150 次），合计 450 次。若用 (A₁A₂)A₃ 则需 1000+600=1600 次。
