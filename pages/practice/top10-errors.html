Phase 2 高频错题 TOP 10（考前必刷 · 举一反三）

适用阶段：Day 26 之后，冲刺阶段每日回看。本文从 8 套已交付真题卷（2019 上/下、2020 下、2021 上/下、2022 上/下、2023 上）的答案解析中反复出现的易错点、⚠️ 分歧题、计算型失分题，以及三轮错题回归（review-round1/2/3.md）中筛选出错误率最高的 10 个知识点。

每个条目结构：知识点 → 为什么易错 → 正确套路（公式或判定步骤）→ 真题例题（指向已交付 key）→ 举一反三变式。

使用方法：先盖住"正确套路"自己复述，再对照；例题回到对应 -key.md 重做推导；变式用来检验是否真正掌握（换个壳子还会不会）。

TOP 1：AOE 网关键路径与总时差（松弛时间）

知识点：关键路径 = 从源点到汇点的最长路径，其长度 = 最短工期；活动的总时差（松弛时间）= 该活动最迟开始时间 − 最早开始时间。

为什么易错： - 把"最长路径"理解成"边最多的路径"（长度是权值之和，不是边数）。 - 只算出一条关键路径就选答案——一个 AOE 网可以有多条等长的关键路径（2020 下 Q18 就有 2 条）。 - 总时差公式方向记反（Vl − Ve 而不是 Ve − Vl），或松弛时间忘记减去活动本身的时长。 - "哪个活动延期会影响总工期"= 问关键活动（总时差为 0），不是问最长边。

正确套路（判定步骤）： 1. 正向递推最早发生时间：Ve(j) = max{ Ve(i) + d(i,j) }，源点 Ve = 0； 2. 逆向递推最迟发生时间：Vl(i) = min{ Vl(j) − d(i,j) }，汇点 Vl = Ve(汇点)； 3. 关键活动：Ve(i) = Vl(i) 的顶点；关键路径长度 = Ve(汇点)； 4. 活动 e→k 的松弛时间 = Vl(k) − Ve(e) − d(e,k)（总时差 ≥ 0，= 0 即关键活动）； 5. "延期 x 天是否影响工期"：比较 x 与该活动总时差，x ≤ 总时差则工期不变。

真题例题：2019H1-morning-key.md Q18（关键路径 55 天，⚠️ 网络分歧 50/55）、2019H2-morning-key.md Q17-18（ABFJL 与 ADGIJL 均 22 天，2 条）、2020H2-morning-key.md Q17-18（22 天，2 条）、2021H1-morning-key.md Q17（A-D-F-H-J 48 天）、2021H2-morning-key.md Q18-19（20 天 + 关键活动判定）、2022H1-morning-key.md Q69-70（65 天 + 延误吸收，⚠️ 图形复原不全）、2022H2-morning-key.md Q17-18（A-C-F-I-J 58 天）、2023H1-morning-key.md Q17-18（23 天）；本模拟卷 2018H1-mock-key.md Q17-18（22 天 + EH/IJ 松弛）。

举一反三变式： - 变式 A：给出"活动 EH 延期 4 天"，问总工期是否变化（算 EH 松弛 = 5 > 4 → 不变）。 - 变式 B：图中增加一条新边，问关键路径是否改变（重算两条候选路径长度比较）。

TOP 2：页式地址转换与位示图（OS 存储管理计算）

知识点：页式虚拟地址 = 页号 + 页内偏移；物理地址 = 块号拼接偏移。位示图用位记录磁盘块使用情况。

为什么易错： - 页号查表得到块号后，与偏移相加（错），应为拼接； - 页大小 4K = 2¹² 不知道这意味着"低 12 位是偏移"； - 位示图：容量单位换算错（GB→MB 乘 1024），或把"每字几位"与"字数"弄反。

正确套路（公式）： - 页大小 = 2^k → 虚拟地址低 k 位 = 页内偏移，高位 = 页号； - 查页表：页号 → 块号；物理地址 = 块号 × 2^k + 偏移（即二进制拼接）； - 位示图：字数 = 磁盘块数 ÷ 字长(位/字)；块数 = 磁盘容量 ÷ 块大小（注意 2 进制换算）。

真题例题：2020H2-morning-key.md Q24（3C20H → 页号 3 → 块号 6 → 6C20H，拼接不是相加）；位示图：2019H1-morning-key.md Q25、2021H1-morning-key.md Q24、2023H1-morning-key.md Q23。

举一反三变式： - 变式 A：页大小 8K，逻辑地址 2F3AH → 页号、偏移各是多少？（8K = 2¹³，低 13 位为偏移） - 变式 B：2048GB 磁盘、8MB 块、字长 128 位 → 位示图几个字？（2¹⁸ 块 ÷ 2⁷ = 2048 个字）

TOP 3：前驱图 / 临界区 PV 操作填空（信号量初值）

知识点：用信号量与 P/V 操作实现进程同步与互斥；前驱图中每条边对应一对 P/V。

为什么易错： - P、V 写反（正确：前驱结束后 V，后继开始前 P）； - 信号量初值设错：互斥用 1、同步（前驱约束）用 0、资源信号量用"可用资源数"； - 多空连环题（三空/四空）题号与空位错位；只顾一个信号量忘了配对。

正确套路（判定步骤）： 1. 每条前驱边 Pi → Pj 设一个信号量 S（初值 0）：Pi 的结束处 V(S)，Pj 的开始处 P(S)； 2. 互斥临界区设一个信号量 mutex（初值 1）：进临界区前 P(mutex)，出临界区后 V(mutex)； 3. 资源信号量初值 = 可用资源数；其取值范围 = [−(n−初值), 初值]； 4. 口诀："前 P 后 V 一对配，初值看资源：互斥 1、同步 0"。

真题例题：2019H2-morning-key.md Q23-25、2021H1-morning-key.md Q26-28、2021H2-morning-key.md Q24-26、2022H1-morning-key.md Q58-61（四空连环）、2023H1-morning-key.md Q26-28；信号量取值范围 2020H2-morning-key.md Q27；本模拟卷 2018H1-mock-key.md Q23-24（售票临界区互斥，初值 1）。

举一反三变式： - 变式 A：售票系统保护共享剩余票数，(a) 处进临界区前应填什么操作？（P(S)，S 初值 1） - 变式 B：n 个进程共享 5 台打印机，信号量取值范围？（−(n−5) ~ 5）

TOP 4：索引文件容量（多级索引计算）

知识点：文件系统中多级索引能寻址的最大文件长度。

为什么易错： - 把"1KB 索引块 / 4B 地址项"算成 1024 项（应为 256 项）； - 漏算直接索引项；二级索引忘记平方； - 单位混用（结果单位是"数据块"还是"KB"）。

正确套路（公式）： - 每个索引块可容纳地址项数 = 索引块大小 ÷ 地址项长度（1024B ÷ 4B = 256 项）； - 最大文件长度 = 直接索引项数 + 一级索引项数 × 256 + 二级索引项数 × 256²（单位：数据块）； - 若题目给三级索引，再加 三级项数 × 256³。

真题例题：2020H2-morning-key.md Q25-26（直接 5 + 一级 2×256 + 二级 256² = 66053 KB）。

举一反三变式： - 变式 A：索引块 512B、地址项 4B、直接 4 项 + 一级 2 项 → 最大多少块？（128 项；4 + 2×128 = 260 块） - 变式 B：为什么二级索引是 256² 而不是 2×256？（一级索引块本身再存 256 个指向二级索引块的指针）

TOP 5：候选码判定与函数依赖（Armstrong 公理）

知识点：求关系模式的候选码；Armstrong 公理系统（自反律、增广律、传递律、伪传递律）。

为什么易错： - 候选码漏属性（属性闭包没求全就下结论）； - 伪传递律与传递律混淆：伪传递是 X→Y, WY→Z ⇒ XW→Z，传递是 X→Y, Y→Z ⇒ X→Z； - 冗余依赖判断错（能被其余依赖推出的那条才是冗余）。

正确套路（判定步骤）： 1. 筛属性：只在左侧出现的属性必在候选码中；只在右侧出现的属性必不在；两侧都出现的待定； 2. 对待定属性逐个/分组求闭包 X⁺：若 X⁺ = U（全部属性）则 X 是候选码； 3. 候选码的属性都是主属性； 4. Armstrong：伪传递 = X→Y 且 WY→Z ⇒ XW→Z；增广 = X→Y, Z⊆U ⇒ XZ→YZ。

真题例题：2021H1-morning-key.md Q52-53（唯一候选码 AC + 冗余依赖 A→H）、2023H1-morning-key.md Q52-54（Armstrong 公理 + 候选码与主属性）、2019H1-morning-key.md Q52-53；本模拟卷 2018H1-mock-key.md Q51（伪传递律辨析）。

举一反三变式： - 变式 A：R(A,B,C,D)，F = {A→B, B→C, C→D}，候选码？（A，因为 A⁺ = ABCD） - 变式 B："若 X→Y, WY→Z 则 XW→Z"是哪条公理？（伪传递律，不是传递律）

TOP 6：二叉树顺序存储下标与"树的度→叶子数"

知识点：二叉树的数组（顺序）存储中父子下标的关系；树的度数与叶子结点数公式。

为什么易错： - 顺序存储下标从 0 还是从 1 开始搞混，导致左右孩子公式用错； - 树的度公式 n₀ = 1 + Σ(i−1)·nᵢ 记不住或把 n₀、n₁、n₂ 代错； - 二叉树性质 n₀ = n₂ + 1 与一般树的度公式混用。

正确套路（公式）： - 根下标为 1：左孩子 = 2i，右孩子 = 2i+1；父 = ⌊i/2⌋； - 根下标为 0：左孩子 = 2i+1，右孩子 = 2i+2；父 = ⌊(i−1)/2⌋； - 一般树（度 = max 分支数）：n₀ = 1 + Σ_{i≥1}(i−1)·nᵢ（nᵢ = 度为 i 的结点数）； - 二叉树：n₀ = n₂ + 1。

真题例题：本模拟卷 2018H1-mock-key.md Q59（A=1/B=2/C=3 → D、E、F = 6、7、14）；2019H2-morning-key.md Q59（树的度公式）、2022H1-morning-key.md Q28/Q41（树的度求叶子数 / 满二叉树编号父子关系）。

举一反三变式： - 变式 A：根下标为 1 时，下标 5 与 10 的结点是什么关系？（10 = 2×5 → 5 是 10 的父，左孩子） - 变式 B：树有 5 个度为 3 的结点、3 个度为 1 的结点，无度为 2 的结点，叶子几个？（n₀ = 1 + 2×5 + 0×3 = 11）

TOP 7：哈希表构造与冲突（线性探查）

知识点：哈希冲突的定义、线性探查法构造哈希表、同义词概念。

为什么易错： - 误以为"线性探查的探查序列里都是同义词"（实际上可能挤进来别的关键字的同义词）； - 哈希函数 H(key) mod m 的 m 取错；装填因子与平均查找长度关系不清； - 冲突的定义与"聚集（聚集）"混淆。

正确套路（判定步骤）： - 冲突 = 不同关键字被映射到相同地址； - 线性探查：冲突后依次试 H(key)+1, +2, … (mod m)； - 造表必须逐个元素、逐个地址画表，每插入一个就记录其探查序列； - 查找某 key 的比较次数 = 查到它时所探查的位置数。

真题例题：2019H1-morning-key.md Q60（线性探查哈希表构造）、2021H1-morning-key.md Q60（⚠️ 同义词分歧题：探查序列里不都是同义词）、2022H1-morning-key.md Q26（聚集与同义词）；本模拟卷 2018H1-mock-key.md Q60（冲突的定义）。

举一反三变式： - 变式 A：m = 5，依次插 1、6、2、7，哈希函数 key mod 5，则查 7 要比较几次？（1→位1，6→位1冲突→位2，2→位2冲突→位3，7→位2冲突→位3冲突→位4；查 7 比较 3 次） - 变式 B：链地址法下"同义词"如何组织？（同一链表，探查序列即链表）

TOP 8：白盒覆盖标准与 McCabe 环路复杂度

知识点：语句覆盖 / 判定覆盖 / 条件覆盖 / 判定-条件覆盖 / 路径覆盖的强度与用例数；McCabe 环路复杂度。

为什么易错： - 覆盖标准强弱记错（语句 < 判定 < 条件 < 判定-条件 < 路径）； - 判定覆盖用例数靠"猜"（应按"每个判定的真假各至少一次"推导）； - McCabe 公式记成 E − N（漏 +2），或数区域时漏算图外区域。

正确套路（公式）： - 覆盖强度：语句覆盖 < 判定覆盖 < 条件覆盖 < 判定-条件覆盖 < 路径覆盖； - 判定覆盖：每个判定的"真/假"分支各至少一次（k 个判定，常可用 2 个用例组合达成，具体看流程图汇合结构）； - 路径覆盖：每条可执行路径一个用例（注意排除不可达路径）； - McCabe 三种等价算法：V(G) = 判定节点数 + 1 = E − N + 2 = 区域数（含图外区域）。

真题例题：2019H1-morning-key.md Q34-35、2019H2-morning-key.md Q34-35（路径计数 + McCabe B）、2020H2-morning-key.md Q35-36（语句覆盖 1 个 vs 路径覆盖 4 个）、2021H1-morning-key.md Q34（路径覆盖）、2021H2-morning-key.md Q34-35（语句覆盖 + McCabe C）、2023H1-morning-key.md Q34-35（路径覆盖 + McCabe C）；本模拟卷 2018H1-mock-key.md Q34-35（判定覆盖 2 个 + McCabe B=3）。

举一反三变式： - 变式 A：两个串联判定、无嵌套，判定覆盖最少几个用例？（2 个：一个使两判定皆真、一个使两判定皆假） - 变式 B：流程图 12 条边、9 个节点 → V(G)？（12 − 9 + 2 = 5）

TOP 9：设计模式识别与 GoF 分类（意图 → 模式）

知识点：GoF 23 模式的分类（创建型 5 / 结构型 7 / 行为型 11；类模式 vs 对象模式）与各模式意图。

为什么易错： - 意图与模式张冠李戴：把"抽象与实现分离"当成适配器（实为桥接）、把"动态加职责"当成代理（实为装饰）； - 分类记错：把桥接当成创建型（实为结构型对象模式）； - 只记名字不看类图角色（Abstraction / Implementor 双层级 = 桥接）。

正确套路（意图速记）： - 结构型 7 个（对象）：适配器（对象适配）、桥接、组合、装饰、外观、享元、代理； - 意图动词对应：桥接 = 将抽象部分与其实现部分分离，使二者独立变化；适配器 = 接口转换；装饰 = 动态加职责；外观 = 子系统统一入口；享元 = 共享细粒度对象；代理 = 控制访问； - 行为型：观察者 = 一对多通知；策略 = 算法可互换；中介者 = 对象间解耦中介；责任链 = 请求沿链传递；迭代器 = 顺序访问聚合； - 识别题先看类图是不是"两个独立继承维度 + 一个聚合"→ 桥接。

真题例题：2019H2-morning-key.md Q44-47（桥接四空：识别 / 结构 / 适用性 / 结构型分类）；2019H1-morning-key.md Q44-46（责任链 + 迭代器）、2021H2-morning-key.md Q44-46（中介者）、2022H1-morning-key.md（观察者 / 单例）；本模拟卷 2018H1-mock-key.md Q44-47（桥接：WebApplication × Theme 双维度）。

举一反三变式： - 变式 A：图形（圆/方形）× 绘图程序（V1/V2）两个维度独立扩展 → 什么模式？（桥接） - 变式 B："为其他对象提供代理以控制访问"→ 什么模式？（代理，不是装饰）

TOP 10：校验码（海明码位数与分组、CRC 模 2 运算）

知识点：海明码校验位个数公式与分组规则；CRC 的模 2 运算。

为什么易错： - 海明码校验位公式 2^k ≥ n + k + 1 忘记 +1； - 分组规则不会用：数据位由哪些校验位校验（要把位序分解为 2 的幂之和）； - CRC 用普通除法而非模 2 除法（异或）。

正确套路（公式与步骤）： - 校验位个数：求最小 k 使 2^k ≥ n + k + 1（n = 数据位数）； - 分组规则：校验位 Pj 位于位序 2^(j−1) 处（从右至左编号）；任一数据位所在位序若 = 2^a + 2^b + …，则由 P(a+1)、P(b+1)、… 校验； 例：位序 14 = 8+4+2 → P4、P3、P2；位序 10 = 8+2 → P4、P2； - CRC：用生成多项式对数据（后补 k 个 0）做模 2 除法，余数即 CRC 校验位。

真题例题：2023H1-morning-key.md Q3（海明码校验位）、2019H1-morning-key.md Q5（CRC 模 2 运算）；本模拟卷 2018H1-mock-key.md Q4-5（32 位数据需 6 个校验位 + D5 由 P4P2 校验）。

举一反三变式： - 变式 A：64 位数据至少需要几个海明校验位？（2^k ≥ 64+k+1 → 7 个） - 变式 B：流水线各段操作时间不同时，吞吐率是"最长流水段时间"的倒数（本模拟卷 2018H1-mock-key.md Q6）——同属"公式型记忆题"，一起记。

9 哈希 冲突 = 异关键字同地址；线性探查 H+i (mod m)；探查序列不都是同义词
10 海明码 2^k ≥ n+k+1；位序分解为 2 的幂之和定分组；CRC 用模 2（异或）除法
11 流水线 吞吐率 = 最长流水段时间倒数；加速比 = 顺序时间 ÷ 流水时间
12 可靠性 串联 R₁R₂…；并联 1−(1−R₁)(1−R₂)…；混合先并后串 / 先串后并看表达式
13 设计模式 结构型 7：适桥组装外享代；桥接 = 抽象与实现两维度独立变化
14 UML 图 类图静态结构；序列图按时间；通信图按对象结构传消息；状态图状态转换；部署图软/硬件物理关系
15 进程模型 瀑布需求冻结；增量早交付（第一版本快）；"管理成本"注意两种口径：单个增量易理解成本低（2018 上口径）/ 多增量整体管理成本高（2021 下口径），审题看选项措辞；螺旋 = 风险驱动；原型明需求
16 CMM/CMMI CMM 5 级：初始→可重复→已定义→已管理→优化；CMMI 阶段式同此，CL1 已执行 = 输入转输出
17 OLAP/OLTP 多维分析 = OLAP；日常事务 = OLTP；抽取转换加载 = ETL
18 著作权 署名权/修改权/保护完整权保护期不受限；职务软件著作权归单位；软件著作权自开发完成之日产生
19 中断与 DMA 中断 = 暂停→服务→返回，保存现场为返回原程序；DMA = 主存↔外设直接传送
20 排序复杂度 快排/归并/堆 O(nlgn)；邻接矩阵 DFS/BFS = O(n²)，邻接表 = O(n+e)

最后 30 秒：把上表从 1 念到 20，卡壳的那一行就是今天要重做的题。计算题（1、2、3、5、7、8、10）必须在草稿纸上重算一遍，不能只看公式。
