高频考点速查卡

考前3天重点复习此卡片内容

🔴 数据结构（必考）

链表反转

prev = null, curr = head
while curr != null:
    next = curr.next
    curr.next = prev
    prev = curr
    curr = next
return prev

二叉树遍历

  • 前序：根左右
  • 中序：左根右
  • 后序：左右根
  • 层序：逐层

排序算法复杂度

  • 快速排序：平均O(nlogn)，最坏O(n²)
  • 归并排序：O(nlogn)稳定
  • 堆排序：O(nlogn)不稳定

哈希表

  • 查找O(1)平均
  • 冲突解决：链地址法、开放地址法

🔴 操作系统（必考）

PV操作模板

P(S): S--; if(S<0) block
V(S): S++; if(S<=0) wakeup

死锁条件

互斥 + 占有且等待 + 不可剥夺 + 循环等待

页面置换

  • LRU：最近最少使用（常用）
  • FIFO：先进先出
  • OPT：最佳（理论）

🔴 计算机网络（必考）

TCP三次握手

SYN → SYN+ACK → ACK

子网划分

网络地址 = IP & 子网掩码 可用主机 = 2^主机位 - 2

端口号

HTTP=80, HTTPS=443, FTP=21, SSH=22, DNS=53, SMTP=25

🔴 数据库（必考）

SQL执行顺序

FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY

范式判断

  • 1NF：属性不可分
  • 2NF：消除部分依赖
  • 3NF：消除传递依赖

事务ACID

原子性、一致性、隔离性、持久性

🔴 软件工程（必考）

耦合强度（从强到弱，七级）

内容 > 公共 > 外部 > 控制 > 标记 > 数据 > 非直接

内聚强度（从弱到强）

偶然 < 逻辑 < 时间 < 过程 < 通信 < 顺序 < 功能

测试覆盖

语句 < 判断 < 条件 < 判定/条件 < 条件组合 < 路径

🔴 计算机组成

Cache映射

直接映射：块号 = 主存块号 % Cache块数

流水线

加速比 = 串行时间 / 流水线时间

总线带宽

带宽 = 频率 × 位宽 / 8
